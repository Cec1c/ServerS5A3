# 六期礼包、历史续期与协议兼容增量

六期礼包的账号计数、购买事务、奖励出站和查询协议已经在本仓库。本次补齐日历入口、礼包窗口源码及装饰、精确配置片段，并公开历史道具续期规则和额外兼容回归。

## 礼包入口和资源

日历新增60001–60006六个入口，分别对应201601、201605、201607、201701、201801、201807。保留既有活动状态和奖励参数，匹配资源中没有菜单模板的旧入口只隐藏展示；没有礼包配置的PVF保持原目录。

- 客户端静态组件及接口：[festival-ui](../scripts/client/festival-ui/README.md)。包含关闭后重开修正、分页、邮件状态、拖动与日历贴靠。
- 三个PVF配置节：[六期礼包配置](../resources/festival/README.md)。只提供商品与期次、档位、重复赠礼规则。
- 素材共11帧页面装饰及独立3帧翻页按钮，源PNG/SVG与原包像素核对；不需要其它活动页素材。原生窗口外框与字体仍由匹配客户端提供。

组件可以独立编译和离线验证，不包含完整累计客户端的其它实现，也不提供完整EXE重建或安装脚本。实际接入时必须保持现有分派、来源通知、对象所有权和其它累计功能。

## 精确历史续期

两个名单分别包含50项节日道具和357项经验道具。只有物品ID、规范化资源路径、旧实例绝对期限及目标PVF期限都相符时才续期。目标期限采用现有PVF/协议编码1861826400；目标资源定义须先实际具有该期限。每日删除、相对期限和独立指定期限不属于这个迁移。

合成定义测试覆盖全部407项身份、路径规范化、错误ID/路径/目标、每日和相对期限、独立期限保护及重复执行。另有显式提供资源的实档测试；公开源码不依赖完整私有PVF才能运行基础回归。

## 删除及邮件兼容

合法的材料删除请求在归属、槽位或数量等业务校验失败时返回当前客户端可解析的失败protobuf ACK，结束待删除状态；非法报文仍拒绝，失败不修改资产。

邮件op95领取成功后只用ACK更新对应附件，保留库存行刷新。详情页还可能持有父邮件对象，因此不再立即重建整个邮箱管理器；op96显式重开仍返回完整列表。回归同时检查多附件逐个/全部领取、满包剩余、保存信件、重复请求和资产原子性。

## 其它回归与历史工具

新增退队重组首次/再次进图、最后队员退出、奖励资格与展示分离、缓存多键并发、隐藏迷宫解析、换装身份、公会结果窗口、死亡/复活和比赛目录的回归。公开主干已经提取的共享测试夹具继续复用；保留当前各团本等待区边界。通用奖励溢出测试保留原覆盖，不引入其它奖励配置。

[队伍标识工具](../scripts/client/raid-table-roster/README.md)和[本地头像工具](../scripts/client/raid-local-face/README.md)是固定旧输入摘要的维护资料；只生成外部候选并独立验证，不安装到当前客户端。[售货机满包拒绝验证](../scripts/client/vending-mail/README.md)只验证历史匹配输入的失败应答，不包含客户端补丁。

异次元历史计数说明、隐藏领主PVF规则及队友mode0状态文档分别标明证据日期、已知契约和未验收边界。卢克共享完成的资源与事务说明已在 [LUKE_ENERGY_PARTY_COMPLETION.md](LUKE_ENERGY_PARTY_COMPLETION.md)，本次不重复其历史段落。
