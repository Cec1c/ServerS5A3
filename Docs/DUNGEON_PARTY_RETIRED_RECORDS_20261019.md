# 副本解散时清理整份旧队伍记录

当前客户端可为每名已投影成员分别保存一份副本上下文队伍表。队长回城触发解散时，
旧实现给留图成员发队长的上下文0移除，再给每名在线成员发自身的城镇上下文空队伍。
这无法覆盖接收者持有的其它副本上下文记录。只读现场确认权威队伍已消失，
客户端仍有包含双方成员的旧副本记录。

仅在既有队长离图且其它队员留在原副本的解散分支，official-24.9针对本次权威
快照中的全部成员，向每个当前绑定接收者补齐上下文0的kind3记录清理；
已成功发送的队长移除不重复。原有空实时表、本地空队伍、队员原实例保持。
没有mode0/mode1外观重画，不修改时装、角色存档或PVF。

`DNFBRIDGE_PARTY_DUNGEON_RETIRED_RECORD_CLEAR=off`保留旧通知序列；其它profile
仍用旧行为。当前绑定发生变化即停止补发，零键、重复键不发送。

配套v140修正客户端kind3最终删除误用本地连接上下文的问题；线格式无新增字段。
v139及更早客户端仍有自身删除上下文缺陷，不能据此声称其旧缓存已彻底回收。
本项与v140及后续入队方向、活动人物移除组合已完成预览实机验收。

红绿回归确认原实现漏掉返回者的两份记录及留图成员自己的记录；补修后双方
每个成员上下文0记录恰好清理一次，留图实例及权威队伍解散规则保持。
已验收双方模型、重新组队及再次进图；资料窗与头像时装另行修复。
