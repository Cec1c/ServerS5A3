# 擂台战默认出场顺序与不等人数开局

模式 3 在双方各有至少一名参战者、所有非房主参战者已准备后允许开局，支持 1v2、1v3 和反向组合。其它模式保留原人数校验，观战者不计入人数。

客户端进入初始选人状态 8、整理完候选者后自动发送空体 C2S298；服务端收到所有参战者的通知后安排五秒选择窗口。无人申请投骰时，每队选择座位号最小的存活玩家，class-0/112 不带骰子行，因此直接出场。存在有效申请时保留原有随机投骰。击败后仍由存活队友接替，对方存活选手通过 -1 哨兵保留，最后一名队员败北沿用既有结算。

旧客户端的 C2S112 首次申请入口继续兼容。默认自动开局接受客户端的选人就绪通知；不使用开局通知之后的固定延时猜测地图加载是否完成。
