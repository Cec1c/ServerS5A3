# 普通假面骑士模型与默认团本页

普通入口 NPC 20491 与团本任务 NPC 20315 使用独立定义。普通入口只提供 `[select channel window]`，团本创建、商店和任务目标保持在原定义；活动2449、任务8641及原生频道资格检查继续执行。

普通定义应位于 `npc/` 根目录，使用与原定义相同的 `Animation/GContents/20180619_Fiendwar/Mask_knight.ani` 引用。若把原定义复制到 `npc/custom/`，按文件目录解析的动画路径会变成不存在的 `npc/custom/animation/...`。只查 `npc/animation/...` 存在，不能证明子目录 NPC 的资源闭包。将定义映射回根目录，同时保留模型和地图坐标，可使固定NPC根和相对文件目录两种解析都落到已有动画。原始IMG的16个引用帧可解码；真人画面仍须验收。

v146 的原生 role0xA3 添加命令0xC2，点击固定调用窗口0x42F，参数为(0,2)。原生打开函数将2减一选tab1，因此打开特殊区域；PVF参数本身原先不会被读取。`patch_npc_raid_tab_v147.py` 仅接受精确v146摘要和C2指令指纹，复用原生角色整数getter读取0xA3：值3传原生参数3，其他值保持原参数2。配套普通20491使用值3；露德米拉等既有零值入口保持特殊区域。

原生窗口继续执行tab选择、状态存储和刷新。值3沿原生非2分支检查安图恩/卢克/超时空活动及前置资格，没有强制启用tab、伪造任务完成或绕过频道准入。补丁只修改C2入口、PE节头/校验和并追加46字节代码，保留原协议接收位及活动窗口补丁。

`verify_npc_raid_tab_v147.py` 用实际候选指令回放C2与014177BD选择/存储及014177E4分支，覆盖0、1、2、3、4、-1及最大有符号整数，检查窗口参数、ESI和栈平衡；原v146对值3仍选特殊页作为基线。角色getter契约、窗口管理器和tab控件是夹具。此验证不是完整UI或真人登录验收。私有配套与签名更新另记，不附游戏资产到源码MR；公开Release仍待用户验收。
