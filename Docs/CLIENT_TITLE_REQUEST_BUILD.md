# 称号请求 OP19 标记

原构建说明对应 `scripts/client/title-request`。以下保留该工具的基线说明；称号入口的后续修复另见 `Docs/TITLE_REQUEST_RETURN_RETEST_20261025.md`。

该工具为 ADD07 生成精确输入、完全离线的原生候选；不部署、不安装，也不检查运行中的进程。

固定基线：

```text
SHA256 e5751354901fc142324d11cfc717e4a958396877f1c0fc545f51645f8e77af55
111910912 bytes
```

既有 `.op19ui` 节从 `0x6E95000` 开始。当前简单白名单为 `0x2499E10`、`0x249A344`、`0x249A3DF`、`0x249A455`；两个额外路径需要原生栈认证。已识别的未变化装备请求在 `0x6E951C6` 发出标记 2；其他调用者回退在 `0x6E95052` 使用标记 0。

称号专用生产者的返回地址为 `0x12A3474`、`0x12AB194`、`0x12ACB2B`、`0x12ACB78` 和 `0x12AF918`。它们所在的事件路径由离线分析保存到证据目录。候选只扩展 `0x6E95050` 的回退，并精确匹配这些返回值、目标槽位 13、计数 1 及已知且带帧指针的父返回地址。不同返回、槽位、计数或父地址均落到未修改的 `push 0`，因此登录/装备重放不会被全局标记。

`run_all.py` 执行静态分析、构建候选，并对两个映像运行有界 Unicorn ABI 用例。构建要求 Windows、Unicorn 2.x、Capstone、至少 3 GiB 可用物理内存及精确基线摘要。`title_extension.title_extension(extension_va)` 与 `title_extension.fallback_redirect(extension_va)` 是供主玩法刷新构建器直接组合的独立入口。

生成的二进制、日志和原始反汇编只进入调用方指定的独立工作目录。离线 ABI 结果不代表具体游戏版本已发布、安装或通过完整原生界面验收。
