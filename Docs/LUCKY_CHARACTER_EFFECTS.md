# 幸运角色掉落与疲劳加速

活动 1054 沿用现有开关、职业及日期资格。技能等级加成由客户端原生读取 PVF 处理，服务端不再叠加技能等级。现有击杀、通关、任务和组队通关经验规则保持。

## 配置与生效范围

- 匹配 PVF 中的旧标签 `[private new characters only] 1` 兼容为 1～89 级范围：活动 1054 开启后，范围内新旧普通角色均有资格，不再读取历史新角色标记或要求预约报名。已有角色重新选角即可投影；达到 90 级立即清除状态和后续经验/掉落/疲劳燃烧效果。客户端及 PVF 无需更换，旧角色数据无需批量补标记；新角色继续写历史标记仅用于旧版回退兼容。特殊频道、极限角色和决斗专用角色限制保持。
- `etc/chn_activatecharacter.etc` 的 `[unique drop ratio]`：普通装备掉落的神器档权重加成；当前 PVF 为 50%，即原神器概率乘 1.5，并非额外 50 个百分点。不增加传说、史诗、固定物品或深渊独立奖励概率。
- 与大富翁神器加成按原始权重相加，组队每人按自己的角色资格独立计算。
- 同文件的 `[fatigue accel percent]`：疲劳燃烧增加的基础击杀/通关经验比例；当前为 100%。不加成任务经验，也不将其他经验增益再翻倍。
- `etc/chn_fatigueaccelchkdungeon.etc` 的 `[unable dungeon]`：禁止疲劳加速的副本列表；当前为 3557。缺失、非整数或非正数配置拒绝加载，不静默忽略。

## 疲劳加速规则

按角色保存勾选值 `fatigue_acceleration`，每次成功选择角色时重置为 0，必须重新手动勾选。本次登录内的过图、进出地下城、状态通知及每日疲劳刷新不重置选择；562 请求仅保存开关，不立即扣费。普通房间开启且余额至少 2 点时扣 2 点，成功提交后记录本房间燃烧比例。周期入场复用同一规则，并与原门票及次数同事务提交；回滚或房间重访不重复扣费。

本房间已支付的燃烧资格固定，切换勾选从下一次房间扣费生效；通关重试沿用已提交的经验和展示。最后仅剩 1 点按普通 1 点扣除、无燃烧增益；零疲劳不制造额外经验。无疲劳副本、PVF 禁用副本和公会定额入场规则不加倍。

上述末点及房间规则是该服务端实现政策；原生协议取证确认报文与开关状态，不能据此称完整复原了历史所有边界行为。
