# 再次挑战被拒后保留已通关副本的回城上下文

普通副本和裂缝结算页再次挑战会先卸载旧副本，再经过正式入场校验。旧返回上下文仅为团本登记，因此无疲劳或次数耗尽等拒绝发生后，普通副本的旧运行记录无法恢复，后续结算页回城或系统菜单回城找不到已通关记录。

返回上下文扩展到普通单人及组队已通关副本。单人要求同一运行记录，组队要求共享副本实例，团本继续要求同一实例和运行标识。新入场未提交时仅恢复确实已退休的记录；已进入新副本、已经回城、角色代际改变、失去认证、频道或账号改变时不恢复。成功重试保留新副本，准入、拒绝码、奖励和资产事务不变。

两条正式入口回归在旧代码失败：无疲劳再次挑战被拒后运行记录为空；裂缝次数耗尽同样丢失运行记录。修复后分别保留旧运行记录，再走系统菜单回城或结算页回城，均发送现有 op24。测试比较疲劳、金币、背包和每日次数未变化。另测普通队伍双方恢复到同一实例，以及旧上下文不能覆盖新运行记录、切换后的角色或频道、失去认证的会话。

地图与内存仓库使用隔离流程夹具；裂缝夹具走正式每日次数门，不代表实际关卡、战斗、掉落或原生客户端验收。真实资源及游戏验收分别记录。本修复不新增主线剧情行为，不需要修改客户端或PVF。
