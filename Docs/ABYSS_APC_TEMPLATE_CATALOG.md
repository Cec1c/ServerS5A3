# 深渊 APC 模板目录校验

深渊波次生成器将 APC 产为 Type 5，但追加隐藏模板时旧实现对所有条目查询 monster.lst。当前资源的合法 APC 仅在 AICharacter.lst 中，因此已经扣票并清空源房间后，目标房间预检仍拒绝过门。

仅将 Type 5 的定义校验改为 AICharacter 目录；其余类型保留怪物目录规则。缺目录、缺定义或解析失败仍返回错误，实际运行房间在完整目标预检成功之后提交。邻接、清房、请求形状、身份、扣票、对象编号、隐藏波次顺序均沿用原实现。

回归的真实资源入口为 DNFBRIDGE_ABYSS_DOOR_PVF 与 DNFBRIDGE_ABYSS_DOOR_CHANNEL；都为空时显式跳过真实路线，显式选择不完整或错误输入失败。另有不依赖私有资源的目录边界测试。PVF 摘要匹配当前配套，频道需含合法17；输出路径 R145_OUT 可选，默认测试临时目录。

工业基地、寂静城的同一冻结路线在旧实现因 APC 定义查错目录而失败；地轨中心普通怪物波次作对照。候选验证合法扣票、逐房清怪和过门、隐藏行及679顺序、缺依赖拒绝时房间及库存不变、同房重放不重复扣票。鲁夫悬空海港、时空之门仅取得资源证据，没有完整入口验证。

用户实机验收：完成深渊资格且门票充足的角色分别进入工业基地、寂静城深渊，清怪后走向深渊房间，检查能否正常过门、载图并移动；另用地轨中心对照。记录具体副本、角色与时间。当前交付修复已证实的服务端过门拒绝，原生 APC 对象生命周期、整场深渊清理及奖励仍待游戏内验证。
