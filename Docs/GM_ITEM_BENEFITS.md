# 全服物品邮件与新角色福利

GM → 测试福利 → 全服物品邮件。填写物品 ID、数量、邮件标题和正文，独立 GM 从匹配的 PVF 核对物品并显示名称。每条规则一种物品；装备每封限一件。需要其他物品可建立另一条规则，无需改代码。

1. 点击“校验物品并保存停用规则”。保存不会发邮件。
2. 核对物品名称、数量和自动发放选项，确认启用规则。
3. 点击“预览现有角色／补发”，核对已发、待补发和收件名单，再确认发放。
4. 后续补发继续使用同一规则。可刷新记录、继续中断批次或重试失败角色；新建另一条规则属于独立的一次福利，会再次发放。

去重单位是“规则 + 角色”，不是账号。同账号的多个角色可各收一封；领取、删除邮件和服务重启不会清空发放记录。角色重新创建属于新角色。邮件和去重记录在同一账号／角色／邮箱事务中提交，手动补发与自动发放并发也不会重复。

勾选“后续新角色自动发放”后，首次启用时间之后创建的角色由独立 GM 后台定时扫描并发放。已有角色必须手动预览补发。暂停后不开始新发放；重新启用保留原首次启用时间和记录，暂停期间创建的角色可在后续扫描时补领。暂时失败会在后续扫描时重试。无需保持浏览器打开，也不依赖角色进城；游戏内可能需要重开邮箱查看。

规则内容保存后固定，启停不会改变奖励。预览冻结当时的角色名单，每次请求最多处理十个待发角色；页面自动继续，最近二十批可查看结果。新预览会查询永久记录并跳过已有发放；自动发放的记录也可通过重新预览核对。首版完整预览最多一千个账号、五千个角色，超出时明确拒绝，避免静默漏发。

物品的职业、期限和使用限制仍由当前 PVF 及既有物品逻辑决定。直接指定 ID 不会修改礼盒内容、解除职业限制或把它变为永久道具。在线玩家可重新打开邮箱，必要时重新登录；实际领取和开启效果需要在对应客户端验收。

首次迁移见 [独立 GM 服务](GM_STANDALONE.md)。完成迁移后，本功能随独立 GM 部署；既有政策、金币批次和账号记录保留。部署本身不创建规则、不启用自动福利、不发放真实物品。保持管理鉴权，玩家公开网关不开放这些管理接口。
