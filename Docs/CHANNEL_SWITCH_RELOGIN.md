# 频道切换与重新登录修复

普通频道换线和选角色进入游戏，使用当前城镇的赛丽亚房间。城镇共用房间地图时，按真实 PVF 房门确定目标，继续保存所属城镇及出房来源，避免统一回到艾尔文防线。已有的登录位置策略开关继续生效。

## 普通换线

角色绑定完成后，在场景激活之前同步房间位置。`official-24.9` 的普通手动换线会先准备完整初始化报文，再连续写出已编码字节流，缩短街道先出现、随后进入房间的窗口。

报文内容、顺序、序号和保护层编码沿用现有路径；不替换连接对象。准备失败、取消、超过 8 MiB 或短写时结束连接，避免继续使用已经推进的编码状态。共享背包的发送证据只在实际写出成功后登记。

## 特殊频道重登

当前客户端接受第一次 LOGIN 成功后，会跳过后续成功应答中的类型读取。仅在角色列表前补发第二次成功，不能保证清除帝国玩法界面。

本次在已验证账号的首次 LOGIN 成功之前完成普通频道更正，再对目标 CHANNELINFO 引出的 LOGIN 请求发送唯一成功应答。频道、端口和城镇 owner 使用同一目标，之后仍等待客户端的真实角色列表请求。账号不匹配、旧选角请求和重复 LOGIN 不能越过等待状态。

普通目标优先采用有效的普通来源和频道目录 resident，不为本机目录写死频道编号。进行中团本仅保留本账号、同频道、同实例、有效期内的真实断线席位；选角时仍核对具体角色。决斗既有登录路径保持。

## 主动换线与帝国返回

已认证且已选角色的旧连接收到 EXIT 时，登记 30 秒、单次消费的换线交接。交接由账号和已验证启动器令牌的摘要隔离，仅用于区分流程，不替代认证；不记录令牌或其摘要。EXIT 应答写失败会撤销对应记录。

交接在目标频道解析、CHANNELINFO 或首次 LOGIN 应答写出失败时恢复，前提是仍在有效期内且没有新 EXIT 记录；恢复后仍只允许成功消费一次，供同账号、同启动器令牌的快速重连重试。

有有效交接时保留主动选择的特殊频道。帝国退出后再次连接同一帝国频道，则按返回城镇流程恢复此前普通来源。现用 EXIT 没有目标字段，所以同一帝国频道的其它主动重连也适用此规则，尚不能证明已区分全部 UI 操作。

帝国的必要城镇入口从真实 PVF 的城镇、地图和 gate 解析，并检查区域条件。本次不包含帝国组队、每日名单或战斗实现，也不附带本机频道目录、客户端和部署配置。
