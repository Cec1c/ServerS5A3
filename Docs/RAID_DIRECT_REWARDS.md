# 团本结算直接奖励

团本奖励计划冻结前递归展开随机容器，让普通安徒恩、卢克、超时空及单人安徒恩/卢克直接获得最终材料、卡片和随机装备。例如，参考 PVF 的固定零抽样中，奖励源 `10304483` 产生 `10093974 × 20` 和 `100050518 × 1`，翻牌和持久化均使用这份冻结结果。

`[booster selection]` 自选礼盒仍作为物品发放，保留玩家的选择。已有背包礼盒、普通开盒入口、PVF 概率权重、客户端和数据库结构不在修改范围内。

## 实现边界

- `raid_reward_expand.go` 复用现有 PVF 解析器及权重抽样，递归展开 `[booster]`、`[booster random]`、`[cera booster]`、`[upgradable legacy]` 和 `[random upgradable legacy]`。多份同一随机盒分别抽取，最终同物品数量汇总。
- `raid_reward_grant.go` 在冻结计划前调用统一解析入口，入场依赖检查遍历所有可达正权重分支。既有发奖事务、指纹、收据、账号共享存储和溢出邮件保留；重试沿用冻结产物。
- `raid_single_rewards.go` 在保留单人奖励源、奖励池、标志及补偿盒限制的基础上复用统一入口；单人卢克沿用现有调用链。
- 循环、缺失物品、无效数量及需材料或金币费用的随机包装均返回错误。递归深度上限为 16，解析遍历上限为 4096，最终奖励最多 255 行，每项总数不超过 65535。
