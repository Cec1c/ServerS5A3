# R170 超时空自动临战编队

本轮依据操作者明确规则修正：攻坚队的1～8号是个人席位；玩家不能自行建立、邀请或加入小队。进入战斗副本前同一地图的玩家构成此次临时队伍，通关返回后解散，下次战斗重新计算。

## 入口边界

`official-24.9`、频道类型42的手动建队、直接入队、目录入队和快速组队请求不再进入普通队伍管理器。邀请模式0/12在等待区也被拒绝；op10失败保留客户端要求的第三字节mode。旧邀请接受不能新建队伍。普通入队原语和代发邀请入口同步限制，其他频道和交易模式保留。

已由自动入战冻结的同一遭遇战成员，重复消息只恢复原有名单和模型，不新建、合并或重排成员；不能用它吸收其他区域或其他run的角色。恢复包不重播peer握手。

## 自动准入

自动准入依据确认移动的来源区域，不能把来源和目标两个区域的人数相加。准入竞争必须在修改中央小队之前处理，失败请求不能删除另一请求已建立的小队。个人攻坚编号不由临时小队的leader/slot反向改写。

R169已补确认回城解散临时小队、旧返回不能删除新队伍、未提交进图按本次Enter前后像回滚；R170补手动入口与自动名单来源的边界。

## 验证和部署

本轮测试结果以R170检查点为准，R169通过结果不覆盖R170。必须覆盖：等待区手动建队拒绝、旧邀请拒绝、同区域自动入战、其他区域不被拉入、两请求竞争、通关解散/重入、普通频道对照。
