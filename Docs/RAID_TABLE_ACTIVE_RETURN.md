# 活动安徒恩战况表返回城镇

当前客户端安徒恩战况表的返回按钮在活动副本发送op72，正文0102。服务端此前将它仅按结果页动作处理，因尚未完成结算而拒绝。现在仅在当前角色确实属于同一合法活动安徒恩run且已落位时，将该精确请求转入原有主动退场流程；不生成结算或奖励，不改变已完成副本的结果和免费牌屏障。

准入保留版本、当前runtime、认证账号/角色代次、频道、攻坚实例/phase/attempt/run、地图/参与者和Participation检查。入场与表内返回共用同锁校验体，等待城镇确认时再次核owner。成功ACK为class1/72正文010102，再走已有typed24；ACK失败不记成功，24失败可续办且不重ACK。显式成员退出沿既有离队流程，同伴run不被主动退场。

真实资源回归包含合法入场及实际请求、42退场对照、重复请求、错误归属/动作/长度、ACK与24写失败、确认前阶段变化及队员正例。累计保留完成raid和普通牌面前的旧门回归；公开独立适配其原有请求ID/ACK记账，没有搬入其他累计业务。目标测试需设置DNFBRIDGE_REAL_PVF_SMOKE；未设置时由既有真实资源helper明确跳过，不能把默认skip算作实际目标通过。

匹配v150的原始sender/ACK切片证明该请求和消费字段，但控件状态、UI叶子、完整actor生命周期和真实网络尚未执行。现场需在合法活动安徒恩副本打开战况表点返回，核对本人退场、同伴继续战斗、重复点击和再次入图；记录角色/地图/时间与实际运行版本。卢克、超时空按钮及已失效阶段不纳入本新增分支。
