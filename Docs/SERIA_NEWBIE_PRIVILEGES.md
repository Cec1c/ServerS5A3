# 赛丽亚新冒险家特权

沿用活动开关 1370、原生 1369/304 状态与 1429/1430 引导/领奖，不新增协议或 PVF 补丁；客户端需已开放这些既有接收位。1369 用户类型 0 为新手，1 至 5 为回归，6 为不参与；历史未记录类型的回归状态继续投影为 5，不能被迁移成新手。

仅在认证登录首次补建账号档案、账号没有历史角色且活动已开启时标记待进入资格。已有账号、历史角色迁移后补档、非认证会话不标记。首次成功选角的场景准备在原账号/角色/邮件事务中消费标记，开始 30 天资格。首次标记和开始记录均持久化，换角、重登、删除角色不会重新获得新手周期。旧账号不自动补发。新手过期后仍可按原七天离线规则获得新的回归周期；同一时期只绑定一组任务。

任务与邮件读取 `etc/seriawelcome.etc` 的 group0：任务 40 至 46 及 17 至 19，签到 26 至 32。新手等级条件按权威角色等级达到 PVF 指定等级判断，转职按权威 `grow_type` 分支判断；学习、分解、无色技能和城镇访问沿用原成功事务计数。签到沿用账号 06 点服务日、七次签到和事务邮件，重复请求不重复发奖。新手与回归使用不同身份字段，报文入口对两种有效资格开放。

当前欢迎经验加成沿用既有活动策略百分比；其他静态特权说明不据此承诺全部战斗权益已实现。源码专项、真实 PVF、原生状态、安装和实机验收分别记录。活动控制名称更新为“赛丽亚的热忱（新手/回归）”，已有 1370 开关值保留。
