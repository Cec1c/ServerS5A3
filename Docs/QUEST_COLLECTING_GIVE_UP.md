# 收集任务放弃与物品回收

允许放弃的收集任务可能声明任务专用掉落。旧无资产路径在看到这些声明后统一返回需要物品事务，导致即使持有量为零也不能放弃。任务 4099「紫色念气的气息」是一个实际资源回归案例：seeking 4730×12，允许放弃，并声明怪物掉落 4730；该物品类型是 quest。

新增路径仅接收完整 seeking 物品/数量对、无接取赠予、所有声明掉落都属于收集目标的任务；每项物品必须由当前 PVF 证明为 quest 或 material。普通材料保留。任务物品回收超出其他活动任务最大需求的部分，其他任务的接取赠予需求同样参与保留计算。未知活动任务定义、未支持的物品类型或回收边界拒绝执行。

回收与删除 States/Progress 中该任务使用同一角色结算事务，绑定角色与账号，任何阶段失败都不返回成功结果。不会发任务奖励或改变完成历史、其他任务、普通材料。零持有量仍需确认任务状态并在事务内删除，不需要伪造完成条件。当前 no-asset 路径及不允许放弃的资源约束保持。

提交后先发送确切的槽位更新，再返回既有 op32 成功格式；同一会话重复请求保持已有去重逻辑。网络断线与数据库提交不是同一原子事务，发送失败按现有连接错误处理，重新登录读取持久任务/库存，不重做回收。

本地 Linux 验证覆盖：真实 PVF 4099 持有 0/5/12/36 个道具、精确物品更新和 ACK 顺序、重复请求、旧普通材料任务；20 个领域场景包含22项活动任务、多任务/多栈保留、账号不符、资源不完整、禁止放弃、库存保存失败、库存暂存后任务保存失败、提交前失败及回滚。

扩展任务包回归在本次使用的累计 PVF 下存在三项完成券/3971任务链失败，已在未修改的相同基线复现。此文不宣称完整任务包全绿，不把本地候选视为部署或实机验收。激活赠予和其他任务类型的回收不在本次新增路径内。
