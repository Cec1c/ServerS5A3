# 疲劳药的日次数与冷却

06点按服务日刷新疲劳额度和显式每日使用次数，冷却使用实际经过的毫秒数。原实现两处在日切换时清除最后使用时间，并把22小时及以上冷却替换为每日一次，分别导致跨06点提前可用和冷却到期后仍被拒绝。

修复保留最后使用时间，只采用PVF明确声明的每日次数，对所有正cool time检查实际间隔。例如10005098仍是每日3次加10小时冷却；10005187保留22小时冷却，不额外添加每日次数。其他同名品种按各自资源处理。

真实资源完整515/action58回归覆盖跨日、冷却到期前1毫秒与精确到期、满22小时同服务日、显式daily3、扣除最后一件、旧RawEntry数量覆盖、冷会话读取、归属和保存失败回滚。堆叠数、每日剩余次数与冷却遮罩不是同一个值；本补丁不把尚未复现的数量/UI问题改称已修复。

旧版本已清掉的历史使用时间无法从当前记录恢复，不猜测回填或改玩家数据。实机应核对准确品种、使用时间、使用前后库存与重登状态；原生数量显示与冷却UI仍单独验收。
