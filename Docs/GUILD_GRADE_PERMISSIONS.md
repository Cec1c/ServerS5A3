# 公会职位权限编辑

op748 修改一个职位的权限掩码。它不调整成员职位；op749 的职位名称编辑另行处理。

## 请求与规则

- class1 请求严格为 `u8 grade + u32 permissionMask`，共5字节；目标职位为2～5，掩码限定既有18位范围。
- 仅当前会长可编辑：同时核对事务内账号归属、成员grade1和公会记录的会长角色ID。普通成员或副会长即使具有全部权限位，也不能编辑职位定义。
- 在既有公会事务中保存，显式零掩码可撤销副会长默认权限；相同掩码不改变时间戳。成员职位、其他职位定义和角色资产保持原值。
- 成功先回复状态，再重读并向当前同会成员刷新NOTI70中的六组职位掩码/名称；复用会话代次、账号归属和逐个成员预约，避免换角或重连收到旧投影。
- 非法字段返回48，无权限返回36，无有效公会身份或保存失败返回34。失败不发送成功刷新。
