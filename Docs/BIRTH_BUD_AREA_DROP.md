# 诞生之芽区域材料掉落

诞生之芽（10161610）的现用物品说明为魔界地下城产出，但没有普通生成率，怪物材料项及独立/世界表也没有该来源。本次参考90CN轮回源码，在现有怪物模板材料池接入区域材料，不修改PVF。

这些图中走普通杀怪掉落流程的小怪、精英和领主，均将诞生之芽以权重100加入原材料池。每次先过1000/10000（10%）外层判定，再按池内权重抽取一项，每次产出1个。仅有诞生之芽时为10%；若怪物模板还有其它材料，则为10%乘以100除以材料总权重。它不是领主保底，不随难度、成长契约提高概率。

316专用魔界裂缝、317任务专用图、训练场和团本等范围外副本没有新增来源。六图的常规怪物按上述材料池处理，深渊恶魔或专用裂缝首领保留各自的奖励流程。

## 实现及验收边界

条目在随机判定前沿现有PVF目录校验；正常生成地面物品，复用角色归属、拾取事务和死亡/拾取重放保护，不直接发进背包。增加中文区域材料判定日志，以便区分未命中和拾取失败。

仅在这六图的材料池接入新来源。已有金币、装备、独立卡片及邀请函/挑战书表的概率与判定实现保持原值；加入区域材料会按轮回实现消耗该材料池所需随机数。测试分别核对范围、共享外层判定和权重、非目标副本随机流、真实PVF及拾取去重。源码验证不代表已安装或游戏实测。
