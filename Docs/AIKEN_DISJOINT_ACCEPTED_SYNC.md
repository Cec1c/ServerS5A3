# 艾肯分解产物过滤

线上已验收的修复补同步到权威源码。`etc/customability/individualcustominfo.etc` 定义自定义能力类型与 `[disjoint disable item]`，装备的 `[custom ability type]` 决定应用哪一组禁用产物。匹配资源中的艾肯类型为 `warriors dungeon`，禁用传说灵魂 `10099775`；生产代码读取配置，不按所有传说稀有度统一删除灵魂。

过滤位于单件、op26批量及原生连续NPC分解共同使用的产物解析器之后，复用原不可变配置缓存。普通传说产灵魂、晶体/其它材料、账号灵魂仓库与批量原子事务保持。缺失自定义能力配置时普通装备继续可分解；艾肯缺表或配置畸形时在资产变更前拒绝。

回归覆盖艾肯与普通传说单件、混合批量、错误规则零资产变更、普通夹具无可选表，以及非艾肯自定义能力。真实资源回归通过环境变量 `DNFBRIDGE_AIKEN_REAL_PVF_SMOKE` 指向已匹配PVF，检查31件艾肯和普通传说对照及实际分解事务；不上传PVF或本服配置。

本提交不含EXE、GM、数据库状态或其它私有累计修复。线上功能验收、此次公开源码验证与合并分别留证；此次源码同步无需重新部署线上。
