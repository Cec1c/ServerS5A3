# 黑暗武士 PK 连招与独立技能页

PK 学习、重置和普通快捷栏使用 `pvp_dojo_skills_v1` 独立加点。黑暗武士的 op508 保存、op510 自动排列及 op447 初始化也必须使用相同仓储视图；否则仅在 PK 学习的技能会被刷图存档判为未学习，保存失败后又恢复旧连招。

`skillcmd.DojoRepositories` 的设置视图将当前角色的 `dark_knight_combo` 精确映射到 `pvp_dark_knight_combo_v1`，结算事务内使用同一映射。刷图继续使用原有命名空间。首次准备 PK 技能时，在角色结算事务中将旧连招复制为起点；已存在的 PK 连招（包括主动清空的列）不会被再次复制覆盖。旧记录尚不存在时，仍由既有 PVF 根技能初始化流程补全。

选角预加载只读已存在的对应频道连招，不提前创建角色数据；选角后的初始化补齐缺失页。保存按当前 PK 技能页校验，失败恢复、重置及角色状态刷新都使用同一 PK 存档。PK 与刷图技能点、另一页、冷却和连招顺序保留各自边界。

角色结算设置权限仅新增当前角色的精确 PK 连招键；没有扩大为前缀或任意设置访问。不新增数据库表，不需要改 EXE、PVF 或 GM。

本机验证使用 `skillcmd`、`darkknightcombo` 和仓储包测试，并构建 Linux 服务端；按本次要求不执行 dnfbridge 测试。真实 PK 内拖动、自动排列、重登及往返频道验收待部署后完成。
