# 异次元裂缝和艾肯每日入场次数

当前official-24.9按PVF标记决定次数池。`worldmap/DimensionGate.wdm`区域13的7100及7165—7179声明`[dimension dungeon]`，共享该角色同一服务日的累计已用次数；不能将316魔界裂缝的独立次数规则套入。

基础额度取`etc/dimensiongate.etc`的5+0。`etc/dungeonetc/dimensiondungeoninfo.etc`中的日上限10和追加上限5是累计上限，不是免费次数。追加量从真实券的动作参数读取；旧记录没有追加字段视为0，成功入场与用券都在06:00 UTC+8服务日口径下更新。

准入先检查可用额度，最终进入时在同一个`WithinCharacterAssets`事务中重新检查并提交次数、要求消耗的门票和入场房间疲劳。配置错误、最后一次额度被另一会话占用或保存失败时整轮回滚，不能留下先扣的疲劳或门票。

艾肯沿用`etc/dungeoncyclesystem.etc`的副本周期配置：5097/5098及3570/3571各自声明次数。桥层既有的周期事务不改为异次元共享池，门票与疲劳同批提交；成功后才发背包槽位刷新。

2026-10-19使用当前a56资源重新验证入场链和失败回滚。追加券原生515/156入口及材料槽位投影见`DIMENSION_EXTRA_NATIVE_V141_20261019.md`。次数UI仍独立待验，当前客户端812不是次数通知，本实现不发送猜测包；隐藏BOSS、碎片掉落、升级及其它奖励目标另行处理。
