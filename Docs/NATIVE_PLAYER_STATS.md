# 本机原生账号统计接入

小悦入口的一期目标是复用现用客户端的原生弹窗、按钮和文字控件，显示当前账号的今日、本周、累计五项统计及角色贡献。游戏原有计数和采集事务继续沿用，新增接口只读；战令、领奖和排行榜另行接线。

## 账号与读取范围

只读接口挂在既有本机回环管理监听上，由真实连接的对端进程信息、进程启动状态、启动器确认及当前游戏角色会话共同识别账号。它不接受账号、角色或进程 ID 参数，也不向客户端分发管理凭据。连接身份存在歧义、过期、进程标识复用、未确认会话或查询中角色变化时拒绝；其他平台关闭这一识别入口。

默认 JSON 供接口诊断；`native-v1` 为本机客户端扩展提供有界二进制快照。它是本机 HTTP 适配格式，不属于 DNF 游戏协议，不新增或开放游戏接收编号。请求限制回环地址及 Host/Origin，返回禁止缓存；每次打开或手动刷新读取三组账号汇总和一次角色名单，没有全服扫描或定时清零。

周期沿用北京时间 06 点服务日，周一 06 点至下周一 06 点为一周。五项顺序为实际疲劳消耗、深渊完成、史诗拾取、粉装拾取、传说拾取。账号汇总保留已删除角色贡献，明细标识历史角色；当前角色仍须属于已确认账号。角色和数字不从客户端请求自报。

## 原生客户端契约

本机扩展按现用 EXE、PVF 和网页内核完整摘要及关键函数字节核对，版本不符拒绝加载。原生弹窗使用独立空闲窗口槽，构造时复用现有 XML 解析和窗口工厂，两个临时 `CALL` 在构造结束立即恢复；已有窗口缓存不覆盖。

扩展使用原生文本改字接口显示真实快照；三个周期页签、每页七个角色、前后翻页、刷新和关闭都由原生控件完成。数据读取在工作线程执行，UI 线程只处理结果和原生控件。关闭、重开、请求代际及失败均清除旧快照，身份不明时不显示其他账号或兜底数据。

小悦接入使用现有网页内核的导航拦截接口，只匹配已取证的小悦主框架原地址，将其转入原生统计；其他导航委托原拦截器。设置拦截器只替换指针、不释放旧对象的行为已按当前内核核对，URL/`WebString` 与三种回调 ABI 另在隔离进程验证。

该版本针对本机 Windows 单账号测试环境。跨机器部署需要独立的游戏身份交接设计，不能把本机进程识别接口直接当成远程玩家认证。

## 历史验证范围

源侧专项覆盖身份隔离、进程标识复用、实际连接所属进程、服务日/周界、历史角色、跨账号角色拒绝、查询中角色变化、只读限制，以及 UTF-8 与 int64 适配。原生解析另覆盖样本截断、非法 UTF-8、负计数、过大响应和尾部垃圾。上述记录不代表本次重新执行、安装或实机验收。
