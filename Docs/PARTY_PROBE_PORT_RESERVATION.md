# 组队中继探测端口保留

当前embedded中继可把probe端口配置在定向腿端口池内。旧分配器绑定失败后会关闭该probe socket并把同端口分配给定向腿。两名同公网IP合法客户端继续发送原有00/01保活时，都能通过该腿的IP校验，较后的保活会覆盖owner端点，反向负载可能回送给自己。

新分配器跳过启用探针集合的有效配置口和实际绑定口；集合在构造时发布后不变，probe绑定失败或被显式关闭也不转为腿口。关闭probe功能时不保留额外端口。配置范围不扩大：64口中一个probe使腿容量为63，完整拓扑不足时沿用整组失败回落，不发布半套中继。

业务只修改分配与监听集合两处。IP检查、负载/首包处理、扇出、SEED/REPLAY、via-port及既有通告保持。合法客户端持续保活的红绿证据不代表已定位10.18具体角色现场的唯一原因；同IP身份认证和全局扇出其他已知边界没有在此补丁解决。

回归覆盖完整op2注册/邀请/接受、同IP不同端口及NAT重映射、持续00/01保活后双向负载与来源腿口、第三成员、重连代次、多队重建、多probe/池外/关闭/via-port、精确容量和耗尽原子回落。测试连续范围逐口探测并在分块内持有租约，仍不能阻止不遵循测试租约的外部进程争口。

实机验收需要候选上线后，用同一路由器两人组队、持续停留并移动/进入副本；对照不同公网IP、第三人加入、解散重建和断线重连。检查双方都能看到对方动作，非队员不混入，失败时不出现半套中继。自动UDP验证与原生游戏验收分别记录。
