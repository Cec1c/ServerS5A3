# 帝国设队名单的远程换频道交接

远程客户端的服务端会话没有本机进程号。原缓存只接受非零 PID，普通选角已经发送的紧凑名单在切换帝国频道后无法继承。1467 请求能到达，但因缺少已发名单而不回复 1403，客户端继续等待，Tab 和右侧队伍设置均无窗口。

缓存现在使用现有 LOGIN 验证后建立的登录流程摘要、账号和内部服务器号作为身份。同一已认证登录流程跨 TCP 连接保留原 op2 顺序；新登录、不同账号或区服、无验证摘要和已撤销连接不能取得这份名单。无令牌的本地流程保留原 PID 隔离。摘要只用于进程内缓存键，不记录或发送令牌及摘要。

角色归属、当前角色、仓储明细和合法两人队伍校验保持。1403 仍是额外区服计数零；本区选角来自原 op2，不重新按数据库槽位排序，不自动选人或扣费。

回归以真实登录令牌绑定两条 PID 为零的连接，保留不同于 SQL 槽位的紧凑顺序，验证 1467 → 1403、1457 保存当前角色和第二名角色以及金币不变。另覆盖同 PID 不同登录、缺失/未认证摘要、撤销、账号/服务器隔离及名单失效。服务端回归与游戏窗口、实际入场分别验收。
