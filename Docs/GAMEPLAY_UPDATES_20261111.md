# 宠物、编队、强化与冒险团增量

本次公开四组常规修复，以及明确标为实验性的赛丽亚礼盒、成长券和客户端配方。功能源码、资源生成配方、成品发布与实际部署各自记录验证状态。

## 常规修复

- 宠物连续更换附魔时，同步宠物专用卡与升级别名，回包采用当前实例的新属性；摘戴后保持第二次附魔，保留宠物身份和已有资料投影规则。
- 攻坚名单及本人视角统一使用显式编队意图。未编辑的单人开战继续保持单人；新建队伍取最小空号。保留真实普通队ID、队长、固定孔槽和UDP拓扑，并拒绝旧成员修订覆盖新队伍。
- 强化、增幅药水按来源、模式和独立期限解析，同模式使用最高有效加成；按实际穿戴的宠物、称号计算加成与金币费用。补齐休亚锻造炉材料兑换及相关账号绑定保护券资源配方。
- 冒险团内容熟练度使用稳定的内容行映射，避免安徒恩、卢克及两塔的计数显示到其他行；保留历史数据。

## 实验性内容

赛丽亚新增两种50个时空石兑换50个材料的礼盒，内容分别为魔刹石和诞生之芽。只出售一种成长型装备券，售价为3个史诗灵魂、金币费用为0，账号绑定，初始+0且无异次元属性。实际启用需要配对PVF与客户端；仓库不分发完整PVF或NPK。

成长券沿用当前武器培养概率、失败处理与保护规则，当前客户端等级范围为0至31。右键通过原生选择、确认和结果流程赋予较低等级的背包装备，并在成功后消耗源券。券的实例、锁定、有效期及确认快照均由服务端复核。

+0券通过真实纯净增幅书获得异次元属性；已强化券只能通过真实纯净黄金增幅书转换，材料消耗、属性选择和等级变化沿用书本身的规则。无属性状态培养强化；有属性状态培养增幅。增幅态券使用时赋予目标装备券自身的异次元属性和增幅等级，目标无需预先已有异次元属性；数值按目标装备品级的现有PVF初始值计算。力量3、智力4、体力1、精神2。旧模板仅兼容现有实例，不再售卖，列表和培养不按旧编号改写真实属性。普通装备不追溯转换。该统一流程已由用户在本地测试服验收，但未穷举全部等级和所有旧券组合。

客户端配方在公开V212累计基线上增加成长券原生流程，按实际实例属性动态选择强化或通用增幅窗口，移除了阶段文件日志和点击采样。完整EXE以实验性预发行提供，稳定Latest保持V212。客户端与PVF配方仍标为实验性，礼盒所有背包组合、全部培养等级及网络场景没有穷举实测。

安徒恩外网首次进本全队模型缺失问题仍在调查，等待新增真实登录器日志。此次公开不将本地正常组队对照视作该问题根治，也不包含未验收的模型登记候选、本地模拟命令、禁止P2P的测试分支或网络延迟实验。
