# 技能白金徽章按基础职业系合成

## 背景

在 2018 年国服「起源」版本的普通技能白金徽章合成中，玩家普遍记录到的规则是：

- 合成结果限制为执行合成角色所属的基础职业系。
- 同系不同转职仍属于合法结果。例如男枪手角色可以合出男漫游、男机械、男枪炮等男神枪手系技能白金，而不是只出当前转职。
- 男、女分支彼此独立。男枪手与女神枪手不是同一个候选池。
- 合成材料本身来自哪个转职，不应决定结果职业系；结果由执行合成角色决定。

同时期攻略记录：

- <https://www.9game.cn/news/2179131.html>
- <https://news.17173.com/z/dnf/content/06282017/153813371.shtml>

这些资料能够支持“基础职业系限制”这一玩法结论，但没有提供足够可靠的完整官方概率表。本补丁因此只限制合法候选池，不修改原 PVF 权重，也不声称还原某个未公开的精确分布。

## 修改前：S5A3 的实际行为

达芙妮普通徽章合成使用 `op256`。服务端从输入徽章的最低 `grade` 和数量，在 `etc/emblemcompound.etc` 中选择 booster，例如当前 PVF 中两枚 `grade=4` 技能白金使用 `10095593`。

修改前，`currentRollEmblemBoosterReward` 读取 booster 的完整 `[stackable]` 奖励行，然后直接按行权重抽取：

- 没有读取执行角色的 `CharacterRecord.Job`。
- booster 行本身也没有性别或基础职业条件。
- 因此候选池包含所有职业的技能白金，可能合出与执行角色无关的基础职业系。
- 代码没有“职业识别失败或候选为空”的专门状态，因为结果池根本没有按职业建立。

结果是历史玩法预期与当前实现不一致，而不是 PVF 中某个物品 ID 单独配置错误。

## 修改后：候选池生成流程

1. 在现有账号、角色和背包资产事务内读取持久化角色记录。
2. 将角色数字 `Job` 映射到当前 PVF 的精确职业 tag。
3. 读取 booster 行对应物品的 `[enchant] / [skill levelup]` 三元组。
4. 对带技能等级效果的奖励行建立职业掩码。
5. 仅保留与执行角色基础职业匹配的技能白金。
6. 在过滤后的集合上沿用 booster 原有权重随机。
7. 普通无技能白金不套用技能职业过滤，保持原行为。
8. 角色职业无效、技能职业标签未知或过滤后没有候选时，整笔事务失败，不扣材料，不回退全职业池。

实现没有用物品名称、技能名称或当前转职推断职业系，而是使用 PVF 中已有的数值职业 tag。

## 国服历史预期与修改前行为对比

| 项目 | 2018 国服「起源」玩法预期 | 修改前 S5A3 | 本补丁 |
| --- | --- | --- | --- |
| 技能白金结果范围 | 执行角色的基础职业系 | booster 全职业奖励池 | 执行角色的基础职业系 |
| 同系不同转职 | 可出现 | 可出现，但没有边界 | 可出现 |
| 男女枪手等分支 | 独立 | 全部混在一起 | 独立 |
| 材料自身职业 | 不决定结果 | 不决定结果 | 不决定结果 |
| 候选建立顺序 | 先限定职业系再抽 | 直接全池抽 | 先过滤再按原权重抽 |
| 无技能普通白金 | 不属于本规则 | 原逻辑 | 原逻辑不变 |
| 空候选或职业无效 | 不应跨职业兜底 | 没有该保护 | 明确拒绝且不扣材料 |

## 当前 PVF 的职业映射

数字 `Job` 与 tag 映射来自仓库现有 `jobmap`：

- job 2：`[gunner]`，男神枪手系
- job 5：`[at gunner]`，女神枪手系
- job 0：`[swordman]`，男鬼剑士系
- job 11：`[at swordman]`，女鬼剑士系
- job 9：`[demonic swordman]`
- job 10：`[creator mage]`

黑暗武士和缔造者按当前 PVF 的明确职业 tag 处理，不通过名称模糊匹配。一个奖励传送门包含多个技能三元组时，只要其中存在与执行角色基础职业匹配的有效 tag，该物品即可进入对应职业的合法池。

## 权重与性别边界

过滤是在原 booster 行列表上进行：

- 保留原始行顺序。
- 保留原始行权重和重复行。
- 不将本职业池重新归一化为人为固定概率。
- 不使用“抽到外职业后重抽 N 次”，避免性能不确定和条件概率偏移。

因此，本补丁恢复的是合法候选范围，不是虚构一套新的职业内转职概率。

## 验证

新增测试覆盖：

- 男鬼剑、男枪手、女神枪手、黑暗武士、缔造者。
- 同时属于男、女基础职业系的共享技能白金。
- 普通无技能白金保持原候选。
- 空候选池和无效角色 `Job` 不扣材料。
- 未知、缺失或畸形 `[skill levelup]` 标签失败关闭。
- 使用真实 PVF 核对 16 个基础职业池，确认男女枪手候选集不同，抽查候选职业掩码。

## 不在本补丁范围

- 不修改合成材料数量、手续费、成功率或其他徽章规则。
- 不增加当前转职保底或自选技能。
- 不实现后期玲珑徽章、碎片兑换或金币转换。
- 不修改 PVF、客户端 EXE、协议或物品 ID 表。
- 不把“分解稀有时装”的相邻职业限制混入本次改动。
