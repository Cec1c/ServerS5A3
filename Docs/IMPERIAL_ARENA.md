# 帝国竞技场

## 业务范围

`tagtournament` 领域负责资源目录、账号队伍、当日付费与领奖账本、双角色回合状态、通关记录及每周挑战。`dnfbridge/tag_tournament_*` 负责现用客户端的资料投影、报文顺序、入图、切人、死亡、结果页和回城恢复。

- 普通模式支持四个普通回合和可选择的竞技之王；困难模式支持七回合。当前报文编码严格校验这两种界面结构。
- 组队设置从同账号、当前连接实际收到的角色名单选取两名符合 PVF 等级条件的角色，保存到账号元数据。休息室按需打开设置，不在每次进入频道时自动弹空窗口。
- 所有角色资料、技能页、装备、专用栏位和当日地图预检通过后，才在账号事务内收取首次费用并建立挑战。付费后的模式锁定至次日北京时间 06:00；当日免费重入同样重建完整双角色资料和初始出战状态。
- 场上只激活一名角色，备用角色由专用 Tag 协议管理。切换校验当前挑战、角色、地图、存活与冷却；每回合由当前房间的怪物死亡推进，不能通过切人或角色死亡直接完成关卡。
- 比赛中拦截换装、技能变更、队伍变更、普通消耗品及耐久扣除。六种专用道具的资源、效果单位和冷却读取 PVF，原生施法和效果仍依赖配套客户端与资源。
- 中途退出、全员死亡、通关、断线分别关闭挑战并结算已确认的进度。通关后停止计时；已领奖的重复挑战仍可改善个人最快成绩。

## PVF 与奖励

运行时读取 `etc/tagtournament/tagtournament.etc`，并交叉校验 dungeon、map、monster、stackable 和奖励字体的实际定义。费用、等级、地图池、怪物、困难阶段倍率、奖励物品/数量/权重、专用道具、切人冷却和每周挑战目标时间均从资源解析；生产代码不以测试资源中的固定数值替代配置。

每日名单使用版本化的确定性策略 `local-tag-daily-v1`：同配置、同北京时间 06:00 服务日产生相同顺序和弱点，重登不重抽。此策略不是官方历史星期轮换表。普通竞技之王没有属性弱点，困难模式另有共同物理/魔法弱点。

每日领奖额度按账号保存，当前实现只接纳已验证的每日一次配置：

| 模式 | 记录与发放 |
| --- | --- |
| 普通 | 按当日怪物记录是否领奖，按普通/特殊奖励表分组及权重生成邮件附件。 |
| 困难 | 配置表各行是该阶段的累计总额，不能把七行相加。按已领奖最高连续阶段记录，每完成新阶段即补发累计总额的差值；重复前段不重复发奖。 |

账本推进与奖励邮件在同一账号/角色/邮箱事务提交。单封邮件可包含两种材料，复用上游已有独立附件领取编号；发包失败重试不重复增加资产。已经领取过的回合不再发送奖励提示窗口。

### 每周挑战与排行

每周挑战按账号保存本周完整困难通关的最好成绩及当时两名角色的职业快照，每周四北京时间 06:00 换周。上栏显示 PVF 挑战目标，下栏显示自己的通关成绩；尚未通关不伪造成绩。

本周成绩达到 `tag tournament hard mode time attack standard rank` 的毫秒目标后，可通过 1554 领取一次邮件奖励。物品读取 `tag tournament hard mode time attack reward` 首项，期限与字体效果读取该物品定义；后三项不猜作数量或期限。现有配套资源解析为一件 14 天帝国竞技场伤害字体，这是本实现按 PVF 达标配置接入的每周奖励，不能据此推导官方历史排行奖励规则。

本贡献不含跨账号排行榜、冒险团名次、前 200 名结算、网页入口或排行榜预览页面。1396 的历史最快成绩和 1530 的个人周挑战均不代表排行榜。

## 报文与回城时序

路由限 `official-24.9`、默认游戏分类及类型 39 帝国频道；休息室位置从真实 PVF 城镇 48 的 gate 取得。常用专用报文如下，类别和正文不可仅凭编号互换：

本分支仅接入帝国专用城镇及必要的普通来源保存。通用冷登录重定向、主动换线交接和“返回频道”的重连判定由 [频道 MR !168](https://gitgud.io/16ww/servers5a3/-/merge_requests/168) 单独维护；该流程需要与帝国完整频道往返配套核对，不能把本分支的战斗/回城回归当作上述频道流程已合并或已验收。

| 方向 | 类别/编号 | 用途 |
| --- | --- | --- |
| 请求 | class1 / 1457、1467 | 保存队伍、获取当前连接可用名单及队伍。 |
| 请求 | class1 / 1458、1465、1466 | 购买入场、Tag、专用角色死亡。 |
| 通知 | class0 / 1388～1394 | 队伍、完整双角色、角色选项、技能指令、黑暗武士组合、BUFF 换装和快捷键。 |
| 通知 | class0 / 1395～1398、1402、1403 | 每日名单、通关、阶段奖励、付费领奖状态、出战角色及人数。 |
| 通知/请求 | class0 / 1530；class1 / 1554 | 13 字节个人周挑战状态；空正文领取及一字节成功应答。 |

传统与 upper 请求分发复用同一身份和状态校验。通用 15/16/45、39/117、42/72 等入口仅在本连接确有帝国挑战时转入专用处理。

回城 24 写入成功只表示传输成功。紧接着发送 1388 会重建原生双角色持有者，与旧场景销毁重叠。现在先保存归属当前角色和挑战的恢复凭据；收到真实城镇位置、队伍设置或重入请求并恢复原角色/HUD 后，再投影保存的队伍。旧角色代次被替换时清理凭据，写失败保留可重试状态。覆盖主/备用角色、中途/通关返回、打开设置及立即免费重入。

## 验证与配套边界

自动回归覆盖领域事务、归属与失败回滚、两种模式整场、初次与免费重入、角色双向切换、奖励防重、计时、周领奖以及回城时序。真实 PVF 专项通过 `DNFBRIDGE_REAL_PVF_SMOKE` 指向部署者批准的资源，只读资源并使用内存仓储/缓冲连接，不连接玩家数据库。

本机累计版本已获用户确认进图、切人及最新回城修订可用；公开上游组合的重新验证结果见本次 MR。缓冲连接测试和原生读取探针不替代 GUI、全部职业、技能效果、跨日跨周及公开玩家资源组合验收。

本贡献仅服务端业务、测试和说明，不包含客户端补丁或资源。部署前按 [客户端发布同步](CLIENT_RELEASE_SYNC.md) 核对实际 EXE 的请求、接收支持、上述正文契约及对应 PVF/NPK/dstr，完成正式发布与玩家通道验证；接收开关开放不等于功能验收。

### 外部频道目录

“前往帝国竞技场”只列出类型 39 的频道。服务端从同一份外部 `channel_info.etc` 同时生成监听端口、游戏频道广告和客户端动态下载目录；目录缺少类型 39 时，按钮不会得到可选频道，服务端也不会打开对应游戏端口。服务启动不要求所有 `official-24.9` 实例都启用帝国；只有准备或验证本功能部署时，才显式运行下面的目录预检，避免改变既有 118 条表的启动兼容性。

原批准的外部 118 条目录不含帝国行。使用 `scripts/migrate_empire_channel.py` 从该完整 ETC 生成新文件，工具插入 `[tagtournament]` 区域块和一条频道行，逐字节保留其余原条目。区域块包含当前匹配 PVF 的 `tag tournament dungeon list` 中的 320、336；先前已部署的 119 条目录虽然有 187 频道，但区域块为空，按副本号查询和客户端下载目录均无法将这两个副本关联到 187。

```text
python scripts/migrate_empire_channel.py <approved-channel.etc> <new-channel.etc>
python scripts/check_empire_channel.py <approved-channel.etc> <new-channel.etc>
```

已有空区域块的119条线上目录不能重新执行118→119迁移；用 `python scripts/check_empire_channel_update.py <current-119.etc> <candidate-119.etc>` 核对本次原位更新。它要求当前目录仍有唯一的187/type39行，并证明候选恰好只添加320和336两行；该预检不替代实际部署及客户端验收。

本次119→119发布必须保留原有119个频道端口及监听，备份并读回完整表和目录元数据；运行源标识从 `external:approved-119-empire-arena-v1` 更新到 `external:approved-119-empire-arena-pvfmap-v2`。使用审查过的BAT部署入口和最新累计源码，不能直接复制候选文件覆盖现网表。

候选行使用本地分配的频道号 187、端口 10187、类型 39 和 `[tagtournament]` 分组；显示名“帝国竞技场”来自真实 PVF94 的城镇 48 `[name]`，不是据测试代码编造的运行资源。部署生成配置仍须使用完整 ETC，不能把名称、端口或两条记录分别写进多个来源。显式预检应核对候选恰为 118 条基线加唯一审查插入、总数为 119、类型 39 行为 187/10187、区域映射为 320/336；部署和下载读回还应核对实际进程挂载文件摘要。工具输出与服务端目录查询测试只证明这份配置的映射，不代替客户端 NPC 点击、频道选择、进图或战斗实机验收。
