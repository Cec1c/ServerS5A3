# 权威穿戴复述的有期限收据

默认未启用可选登录NOOP窗口时，领域层第一条自动装备复述已经成功判为worn_slot_reassert，但桥侧缺少这个成功事实，第二条相同陈述因出现序号递增而真卸装。新增typed EquipmentMoveFact，把成功领域结果交给桥侧；只为具名worn-slot noop记录收据，失败/拒绝不记录，不依赖日志或回包是否写出。

收据绑定角色ID、选角代次、连接/场景轮次、装备槽及完整规范化陈述。第一次成功起使用既有WINDOW_MS（默认15秒、上限60秒）的固定截止，重复不滑动、过期不重开；运行时加大窗口也不延长旧截止。明确玩家tail2卸装保持，任何成功op19实际移动清新收据；REPEAT回退或WINDOW=once不建立新收据。默认NOOP仍关闭。NOOP=true时既有登录repeat账本保持原契约，其相同陈述可越过时限，不能将新收据的期限说成整个旧策略的统一上限。

完整真实PVF请求链覆盖选角、技能重建、1345、自动复述、冷连接、明确穿脱、保存失败、代次变更及其他库存移动清账。六组掌握/非掌握对照原来同样失败，证据指向复述衔接，不证明掌握技能本身导致卸装。固定输入SHA和旧候选无期限反例由外部审查记录保存。

真实资源测试默认不依赖私有文件。完整handler矩阵需同时设置DNFBRIDGE_WEAPON_RECEIPT_REAL_PVF与DNFBRIDGE_WEAPON_RECEIPT_CHANNEL；二者都空时显式Skip，选择不完整、路径错误或PVF摘要不符时失败。专属定向运行必须零skip，receipt时钟/owner单测独立执行。频道输入需为与正式配套一致且含合法17/type11的channel_info，代码不内置本机路径。
