# 强化与增幅按装备真实品质应用失败惩罚

增幅策略此前没有目标模板参数，统一用普通品质的销毁阈值覆盖所有装备。固定PVF仅为普通、高级装备声明了该额外阈值，导致其它品质在+8、+9的正常失败被错误处理为装备销毁。现在策略通过已验证的目标模板ID读取PVF装备身份和单值rarity，再选择该品质自己的阈值；缺失或无效品质、物品身份、策略行会拒绝本次尝试。

策略同时传递PenaltyValue。PVF惩罚0/1保持等级，惩罚2按声明数值减去等级并最低到0，惩罚3才进入既有保护券与销毁补偿流程。此前惩罚1被当成固定减1，惩罚2被当成不变，且数值未到达事务层。金币、材料、保护券、目标与补偿沿用原有资产事务；补偿数量公式本轮不改，仅在真实销毁时继续使用。

策略读取绑定到当时观察到的目标等级，资产事务在扣费和随机判定之前重新核对等级。策略读取失败、解析器缺失或等级变化都拒绝消耗，避免静默退回必定成功或使用陈旧策略。已配置策略的成功权重0按必定失败执行；领域内部未配置策略的旧调用夹具保持原有兼容规则，正式客户端入口必须提供策略。

固定PVF专项覆盖全部七种品质的真实装备模板。普通和高级在+8触发各自阈值，其它品质+8、+9保持原有数值惩罚；+10的销毁档不变。强化侧覆盖保持等级、减3及销毁边界。无效目标、材料身份和既有特殊NPC付款回归均保留。

正式处理器专项从实际PVF读取策略和保护券身份，覆盖+8、+9失败保留装备且不耗保护券、+10销毁档由保护券保留装备。核验资产提交、动作ACK、目标/材料/保护券的op14投影和无错误补偿。随机失败结果与金币报价使用固定夹具，仓库为隔离内存，不称为玩家报文或游戏内验收。

领域专项覆盖数值惩罚、最低0、零成功权重、缺失/失败策略、陈旧目标等级及事务晚写失败。将策略恢复为普通品质阈值、清空惩罚数值、取消等级重检，三个独立反例均应失败；原字节恢复后再运行最终验证。

该候选只改服务端源码，无客户端、PVF或玩家数据改写。公开MR、部署和实机验收分别记录，保持待验收状态。
