# 本地 Windows 测试修复交接（2026-10-13）

本次贡献基于上游 `bdd60a532c12c149becaa4a7c8e84524e4b2057c`，整理已安装测试版本的服务端改动，保留该基线的两项 NPC 商店更新。服务端域规则、桥接协议和 GM 本地账号适配随各自回归一起提交。

## 改动

- 本地注册反馈：保留可读的服务端失败原因；GM 通过 `dnf_login_accounts` 读取本地账号，稳定映射面板选择器，拒绝选择器歧义，不创建兼容旧账号表或复制密码。
- 频道下载：增加实例拥有的 `protocol.channel_script_encoding`（默认 `utf8`，可设 `gbk`）；仅转换下载脚本，不改变源配置编码。运行时配置散列绑定该选项，非法编码拒绝启动。
- 剧情与回城：免费翻牌及奖励持久化后刷新本次已完成主线；任务完成后按进行中、已完成、可接取列表的顺序发布，保留客户端主线前置索引及下一任务对话。接取仍由玩家原生请求决定。回城禁止旧副本角色状态重放。
- 任务手册与放弃：保留 `1427` 预检查、`1454` 提交及角色代次/有效期校验，调整提交后任务快照顺序；旧协议 `32` 放弃请求接入已有事务路径，保留当前职业。
- 转职入口：已转职角色不再获得新的初次转职职业奖励任务；已有任务仍展示以供正常放弃，无职业奖励的后续任务及自身觉醒仍按 PVF 判断，不迁移 NPC。
- 幸运星：按进图时等级结算，在奖励事务中写入账号钱包，避免漏发或重复发放；GM 读写同一钱包并保留其他元数据；购买后先响应实际购买数量，再发布金币绝对余额及租赁状态，保留 PVF 价格与上限。
- 金币罐：原生随机开罐识别 PVF 金币奖励项，来源罐数量和金币在同一事务内提交；发送金币奖励响应及绝对余额刷新，拒绝等级、容量或持久化失败时不扣罐，不把普通礼盒占位项当作金币。
- 结算拾取：按物品栏分类分配槽位；已装备物品不占用背包槽位。包含对应领域/桥接回归。
