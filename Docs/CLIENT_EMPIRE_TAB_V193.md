# 帝国竞技场未设队伍时的 Tab 入口

V193 在没有已设定参战角色时，两次原生角色查询返回空值，Tab 函数却先解引用队员列表的起点，之后才检查查询结果。空表触发原生迭代器检查，无法到达已有的设定队伍窗口入口。

补丁仅将两次查询的空值检查移到迭代器读取之前；缺任一角色时走原生 DA 窗口入口，两名角色齐全时保留原有流程。来源通知、已发布资料页和频道菜单等累计修改保持；不改动 CRT 错误处理、不伪造队员、不修改服务端入场条件或费用。

生成器只接受精确 V193，拒绝覆盖输入或已有输出，并验证所有未声明字节保持。测试执行真实 Tab 入口、角色查询、迭代器和退出路径；当前用户/场景查询与 UI 开关为显式夹具，双角色正常分支核对至原始继续位置，不能代替完整 GUI、组队选择和战斗验收。

运行 `DNF_EMPIRE_TAB_V193_CLIENT` 指定正式 V193 后执行 `python -m unittest -v test_empire_tab_v193`。频道名称仍需配套 GBK 下载配置；UTF-8 外部 ETC 与帝国服务端 MR !223 保持独立记录。
