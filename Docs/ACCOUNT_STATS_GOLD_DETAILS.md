# 个人统计金币明细与角色贡献排序

该客户端方案保留现有四组，在个人统计增加“金币明细”入口，显示强化、增幅、锻造、修理、附魔五类实际养成费用。账号汇总与角色贡献共用今日/本周/累计。某路径不扣金币时为零，不补造费用；NPC 买卖和玩家转账不计入养成合计。

只读投影复用原三次 `Activity.Summary`，将已经返回的金币分类保留到快照；不额外查询、不写玩家资产、不新增历史采集。class1/0x7f00 增加 12 字节 `PSQ3`，外层 `PSR1` 不变；`PSA4` 在 `PSA3` 每组八项指标之后追加强化、增幅、锻造、修理、附魔五项 int64。编码及解码核对分类和等于原金币养成合计，拒绝负数及溢出。`PSQ1`/`PSA2` 与 `PSQ2`/`PSA3` 继续兼容；缓存按请求格式隔离，64 KiB、会话身份、换角色屏障、限流及工作数上限保持。

点击角色表头旁“排”按钮，按该指标降序排列，再点切换升序；切换组恢复首项降序，切换周期保留指标并回第一页。排序仅使用客户端快照，先筛选再排序再分页；并列保持服务器原角色顺序，当前角色加“[当前]”标记。原快照保持，不为排序发请求。

该项不新增 DLL、不修改 PVF/NPK；游戏 EXE 生成、安装和原生交互验收由独立流程负责。
