# 公会申请审批与失败恢复

本单元修正申请审批失败后的状态保留与列表恢复。继续使用现有账号、角色、公会和职务校验；公会管理权限位的原生语义仍需补充证据，本单元不调整权限政策。

## 修复行为

- 满员或申请者已经入会时，领域函数返回错误并保留申请、成员和时间戳。此前事务调用能回滚失败，但领域函数本身会先删申请。
- 通过和拒绝的原生行按钮会在发送后立即移除本地行。有效身份请求处理失败后，先发送既有失败确认，再重新读取已提交状态并发送申请列表；无权读取时不发送申请明细。
- 无权读取申请列表、失效成员归属或无有效选角时，op352 返回错误36，使匹配客户端清空旧缓存。此前通用错误34保留旧缓存。
- 成功审批清除申请者在各会的申请；成功拒绝只删除当前会的申请。事务失败不刷新申请者的成员身份，不改变金币或其他角色资产。
