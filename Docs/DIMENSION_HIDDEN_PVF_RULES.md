# 异次元隐藏领主的PVF规则

按操作者2026-10-27最后确认，隐藏领主以PVF为准，每周只出现两次；该确认取代此前“最高奖励次数不影响后续出现”的需求。

服务端读取 `Etc/DungeonEtc/DimensionDungeonInfo.etc` 的 `[hidden boss appear count on week]`，配套资源审计值为2。普通进图的出现概率继续使用同文档 `[hidden boss appear rate by enter count]`；每次成功进入隐藏迷宫即在原入场资产事务里计数，次数满时改选普通迷宫，周四北京时间06:00恢复。旧计划重放、日次数拒绝和事务失败均不额外扣除隐藏次数。

组队共享一个迷宫。队长选隐藏迷宫前读取权威名单中每位成员的持久周计数；任一成员已满则全队进入普通迷宫。队员接受冻结地图和入场资产提交时继续校验自己的次数，避免缓存计划使已满的角色进入第三次隐藏迷宫。

特殊奖励表是 `[hidden boss drop table]` 的难度、物品ID、原始数值三列。当前表有3档、每档11项，包括远古卡片册、四种传说远古袖珍罐和六种魂魔石。ID通过 `stackable.lst`/`equipment.lst` 的“ID后接路径”映射；文件名不能替代lst索引。PVF保持本地只读，不随源码或服务端产物发布。

2026-10-27 的 V25 服务端候选读取这33条原始记录，隐藏迷宫中由PVF标记的隐藏领主死亡时，按难度档对每个物品行分别抽取一次，命中后沿现有地面掉落与拾取事务发放。第三列按同文件出现率及现有副本物品抽取所用的10000档阈值解释；这是基于同版本PVF与服务端公式的实现推断，PVF本身没有文字说明该单位。普通怪、普通迷宫及每周出现上限维持原流程。

真实PVF隔离测试已覆盖33条解析、全部物品ID解析、难度2隐藏领主掉落规划和拾取入包；异界/隐藏计数专项回归通过。该记录当时尚未包含构建、部署或游戏实机验收，不能将测试结果写成线上已修复。
