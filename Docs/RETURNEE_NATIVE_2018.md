# 回归勇士原生 2018 界面

活动管理沿用逻辑编号 1370，默认关闭。当前客户端的网络编号与参考端不同，不能直接发送参考端的 176 字节状态或沿用旧任务手册分派。

## 协议

| 方向/分类 | 编号 | 正文 |
|---|---|---|
| 服务端通知 class0 | 1369 | 固定 352 字节回归状态 |
| 客户端请求 class1 | 1429 | u8 模式、u32 引导编号 |
| 客户端请求 class1 | 1430 | u32 任务或签到编号 |
| 服务端应答 class1 | 1429、1430 | 成功 u8=1；失败 u8=0、u8 错误码 |
| 服务端通知 class0 | 304 | 原生回归权益剩余秒数 u32、旧赠礼标志 u8=0 |

352 字节状态中，偏移 0 是 u16 用户类型；0 属于新手，1 至 5 属于回归分组，6 为非参与状态。偏移 8 是 46 位主引导。偏移 16 开始十行任务，偏移 176 开始七行签到，每行 16 字节：u32 编号、u32 进度、保留 u32、完成 u8、已领取 u8、保留 u16。偏移 288 开始 64 字节是 512 位扩展引导。

1429 模式 0 修改主引导 0 至 45，模式 1 修改扩展引导 0 至 511；越界、错误长度和未知模式拒绝。现用客户端的 1429 即使活动关闭也由回归处理器消费，不能落入历史清主线任务路径。当前任务手册仍使用独立 1427/1454 流程。

1369 只更新任务管理器，304 只同步权益时间。原生底部按钮还检查角色对象的回归启用字段；场景 mode0 中该字段紧跟双技能页字节，其后为 u32。读取链为 22C645D/22C646D → 2961F90 写 actor+3C4，2277F95 → 2961F70 判定按钮资格；按钮 2264470 → B6FF30 请求窗口 77。现用 PVF 页面为 `ui/guidesystem/seriawelcomemission2018.xui`，中文标题“赛丽亚的热忱”。

## PVF 和资格

配置读取 `etc/seriawelcome.etc` 的 `mission list`、`mission group` 中 group1 的任务、底部奖励和签到编号，邮件标题/正文读取 `reward mail`。当前任务编号为 47 至 53、20 至 22，签到编号 33 至 39。奖励道具、数量和任务要求来自 PVF；加载时核对编号唯一、条件支持、七天签到结构及奖励道具有效性。

默认账号离线七天触发回归，资格持续三十天；资格和经验比例由移植活动策略保存，未配置时欢迎经验为 20%。离线分组读取 `return day`。没有可靠离线记录的账号先记录观察时间，不凭空生成历史。新周期重置任务与签到领取位，保留账号引导位。

签到按账号计算，以北京时间 06:00 区分服务日，有实际在线观察才增加一天，最多七天；换角色、重连和同一天重复查询不增加天数。可以补领已经达成的前几天奖励，未达成日期和过期资格不可领取。

## 进度与发奖

访问城镇从服务端已经验证的非赛丽亚落点取得，随位置保存及失败回滚；支持当前 PVF 的任意城镇条件，也保留指定城镇条件。施放无色技能在成功扣除晶块的同一事务中计一次，按施放次数而非晶块个数。异界复用现有异次元裂缝分类，在终局结算事务中记录；重放或失败不增加。

其余任务沿用完成任务、升级、分解、学习技能及公会的权威状态。账号消费各角色的新进度快照，不将换角色前的历史累计当成本次回归进度。任务汇总奖励只统计实际完成的普通任务，不把七天签到混入。

普通任务和签到共用账号/角色/邮件事务，领取位与奖励邮件一起提交；失败回滚，并发和重放只发一次。领奖时重新读取权威进度，不接受客户端提交完成数。状态按原活动刷新节奏更新，领取及引导应答后立即重发最新状态。

活动默认关闭。源码分派、真实 PVF 解析、安装、客户端接收和实机界面分别记录，不能用专项结果代替完整联网与界面验收。
