# 公会搜索与分页

修复前，op1450的标签掩码被当作页码，真正的页码没有使用，文字搜索也没有区分公会名和会长名。选择标签可能翻到错误页，翻页可能反复返回首页。现在按匹配客户端的字段解析，在筛选后统计总数并取每页30条，保留既有回包布局。

| 模式 | 请求体 | 查询范围 |
| --- | --- | --- |
| 0 | `u8 mode + DSTR query` | 公会名 |
| 1 | `u8 mode + DSTR query` | 公会长名字 |
| 2 | `u8 mode + u32 tagMask + u8 page` | 标签筛选，零基页码 |

DSTR是`u32`字节长度及GB18030内容。文字输入限14个UTF-16代码单元，严格核对编码和长度，拒绝NUL、控制字符及额外尾随字段。模式0/1没有页码字段，从首页返回。标签仅使用低七位，至多选择三个；零掩码显示全部，超出结果范围的页返回实际总数和空行集合。

当前本地查询保留大小写不敏感的子串匹配、等级降序及ID升序；多标签要求全部满足。**客户端只证明字段、选择器和展示方式，不能证明原服数据库的匹配、排序或推荐算法。上述本地规则仍需准确配套服务端源码核对。** 宣传栏开关不限制普通公开搜索，历史外部宣传服务另行接线。

成功响应为class1：`01 + u32 filteredTotal + u8 page + u8 count + rows`。每行是`u32 guildID + u8 joinMode + u32 tags + u16 memberCount + u8 level + guildName DSTR + masterName DSTR + promotion DSTR`。错误保留既有失败响应，客户端结束等待。搜索只读公会聚合，不更新积分、成员、时间戳或发出成员广播；既有账号归属和class校验保留。账号索引1451及推荐视图保持原行为。
