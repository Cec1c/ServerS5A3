# 强化金币与结果尾部兼容

普通强化默认费用接线曾只处理已核 NPC 的材料换算，其他强化回落到装备 Extra 金币字段；没有该字段时费用为零。默认档现使用既有 PVF 原生金币计算器，在资产事务内核对目标等级并报价，金币不足先于抽签和材料写入拒绝。增幅使用自身费用表，便携强化器的免金币规则及材料兑换场景校验保持。

当前客户端模块 SHA256 `478611607f7b6567fcaff7af1ca53c4700eec93b9285ac75d47bd5465d535586` 的 class1/op80 回调为 VA `0x1fe02a0`，注册点 `0x1fe7b25`。接受强化结果后，VA `0x1fe0e3b` 和 `0x1fe0e4e` 无条件调用 u16 和 i32 读取器，消费额外材料槽位及剩余数量。无材料用槽位 `0xffff`、数量零；有兑换时使用同一资产事务提交后的槽位和剩余数量。

旧普通/券强化应答缺少这六字节。隔离执行该客户端尾部及实际读取器指令，旧空尾令剩余长度成为 -6，完整中性尾和兑换尾均恰好消费六字节。测试替代了运行环境、缓冲区和溢出报告条件；它证明越过消息体读取，不代表重现玩家现场崩溃。

共用编码器现在包含尾部，摧毁奖励字段位于尾部之前。勋章强化删除其已存在的单独补尾，保持最终 25 字节，避免重复。错误应答仍是两字节拒绝形状。

验证覆盖默认扣金、余额不足零写入、余额恰好足够、NPC 换算、交易晚期失败回滚，以及成功、保持、降级、保护、摧毁、强化券和勋章应答。真实资源测试覆盖 +12 强化失败的资产与投影。源码测试、客户端隔离测试、部署及实机复测各自记录。

费用解析边界：目前原生报价器不支持 `level linear ability`、`upgrade cost discount`、`custom upgrade type` 和 `upgrade exclusive material` 等特殊元数据；含这些字段的装备会拒绝普通强化并保持资产不变。默认启用后，这些装备不再沿用旧 Extra 费用或缺省零费。普通装备使用 PVF 报价覆盖旧 Extra 金币字段；显式非空、非 `candidate` 的环境档仍保留历史关闭行为。实际部署需核对该环境档；不能把普通装备回归通过表述为所有特殊装备均已支持。
