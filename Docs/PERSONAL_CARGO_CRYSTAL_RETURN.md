# 个人金库取出晶块与成长胶囊排查

个人金库 list 2 的取出请求仍以普通材料页为目标，原路径只访问角色库存，造成无色等小晶块回到材料页。现在领域层先识别实际道具，在账号与角色的同一资产事务内重新读取来源并转入既有的固定账号晶块/灵魂格。普通材料保留原来的寻位逻辑。

op19 成功应答使用事务实际端点；合并时在应答后刷新个人金库来源和账号目标数量。目标满额或不兼容时拒绝移动，不交换固定格、不删除余量；提交失败全部回滚。已在普通材料页的历史晶块仍由既有登录清扫转回账号仓库。

成长胶囊使用 etc/adventurersystem/adventurersystem2018.etc 的等级与经验规则。当前资源领取等级为 50～86，满级角色累计、同账号符合等级的角色领取；满容量时停止继续累计，领取后恢复。领取直接给予角色经验，不生成背包道具。90 级按钮置灰与该资源规则一致，不能通过补造经验或取消服务端等级检查修复。此次保持原有规则。

验证需在 Linux 执行库存专项（固定格路由、全部十二类材料、拆分/合并、数量守恒、应答、满格/冲突及事务失败回滚），并用实际 PVF 执行冒险团累计、重载、换角领取专项。本机不运行 dnfbridge 测试。游戏客户端实际操作另行验收。
