# 普通卢克选图计数与逐图解锁

机械王座准入使用本角色已保存的通关记录，但选图页读取独立序列缓存。未回复序列42的class1/op869时，悬停条件仍显示0/1。查询回复还必须区分“当前可进入序号”和“已通关位图”：首图通关应发游标1、位图1；发游标0会让第二图仅可见而不可进。

## 服务端范围

- 仅处理序列42的4字节查询，按运行PVF的顺序读取本角色DungeonPermission；验证角色与账号归属，查询不修改数据库。
- class0/op602为`u32 sequence_id + u8 enterable_cursor + u32 individual_clear_mask`。游标指当前可进入的末位，连续已通关前缀后开放下一图；全部通关饱和末图。独立位图只表示真实通关，不能拿难度数值充通关次数。
- 普通卢克结算成功后冻结并推送进度，失败从冻结包续发，不重复奖励；只向本会话已查询过的角色发送。
- 当前EXE的原生个别位图仅支持8图，超出时拒绝。其他序列、团本、下一图流程、机械王座前置及奖励均不修改。
- 时间语义沿用当前持久通关记录，本修复不新增每日重置规则。

## 客户端依赖

官方V207输入SHA256为`eca5ae9017176fb159ae22d6498b2a6805b8b93295042363a90f37f2daae7a03`。其op602消费者已存在，但接收许可未启用。`scripts/client/patch_luke_selector_progress.py`只放行该位并更新PE checksum，拒绝未知输入或重复应用，输出独立候选；不上传或替换完整EXE。

只有更新服务端、没有更新玩家EXE接收许可时，旧客户端不能使用这份进度。正式发行需按现有Release/玩家通道流程同步对应EXE，再部署依赖它的服务端。
