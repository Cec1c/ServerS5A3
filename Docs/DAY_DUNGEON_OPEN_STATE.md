# 周常副本入口开放状态

角色已进入阿比斯区域，但选图界面出现前提示“现在不是地下城的开放时间或角色Lv不符合该地下城。”当前客户端分别读取活动目录和逐副本开放表：108中的2418～2424只表示星期活动，不能代替855维护的入口状态。

服务端在完整活动目录及其所属状态之后发送五条class0/op855，阿比斯城镇107/区域0完成加载后再次恢复；同一客户端进程省略108的换角流程仍发送855。原有06:00服务日定时器同步更新108和855，一次发布共用已核对的星期事件，旧图明确写关闭状态。

855的固定16字节包体为四个小端u32：`类别=0、状态=0或1、副本ID、附加值=0`。客户端原生消费者接受状态1或2；本实现只使用1开放、0关闭。发送使用现有fixed16场景通知封装，失败返回错误，下一次同步重发完整五图，不记录部分成功为完成。

开放日期复用现有领域规则和真实PVF核对：周一4906、周二4910、周三4908、周四4907、周五4909、周六4906/4908/4910、周日4907/4909。服务日按北京时间06:00切换。等级、前置、单人、每日次数及账号参与角色上限继续由既有入场流程和事务校验，本通知不扣次数、不发奖励。

补丁及核对入口位于`scripts/client/patch_day_dungeon_gate.py`、`verify_day_dungeon_gate.py`和`test_day_dungeon_gate.py`。需要Python 3、`pefile`和`capstone`。补丁只接受上述精确输入，生成独立新文件；拒绝未知版本、重复打补丁、覆盖输入或已有输出。不安装、不启动客户端，也不引入DLL。其他客户端版本需重新核对，不能将此处地址直接套用。
