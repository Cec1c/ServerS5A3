## 原因与改动

旧建店入口校验副职业、耐久、收费、组队与城镇登记，但直接接受请求坐标。已用真实 PVF 和真实 op598 handler 复现：分解机与附魔商店在地图外 `(-30000,-30000)` 以及 NPC 附近 `(1227,196)` 均返回成功 `01`；合法点同样成功。

建店现在先解析当前权威城镇/区域对应的地图，再由副职业域检查 `[virtual movable area]` 的 x/y/宽/高矩形和 NPC 禁摆矩形。地图边界含端点，NPC X±80、Y±150 的内部禁止摆摊，边界本身允许；规则来自 `ServerS4A21` 参考实现 `Game/ExpertJob/ExpertJobStorePlacementValidator.cs`。地图/NPC 坐标使用当前真实 PVF；未添加城镇白名单、假坐标或固定 NPC 表。

地图加载包含 `[import script]` 中的 NPC；缺失/循环导入、损坏 NPC 记录、缺失或损坏可行走矩形均拒绝。拒绝发生于登记商店之前，不广播商店，不改金币、职业经验或机器耐久。原有城镇/组队/职业等检查继续生效。
