# 大富翁骰子（幸运热舞派对）

## 累计基底恢复说明

本轮从既有源码候选恢复到当前累计基底，保留城镇活动NPC、超时空频道和赛丽亚幸运值目录；新增145行时既有基础行和活动行字节保持。普通装备稀有度加成调用已恢复的普通怪模板池，不回退旧装备池，也不改独立深渊掉落。

当前正式v150的原生dispatcher证据已确认class1/629、630准入；v151仅新增class1/1342，本项不要求额外扩大接收门。此证据不代替真实界面、圈数奖励和跨日验收。累计目标回归与最终主线完整检查分开记录，本候选未部署。

接入 `event/attendancemarble.evt` 的28格棋盘，沿用90参考端的角色进度与双骰规则。活动145控制入口、掷骰及推荐通关加次；已经取得的地下城Buff在关闭活动后保留。

## 配置与进度

- 每角色每天基础2次，推荐地下城通关4、8、12次各增加2次；通关门槛和加次从PVF读取并校验当前原生窗口支持的四档结构。基础2次与连续双倍上限来自参考端规则。
- 按北京时间06点换日，只重置当天通关与可用次数；棋盘位置、圈数、累计奖励领取和待用Buff保留。4/8/12代表完成的圈数，不是掷骰次数。
- 普通物品格、跳转格、金币购买格、Buff格、三档圈数奖励及邮件有效天数读取PVF。当前解析器只接受已核对的28格、4/8/12圈与29～32号Buff结构；配置不兼容时不发布入口。
- 服务端生成两颗1～6的安全随机骰子；上行参数不能指定点数。双倍机会最多连续5次，查询或641关闭本次双倍机会。
- 扣次数、落点、金币、阶段领取标记和系统邮件放在同一角色资产事务中，失败回滚。推荐通关计数复用既有结算回执防重，不修改数据库结构。
- 奖励通过系统邮件发放，邮件期限读取PVF，附件期限复用现有道具发放政策；库存满不会丢弃邮件奖励。

## 原生入口与协议

活动图标61查询145。class0/108仅追加145基础行和活动行，保留每日在线、赛丽亚幸运值等既有行；登录不主动发送会打开窗口的629。

| 编号 | 上行正文 | 下行 |
| --- | --- | --- |
| 629 | 空 | class1，成功标志后16字节：保留u16、总次数u16、剩余次数u16、位置u16、保留u32、圈数u32 |
| 630 | 操作参数u8 | class1，成功标志后8字节：骰子一u8、骰子二u8、剩余次数u16、圈数u32 |

成功掷骰后不立即补发629，避免重置客户端的骰子与移动动画；不发送class0/569。487/488承担29～32号Buff显示恢复与更新。

629/630虽为class1应答，仍须通过客户端分类分流之前的共用按编号接收门。仅登记class1回调不足以证明回包能抵达窗口；目标客户端必须允许接收这两个编号。641仅上行，无须为它新增同号下行许可。接收门关闭时，即使服务端有正确回包，窗口也可能停留在资源默认的全部完成状态。

当前PVF的窗口标题为“幸运热舞派对”，仍有双骰控件。原生状态更新会隐藏旧“累计疲劳值”控件，没有据该默认标签添加疲劳兑换次数规则。

## 地下城Buff

待用次数按角色保存，在入场发送完成后每种消费一次，绑定当前地下城运行时，换房间不重复消费；修炼道场不消费。无待用Buff时不增加资产事务。

| Buff | 效果 |
| --- | --- |
| 29 | 普通装备神器概率增加120%，保留更高稀有度概率与原分母 |
| 30 | 杀怪经验增加100% |
| 31 | 通关经验增加100% |
| 32 | 杀怪经验增加50%、通关经验增加100% |

经验按基础值叠加到实际提交结果，并更新既有结算显示字段；原契约与公会加成保留。堆叠物、固定掉落和独立深渊池沿用原规则。真实PVF专项同时核对这些效果参数，不自动支持尚未核验的Buff定义。

测试覆盖角色隔离、06点换日、跨圈与三档领取、防重、并发、事务回滚、关闭活动、目录原行保持、协议正文及Buff消费/经验/掉落。真实PVF专项遍历28格、三档圈数奖励及四种Buff配置；原生读取、发送、活动入口和接收门回放只证明对应局部契约，不能代替完整界面。

此贡献仅包含服务端业务、测试和必要说明，不包含客户端、接收表修改或资源。目标客户端须同时具备145界面、629/630读取器及接收许可；公开玩家配套尚需单独确认，因此MR保持草稿。若需要调整EXE，依照 [客户端发行同步流程](CLIENT_RELEASE_SYNC.md) 完成正式Release、镜像和实际更新通道核对后，再部署依赖的服务端。
