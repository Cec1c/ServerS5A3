# 疲劳药跨服务日冷却

现有06点刷新会清除药品最后使用时间，导致10小时或22小时冷却在日切换时提前结束；22小时及以上还被替换为每日一次，导致没有显式日次数限制的药品满22小时后仍被拒绝。

修复保留最后使用时间，显式日次数和疲劳额度按06点刷新，所有正冷却都按真实PVF毫秒间隔校验。10005098保持每日3次加10小时冷却；10005187保持22小时冷却且不添加资源没有声明的每日次数。其他156点同名版本也按各自资源处理，不统一放宽。

真实资源完整515/action58请求验证成功ACK、14库存行与疲劳通知；对照数量1删除、多件扣减、旧RawEntry数量覆盖、冷会话读取，以及错归属/满疲劳/副本内/事务保存失败。库存数量、每日剩余次数与客户端冷却遮罩是不同状态，原报告数量/UI不减没有复现，不据此关闭。

验收应使用合法独立道具实例、准确品种和服务时间；跨06点不能提前解除冷却，冷却到期后符合其他条件应可使用，显式次数上限保持。记录每次使用前后数量及重登读回。旧版本已经清掉的时间戳不猜测恢复，不修改生产记录来制造时钟场景。
