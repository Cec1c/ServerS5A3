# 结婚、婚戒与婚房

从大司祭查找角色接入原生订婚、婚前任务、预约婚礼和婚后系统。规则及奖励以运行时 PVF 为准；婚姻、金币、物品、请帖、礼金和婚房由服务端事务持久化。客户端必须具备 [完整婚姻报文收包准入](WEDDING_CLIENT_RECEIVE.md)，不能只安装服务端。

## 玩家流程

1. 双方使用不同账号，满足 PVF 等级与异性资格，在同一频道的大司祭场景查找、发起求婚并接受。拒绝、超时或会话失效不建立关系，申请状态及时释放。
2. 订婚双方完成准备任务。当前资源的 `20737` 要求二人组队通关普通地下城五次，奖励真爱考验箱；`20738` 收集心意娃娃。通关进度在结算事务更新，不能靠通关界面显示成功推定任务已经提交。
3. 完成双方任务后选择婚礼档位、等待时间，另一方接受才形成预约并收费。普通、高级、豪华婚礼的费用、请帖、奖励及初始婚戒来自 PVF；当前资源分别给予 0、1、2 档婚戒。
4. 新人及受邀宾客进入该场礼堂。随机派送允许发送给当前实际可邀请人数，不要求在线人数达到 30。名额分双方计算，已邀请名单共享；手动邀请使用真实角色 ID。
5. 宾客按实际邀请发送祝福和礼金；扣款与账本共同提交。付款时不提前发送不存在邮件的提醒，结束结算或取消退款真正提交邮件后才通知。
6. 到期且双方已完成真实礼堂加载后播放婚礼、完成婚姻并结算奖励。取消和失败预约按照真实付款凭据退款，冷却与日限按规则保留；不通过清空冷却掩盖预约错误。

## 婚后状态与属性

婚姻状态包括双向配偶、关系标识、婚戒、个人心意点和共享婚房。婚戒升级事务同时保存双方等级并扣除真实升级券，配偶离线也可持久化；操作方只接收一次升级结果，配偶使用 C0/1001 通知。

升级应答无论成功或失败都为 **6 字节**：`flag:u8 + error:i32 + ringStage:u8`。配偶通知仅含一个等级字节，不能互换布局。

当前 PVF 婚戒是每档完整属性快照，不能重复累加低档：

| 档位 | 属性 |
| --- | --- |
| 0 | 体力、精神各 +8 |
| 1 | 力量、智力各 +15，体力、精神各 +10 |
| 2 | 1 档属性及硬直 +200 |
| 3 | 2 档属性及移动速度原始值 +20 |
| 4 | 3 档属性及物理、魔法暴击率各 +2 |
| 5 | 4 档属性及攻击、施放速度原始值各 +20 |

原始速度单位不直接等于百分比。婚房只有实际摆放家具计分，加成由运行时 PVF 表计算。服务端基础角色属性不再次叠加婚姻属性，未婚角色的婚戒和婚房投影为零，没有移植其他版本专设的未婚加成。

登录、进本、回城、场景及背包刷新均按当前会话和最新关系回放婚姻、婚房状态；角色创建通知 raw71 mode0 的婚姻片段也写入权威值：`raw[0x17]=phase:u8`、`raw[0x18]=ring:u8`、`raw[0x19:0x1D]=roomPoints:u32`。只补 C0/1000 不足以阻止后续角色重建把客户端独立缓存重置为最低婚戒和零婚房。

## 婚房、树、胶囊与道具

装修请求 C1045 的 0 为打开、1 为关闭；无编辑租约时合法关闭可成功返回，不能误踢另一方的租约。C1046 为 27 字节，13 字节前缀后接两个 `container:u8 + slot:u16 + itemID:u32` 端点，其中没有数量字段；一件家具占一格。快照按 `1011 → 1008 → 1009` 清理旧槽再恢复现状，避免摆放或删除后残留。

树的种子、期限、每日浇水、成长及收获奖励来自 PVF，操作时重新校验。错误码按各自原生处理器映射，不能把浇水、收获和胶囊的同号错误当成同一文字。胶囊仅由有结算凭据的推荐地下城充能，制作、赠送、领取和消耗分别验证归属和重放。

婚礼化妆箱沿用匹配的 PVF 礼包类型；奖励放不下时走同事务邮件。豪华婚礼给予蓝玉戒指及两张低阶升级券来自当前 PVF，券只进入背包，不自动消耗。商城补读 `[community item]` 的原生九列商品，仍走既有扣款、发物品与回滚。

礼堂留言在首次访问婚房留言簿时，将本场成功婚礼的留言同事务归档，保留作者、时间与内容并重新编号；重复打开不重复归档，其他伴侣及取消场次隔离。

## 验证范围与已知边界

包含领域事务、协议布局、同屏和离线投影、场景加载、超时、重放及资产回滚回归。公开候选完整 Linux 验收以本 PR 的 CI 结果为准；本地已安装版本已有用户游戏反馈通过，公开主干集成后的 CI 与本地游戏反馈分别登记，不以原生模拟器代替图形联网实测。

仍保留这些边界，不能将提交描述为所有界面均已修完：

- 预约资料先发、成功回复后发，避免后续通知清空“恭喜”正文；同一发起角色关掉后再次出现相同“恭喜”的反馈尚未完全定位。
- 公会请帖列表已有服务端真实名单及缓存预热；客户端查询链的额外改动未实施，不能保证所有客户端版本均显示正常。
- 高级婚礼优惠券已发放，实际折扣购买尚未完整实测。
- 空胶囊领取的原生错误文案尚未定位；当前 dstr 中 C1054/-4 是“进入礼堂”，不能套用其他版本错误码。
- 祝词通用失败及伴侣传送部分分支原生无弹窗，保留原处理，不伪造跨命令提示。

同性结婚开关及客户端性别跳转改动已取消，不在本次提交内。
