# QST-019 警卫员任务的小盒子来源

## 目标与成因

「比尔马克帝国试验场的警卫员」3656先完成清图子任务3692，再交付子任务3693所需的小盒子10164767。小盒子由前置3649「绝密区域的悲剧」奖励1个，来自更早的绝密区域剧情。

匹配PVF的3091项任务定义中，该物品仅被3649的奖励、3656的交付提示、3693的材料条件引用。牛头械王的开场与死亡剧情、相关动作没有发放箱子的定义。

以原始任务、物品、经验表的有限提取文本运行正式接取、触发和交付入口：正常完成3649，获得1个箱子，3693交付成功并扣除；按等级无奖励完成3649，随后3656可接、3692可完成，3693因缺箱失败。该路径解释了清图完成而整条任务无法交付的现象。

## 解决方案

复用女王书信恢复的任务事务，在新接取和已有活动任务重登的快照入口，支持第二条经过定义核对的关系：3649 → 3656 / 3692、3693 → 10164767×1。

将来源关系作为内部明确配置，共用候选判断、定义校验、库存分配和一次性回执。保留女王书信已有入口、回执键和行为。箱子关系使用独立回执键；来源须为已完成的无奖励跳过记录，后续父任务与交付子任务仍活动，物品必须为真实任务品且当前缺少。

事务内重新读取角色、任务和库存，补1个缺少的箱子并在3649保存回执。提交后发送库存更新，再发送活动任务快照。已有箱子、正常发过来源奖励、已交付或已有恢复回执时保持原状。

## 实现范围

- `quest/queen_letter_recovery.go`及一个共用的剧情来源恢复实现；保持现有书信API兼容。
- 新增箱子关系及领域测试。
- bridge的快照恢复接线与本项正式入口测试。
- 本文与变更记录。

## 测试与验收

1. 正常3649领奖产生一个箱子，3693正常消费；重复交付不多扣。
2. 两种无奖励跳过标记下，新接3656或已有活动任务重登恢复一个箱子；清图后正常交付及父任务结算成功。
3. 重复、并发、重新连接保持一次发放；背包满、库存或任务保存失败整笔回滚，后续可重试。
4. 已有箱子、正常来源、后续已完成、来源未完成及定义变化均保持原状；女王书信全部回归通过。
5. 完整领域、bridge、control、list、vet和双平台构建；匹配PVF专项在串行窗口执行。
6. 用户实测：不用完成券绕过3656，清图、与土罐对话、交箱并领取父任务奖励，重登后后续主线可继续。

允许失败。返回已尝试步骤、失败证据、当前修改和需要确认的信息。
