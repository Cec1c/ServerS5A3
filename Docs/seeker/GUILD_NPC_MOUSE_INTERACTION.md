# 公会 NPC 鼠标窗口交互

匹配 V176 客户端，鼠标通过场景 NPC 命中打开窗口；键盘近邻查询的 40+add 矩形不参与鼠标点击。服务端将该矩形用作商人购买、升级和守护神交互的准入，导致正常窗口请求返回错误 3。

修复在 bridge 保留当前角色代际、场景就绪、同地图真实 NPC、持久场景、会籍/权限、等级及原资产事务校验，移除误用的键盘距离条件。守护神仍核对首购或当前出战等级对应 NPC 存在。

验证目标：原失败坐标在真实分发器购买、升级和首购成功；重放不重复扣费；跨场景、错误 NPC、过期会话及权限不足继续拒绝。守护神培养动作另行接通。原始报文和二进制反汇编留本地。
