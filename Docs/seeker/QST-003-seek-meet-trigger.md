# QST-003 危险的研究：材料条件进度与回调数量

状态：修复候选已通过自动验证，待部署及正常游戏流程实测。

## 成因与证据

真实父任务3729包含会面子任务3762和材料/会面子任务3763。3763的整数数据为3033、3034、3035、3036各200，尾项NPC79。旧服务端把第一种材料数量200放进低9位，得到初值712；客户端把该通道作为材料整体条件的待办开关。

匹配V124 EXE SHA256为 `eaa2485609fa9cc2c9ca99fadd743b5206a37b5517dd07d195eb35b3c0a29d50`，PVF SHA256为 `fef4f46f6c3096d10cd88c84579dea8bd4fffa18e5a75b4684a2e920864f5525`。原生标签解密与真实跳表执行确认 `[seek n meet npc]` 对应type25。材料更新入口RVA `0x018b51e0` 逐对检查全部材料，忽略末NPC；材料谓词RVA `0x035e6f70` 要求每种数量满足，随后通过RVA `0x018991c0` 和 `0x01b00630` 发送COMMAND33。

独立离线执行覆盖材料无/仅第一种/末种199/四种各200，与trigger0/1/512/513/712的20组组合。材料齐全时，712产生200次0x10减请求，513产生1次，512产生0次；材料不足时不执行材料减计数，零值通道会被补回1。这支持新接取采用材料1、NPC1，即513。

若每个有效回调引发一次材料更新，n次计数可产生n+(n-1)+...+1次请求；200对应20100。此为受控调度模型，实际客户端全网络链的合并与调用频次未测，不作为现场包数或历史卡图唯一根因。

七态城镇对照在真实西海岸与斯曼工业基地数据上分别通过进出赛丽亚及重登出门：未接、刚接、对话后无材料、只有第一种、四种各199、四种各200、完成券绕过。任务记录保持；未在服务端城镇路由复现任务相关拒绝。

## 实现

- `seekAndMeetNPCInitialTrigger` 用一个材料整体条件初始化低通道，NPC从整数数组尾项判断。实际数量继续保留在材料条件中。
- `repairLegacySeekAndMeetTrigger` 接入既有活动快照前修复流程：仅处理活动、PVF路径和类型来源匹配、材料数组合法的旧超量低通道。旧初值和已递减的异常剩余值压成1，保留NPC通道；0/1、已完成、无来源、其他类型及不合法形状保持。
- 修复先持久化再回包，保存失败仍返回原持久状态。再次读取不重复写入。

本项不改变材料扣除事务。旧 `finishDefinitionSeekingRules` 仅取首对以及无奖励材料子跳过结算的问题在QST-006继续处理；本候选不宣称四种材料消费已经修复。
