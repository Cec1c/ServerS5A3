# 红包领取状态

本人领取一份后，原服务端把该账号的记录设成全局结束；原生页面对所有结束记录显示“抢光啦”。余额和剩余份数仍由事务保存，其他账号仍可领取。

1300 行末状态区分 0 可领取、1 全局结束、2 本账号已领取。真正耗尽、过期或结算优先使用状态 1。客户端把状态 2 放入历史查询列表，隐藏“抢光啦”，显示“已领取”，保留点击领取历史；其他账号继续收到状态 0 和真实剩余份数。同账号重复领取仍由领域事务拒绝。

修改仅涉及红包列表协议、投影和累计客户端的接收分类与状态控件。先发布兼容客户端并读回实际玩家通道，再部署服务端。回归覆盖原状态混淆、五个不同账号完整领取、同账号重试、过期和原生分类/显示/历史请求；不修改玩家资产或 PVF。
