# 公会组队传送次数购买

真实公会内容目录中的 type 7 传送次数已纳入公会积分购买事务，保存次数并在管理面板显示。使用次数与实际组队移动见 [完整链路](GUILD_PARTY_TELEPORT.md)。

成因：购买处理仅支持其他已实现内容；Benefit 领域未建 type 7 次数，管理投影也未输出该项。商品是公会共享次数，不是发往个人背包的展示物品。

真实目录定义：content 13/14/15，type=7、value=10/100/1000、days=9999、mode=1、item=10153534/10153535/10153536，价格 300/2850/27000 公会积分。按传入目录价格结算，验证该类固定次数与模式。次数无时间到期，累加检查 uint32 溢出。

实现范围：复用 PurchaseBenefit 的身份、权限、序号回执与 Guild UoW；type 7 的 Value 为剩余次数、ExpiresAt 为零。重复购买请求返回原回执且不再次收费/加次；已有消耗后的余额不被旧回执覆盖。读写旧注册表及其他福利保持兼容。761 接入三档购买；管理投影输出 type7/expiry0/mode1/当前剩余次数，耗尽后仍输出零次以清除旧显示。

测试：三档购买、连购、重放、余额不足、无权限、无会员、目录类型/模式/期限错误、次数溢出、保存失败回滚；原福利回归保持通过。管理投影覆盖零次和非零次数。

验收：公会积分与共享次数同步变化，个人背包不增加展示道具；使用及重登后次数保持一致。
