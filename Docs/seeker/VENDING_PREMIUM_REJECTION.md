# 售货机黑钻资格拒绝

有效币不足、背包已满、黑钻资格无效等拒绝原来统一返回错误 1。原生回调把它翻译为“出现未知错误，无法使用物品”，无法说明玩家的实际条件。

本项只为领域层的黑钻资格拒绝定义独立错误，CMD215 返回错误 23。累计客户端处理这个专用码时恢复等待/动画状态，明确提示“需要有效的黑钻资格才能使用此售货机”，保持金币、币和物品不变。其它拒绝与成功结算继续走原路径，不放宽资格、不为真实账号补发黑钻。

现场关联以时间、角色、错误长度和摘要对照领域固定错误，不能从通用失败包猜拒绝原因。回归覆盖未激活/过期/有效资格、重复拒绝、失败后成功、最后一币和真实 PVF 奖池；验证原生 dispatcher、错误读取、回调与复位，失败后无空结算。

上线依赖兼容客户端。先正式发布累计 EXE、镜像并更新实际玩家通道，读回摘要后再部署返回新错误码的服务端。

客户端补丁绑定 V191 红包状态/贡献榜累计成品的完整摘要，保留 V190 的频道名、公会菜单与既有来源通知。补丁增加独立只读可执行节，仅接管 CMD215 错误 23；再次应用、输入摘要不符或原生指纹变化时拒绝构建。使用 `scripts/client/patch_vending_premium_error.py --input <累计成品> --output <独立候选>`，原生回归入口为 `scripts/client/test_vending_premium_error.py`。
