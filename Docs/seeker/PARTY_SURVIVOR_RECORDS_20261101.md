# 副本个人回城后的留图队伍名单

个人退队回城后，留在地下城的成员可能仍看到退出者，虽然权威队伍已移除该角色。

原问题中，中央队伍已减为一个成员，留图者也收到了 owner0 的单人名单。这说明仅验证服务端成员数和副本记录不足以覆盖客户端界面。客户端可保留进图前所属频道的队伍记录，普通离队必须同步这份记录，不能只更新 owner0，也不能删除留图者的整支队伍。

本次对每名仍在原实例的成员，用相同权威快照更新当前选中频道和 owner0 的记录：先应用本地成员差异，再清理离场者的普通离队记录，最后刷新剩余成员的各条记录。两种上下文完成后，才移除离场角色并发布非空实时名单。保留原队号、固定槽位和副本运行态，沿用角色代际与运行实例保护。

使用客户端实际选中频道；不使用进图后已置零的 town owner 或旧连接频道。频道超出单字节范围时不截断为其它频道，保留原副本上下文处理。

回归分别读取频道记录的紧凑成员行和跨上下文记录的完整身份行，检查退出者不再出现、剩余成员和槽位不变、两种上下文均收到一次普通离队更新、所有名单先于角色移除。覆盖两人/三人队伍、队长/队员分别退出、频道10/11/255/508，以及既有写包失败、旧运行态保护、个人回城、经验与踢人专项。

本地相关检查与正式优化候选编译不替代公开完整验收；原进图、经验和踢人的用户反馈与本轮留图名单实机验收分开记录。
