# 保存公会频道

当前客户端的管理页保存发送 class1/op830，包体为空；服务端缺少该路由。推荐频道已经存在持久字段和 NOTI70 管理投影，接入保存即可复用现有显示和跳转。

当前正式客户端取证：发送器 RVA `0x0d96440`；成功 ACK 不读额外字段，错误 7 对应“只能将普通区域的频道或特殊区域（普通）的频道设置为公会频道”，19 对应“只有公会长才能设置”。原生推荐目录查询使用两个 uint32：实际广告区服、频道ID。class0/op830 是角色数值映射更新，不用于本功能。

## 实现

增加领域 `SetRecommendedChannel`，在 Guild UoW 内验证账号/角色属于本会，且角色 ID 为会长、品级为 1，保存合法区服及频道。区服 0 有效，频道 0 表示未配置，保存须为正数；具体目录资格由桥接层验证。重复保存不重复改变 UpdatedAt。任意自定义权限掩码不能代替会长身份。

桥接层只接收空请求体，保存发起者当前会话的真实频道，禁止客户端注入其他ID。确认当前频道仍在实际向客户端广告的目录且为既有 `channelcatalog.IsResidentChannel` 认可的普通频道；保存区服取 `channelAdvertiseID()`，不使用角色社交区服。复用 `mutateCurrentGuildForSession`、会话代次检查和 `finishCurrentGuildEdit`，成功 ACK 后通过管理投影刷新同会在线成员。重登沿 NOTI70 恢复。
