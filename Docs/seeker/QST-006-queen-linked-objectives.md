# QST-006 梅娅女王与多材料子任务结算

## 问题与成因

真实任务3249「梅娅女王」包含3609对话子任务和3610材料对话子任务，目标NPC为303。3610要求交付10164786「斯卡迪女王的书信」1封。

旧逻辑把无经验、无奖励子任务都放进只写任务记录的快捷归档路径。材料子任务也被归档，缺书信仍可完成，有书信却不消费。在已含QST-001/002的累计源码上复现了同一缺陷。

另一个共用缺口是`seek n meet npc`只解析第一组材料。真实3729「危险的研究」的3763子任务要求3033、3034、3035、3036各200，末尾79为NPC编号。

## 解决方案

- 快捷归档同时要求没有现有结算材料规则。纯对话继续使用原路径；材料子任务进入既有`ApplyFinishSettlement`。
- 直接子op34通过原子事务检查并扣除材料；父op33可反映子触发完成，但保留子任务待结算。父op34复用QST-001末子结算，在同一事务消费材料、完成父子并保存幂等回执。
- 材料解析读取全部物品/数量对，跳过未配对的尾部NPC。没有任务ID硬编码。
- 材料不足或晚期奖励失败保持原库存和父子状态。重复请求、重连回放使用原回执。

本项不追补已完成记录。完成券属于独立旁路。

## 用户验收目标

1. 不用完成券，正常推进「梅娅女王」，先对话再交书信；交付后书信只扣1，任务完成并可接后续。
2. 重登后任务、库存和后续任务保持；重复交付不再扣书信。
3. 在QST-003和本项均上线后测试「危险的研究」：四种晶块各200，交付各扣200；任一种不足时不能交付，也不扣其他材料。
