# AT-5T 上机问题：只读状态采样

## 目标

提示可见、按技能键触发普通动作却不上机。离线验证已确认单次关闭输入使能不会持续丢失按键，下一步需要同一次尝试的角色、输入驱动对象和载具状态。

提供独立Python命令行采样器，读取已运行客户端的指定字段，输出本地JSONL。采样器沿用现有客户端程序，读取权限仅用于进程身份及内存；游戏操作由测试者完成。

## 数据与方案

- 按PID选择进程，核对EXE完整摘要及模块基址。仅接受已经对照过的V135/V141，地址按实际模块基址换算。
- 采集本地实体角色、优先角色、VirtualCharacter及其场景数组位置；枚举最多4096个场景条目，选择定义61235的载具，最多输出8个。
- 记录角色实际虚表、普通命令入口、资格入口、骑乘指针、动作；载具记录owner/rider、交互状态和锁。
- 记录本地input、技能描述符使能和结果、是否注册到该input、logical4的down/fresh行。记录对象或指针变化，单次读取失败写为字段错误。
- 保护动作字段按客户端原生XOR及校验算法解码，并复读句柄、密文和键值确认采样稳定。输出解码结果及校验状态，不导出密钥表。
- 默认采样20秒、间隔5毫秒，时长上限60秒。输出每条实际时间戳；轮询只说明采样时刻的状态，不能单独证明函数调用先后。

## 测试与验收

单元测试使用构造内存，覆盖角色选择、场景顺序、多个载具、输入缓存匹配、保护字段解码与不稳定读取、空/坏指针、数组上限、摘要不匹配及输出范围。Windows底层读取另用采样器自身进程中的已知缓冲区验证。

游戏内验收：进入任务3529起点，站定后运行采样；松开技能键，再按一次，等动作结束后重复。检查采样是否记录同一角色和载具、输入结果、动作变化及骑乘指针；据失败采样定位下一项修复。此次工具交付与上机修复分别记录。

允许失败。执行者返回已尝试方法、失败证据、当前修改及一个需要确认的问题。

## 工具实现

入口：

```powershell
$targetPid = 1234
python scripts/client/at5t_state_sampler.py `
  --pid $targetPid `
  --output at5t-001.jsonl `
  --seconds 20 `
  --interval-ms 5
```

- `--pid` 必须显式指定，工具不扫描或自动选择进程。`--seconds` 默认 20、最大 60；`--interval-ms` 默认 5。
- 输出文件必须尚不存在。工具先验证进程路径、PE32 身份、完整 SHA256、文件大小和目标 EXE 模块基址，验证通过后才创建文件。
- Windows 进程句柄只申请 `PROCESS_QUERY_LIMITED_INFORMATION (0x1000)` 与 `PROCESS_VM_READ (0x10)`。读取层不写目标内存、不分配远端内存、不创建线程，也不调用键盘、调试或注入 API。
- JSONL 第一条为 `header`，包含版本、SHA256、模块基址、时间和采样配置；中间 `sample` 记录角色、场景/载具、描述符、input 与保护动作；最后一条 `summary` 包含停止原因、样本数和错误统计。
- actor 的 `vtable + 0xCAC / +0xE0C / +0x428` 是函数指针槽。输出读取这三个槽得到的资格入口、普通命令入口和动作设置入口目标值，并保留槽读取失败。
- 场景布局最多每 250 ms 复用一次；场景范围、角色/VirtualCharacter 指针、载具槽位或载具标记变化时立即重枚举。场景最多读取 4096 项，载具最多输出 8 个。
- 单字段读取失败输出 `null` 并在 `errors` 中保留字段、地址（密钥链地址除外）、大小和错误；载具及 input 枚举同样保留边界、截断和行读取失败。
- 保护动作使用十六进制偏移 `manager + 0x24 + (handle >> 16) * 4` 与 `bank + 0x2114 + (handle & 0xFFFF) * 4`。字段、manager、bank、key 各读取两次完整快照；任一值变化或第二份快照不完整时 `stable=false`。
- 保护动作只输出 `handle`、密文、`action`、`stable` 和 `integrity`。key manager、bank、key 及其地址不进入 JSONL；integrity 不符时写 `protection.integrity / checksum_mismatch`。

采样是固定间隔状态快照，不证明两条记录之间发生过的函数调用顺序。上机步骤仍由测试者完成。

## 验证结果

Seeker复核补充：无效场景范围每次保留错误，部分场景读取失败时仍保留已经找到的载具并在下一次重试；描述符注册只有完整读取且未匹配时才记录 `false`，读取不完整记录 `null`。20秒采样从身份核验结束后开始，每条记录包含 `read_duration_ms`。新增回归后的26项测试通过，45组原生动作fixture及4项独立检查通过。

`scripts/client/at5t_collect.py` 提供交互入口：明确输入目标PID，倒计时5秒后采集20秒，结果保存到工具旁的 `reports/`。带命令行参数时沿用原入口。打包为独立诊断程序，当前支持V135/V141；玩家客户端后续版本需要核对字段后加入。

独立程序用PyInstaller 6.13.0打包；`--help`、无效PID、非目标程序及交互PID校验四项运行检查通过。采集时松开技能键后单按，待动作结束再重复，保留角色职业与每次尝试的表现。
