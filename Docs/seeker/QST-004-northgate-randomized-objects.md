# QST-004 主线完成后根特北门无法进入

## 已复现场景

真实 PVF SHA256 `fef4f46f6c3096d10cd88c84579dea8bd4fffa18e5a75b4684a2e920864f5525`，副本88（`dungeon/act7/gentnorthgate_r.dgn`）。67级角色经实际主线券 planner 完成任务后，准备副本入口失败；四种普通难度均相同。

对照中，任务3528活动时选择剧情迷宫1、起始图92263，四种难度均可准备。完成主线后选择普通迷宫0，报 `prepare randomized dungeon objects before admission: unsupported randomized object group 0`。没有活动任务的对照也出现同一错误。

## 成因与待确认语义

`worldmap.FreezeRandomizedObjects` 只接受 `[regenerate] 0`。北门普通迷宫声明 `[select] 1`、`[regenerate] 99`，对象61235、neutral阵营、房间(3,1)、坐标(216,240)。因此进入普通迷宫时在随机对象预检被拒绝，主线券只是使角色离开无此对象的剧情迷宫。

下一步核对 `regenerate=99` 的客户端生成/再生语义、对象61235所属模板及已有房间重进处理，再补对应实现。保留随机选择、房间和来源验证；测试不通过修改PVF删除对象来绕过问题。

## 修改范围和测试目标

- 范围：`worldmap/randomized_objects.go`、必要的bridge随机对象处理及对应测试；若要变更回包布局，先补匹配客户端证据。
- 真实PVF：任务3528活动、67级主线券完成、无活动主线，普通难度0至3分别验证副本88入口。
- 核对对象61235在声明房间生成、阵营/坐标正确，离开重进及组队沿用所属run的选择。
- 既有安徒恩5选8及固定精英、未知对象和错误房间等回归保持。
