# QST-022 再次挑战跳到后继副本

## 成因与方案

结算按钮的再次挑战与开始下个任务共用 `{1,0}` 请求。服务端先由当前任务迷宫寻找后继副本，再尝试正常接取后继任务。当前任务未交付或后继条件不足时，接取会被正常拒绝，但旧代码仍使用后继副本作为重进目标，因而离开尚未完成的任务地图。

保留现有接取与失败重试路径；只有后继任务接取成功或已经活动，才切到其任务副本。资格不满足时沿当前副本和原难度再次挑战。存储或投影失败保持现有退出门重试。

## 测试与验收

- 当前任务仍活动、进度未满、进度已满待领奖：再次挑战进入原副本，后继任务保持未接取。
- 后继正常接取或已活动：进入后继副本并发送活动任务投影。
- 任务接取保存、结果丢失或投影发送失败：保留原运行实例及资产，重试只接取一次。
- 当前PVF的山之泪在材料未取得、取得未交付两阶段选择再次挑战，均应回利库天井；正常交付后由原后继选择逻辑继续。

修改限于结算按钮选图条件和回归测试。允许失败，返回实际失败与所需证据。
