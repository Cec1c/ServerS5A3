# QST-025 寻找阿甘左的剧情结算复核

## 目标与现有处理

任务3213要求完成第二脊椎的53529地图。该任务迷宫的敌对阿甘左为APC2004，Proc动作在香料对象触发后将自身HP置零。服务端已有对这一剧情死亡的识别：核对当前任务、地图、已宣布的APC和实际Proc定义，接收无战斗贡献者的死亡报告，推进清图与任务进度。

本次反馈为使用香料使阿甘左死亡后没有关卡结算。旧专项已覆盖最终房间的死亡与结算；本轮增加从正常接取到正式交付的连续复核。

## 本轮验证

当前PVF的有限原文提取测试通过：领域接取3213，逐房通过生产死亡与移动入口推进7个房间、55个普通怪死亡报告，在53529回放APC2004的剧情死亡，随后结算并通过正式op34完成任务。

同一流程已在当前完整PVF通过，7房、55个普通怪、最终剧情死亡与op34交付均成功。前置任务完成记录为隔离初始化；最终死亡报文是依据现有协议的兼容回放。香料的客户端触发、动画和实际报文仍需核对。本轮未发现新的服务端失败，不新增修复计数。

## 验收目标

正常完成前置获得香料，再接取“寻找阿甘左”；逐房抵达最终场景，使用香料使阿甘左恢复，出现结算并正常交付任务。记录最终房间实际死亡报文与结算表现，核对当前已部署版本。

原始资料、资产摘要、日志和实测记录保存在私有调查目录。
