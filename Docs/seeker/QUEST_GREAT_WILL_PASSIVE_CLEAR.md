# 《伟大的意志》剧情销毁报文与通关分派

## 目标与证据

任务 3447《伟大的意志》要求通关副本 7156 次元空间。匹配 PVF 的路线为 70184 → 70185；末房播放剧情 2001，地图被动对象 69292 在剧情结束后销毁。副本明确声明 `[clear condition][destroy object] 69292 1`。

客户端的被动对象销毁报文包含完整 u32 定义编号、owner `FFFF`、零战斗条目及偏移 37 的标记 `1`。该标记同时用于明确的副本销毁条件和类别 3 任务材料来源，不能据此将报文视为仅有材料掉落用途。

公开基线 `65a72c14d9007251af95549a0d640a94fb4d972b` 中，正式网络入口带序号调用材料掉落处理；没有匹配奖励时仍记录事件已处理并提前返回，使后续已有的销毁条件通关入口不可达。旧测试直接调用无序号 handler，或使用标记 `0`，未覆盖此冲突。

真实 PVF 对照测试已复现：前两条路径发出 op115 与结算入口，正式 op39、标记 `1` 的路径没有回包，副本保持 active。

## 实现范围

- 保留材料掉落与地图掉落处理、事务失败重试及来源次数限制。
- 对同时符合当前房间明确销毁通关条件的报文，继续进入原有通关分支；普通被动对象处理后仍终止。
- 沿用当前 boss 房、地图一致、房间敌对目标已清除、恰好一次摆放、目标与 count 精确匹配的归属证明。后续原有 owner、报文形状及 actor 分派保持。
- 保留卢克对应副本的队友完成处理、重复报文幂等及延迟回城取消。不向客户端已销毁的定义编号发送 op38。
- 修改范围为 bridge 分派、定向测试及本文/变更记录；无需改 PVF、客户端或玩家任务存档。

## 验证与验收

1. 正式网络入口回归带序号的标记 1 报文，保留标记 0 和无序号对照。
2. 使用真实 PVF 完成接取、选图、移动至末房、op39、op33 进度及 op34 交付，验证重复报文。
3. 验证错误对象、错误房间、未清敌对目标、摆放及 count 不匹配不触发通关；正常任务材料领取不受影响。
4. 运行领域、bridge、控制器测试及构建检查。真实 PVF 用 `DNF_WORLDMAP_REAL_PVF_SMOKE` 显式提供；未配置的资产测试为跳过。
5. 部署后以 54 级待完成任务进入次元空间，经过两房、播放或跳过剧情，检查完成提示及后续任务。源码验证、部署与玩家验收分别记录。

## 已验证结果

- 匹配 PVF `95147859374186dbeb99f998829a1c642f949e56942ac98be8b5af4492aefe1c`，三条对照路径均完成接取、两房移动、op39 通关、op33 进度归零及 op34 交付；重复 op39/op34 不再发送结算或交付回包。
- 客户端 `534b5ef166d0090d1ab88e01f5f443721abf97eabfacfb007e04e30fd9d51b24` 的有限原生验证执行条件解析、匹配、减计数及报文写入，六项通过。实际解析结果为类型 0、定义 69292、计数 1；未使用人工任务材料条件替代本副本条件。
- 原生测试的文件读取、容器、局部控制及传输为定点夹具，完整游戏场景和视频播放由实机验收覆盖。
- 定向测试共 53 个叶用例通过，包括正常材料任务 3735/3954/3955 的真实 PVF 接取、收集和交付，以及事务失败后同序号重试。
