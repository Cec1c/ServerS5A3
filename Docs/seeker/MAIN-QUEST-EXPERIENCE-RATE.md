# 主线经验倍率

## 目标与成因

测试服反馈主线升级偏慢，本次将正常主线交付经验调整为现有值的3倍。当前经验由服务端`quest/finish_owner.go`依据PVF、成长契约和经验药计算，在角色结算事务中保存；客户端/PVF无需改动。`progression/QuestExperience`仍保留基础规则，避免影响副本经验和其他玩法。

## 方案

- 新增服务端配置`DNFBRIDGE_MAIN_QUEST_EXP_MULTIPLIER`，默认1，支持整数1..100。本服设置3。
- 在正常任务结算输入增加可信服务端倍率（零值按1），由bridge启动选项传入，不能使用客户端请求中的Multiplier替代。
- 主线范围为PVF grade epic，以及通过MainQuestID关联到epic的子任务；无经验标记保持0，其他任务按原值。
- 先按原规则计算基础与既有经验加成，再把基础、加成、合计同时乘倍率，保证相同条件下最终领取值正好是原来的3倍。以uint64检查uint32上限，越界时事务不写入。
- 继续使用现有持久结算回执；倍率变化后重放旧回执不重算、不追加经验。完成券/手册跳过不调用正常领奖逻辑，不增加奖励。
- 生成器从实例字段`main_quest_exp_multiplier`写环境值；统一更新入口将这一个配置项固定在manifest中，保留备份/回退并核对实际进程值。同步使用上游MR及GitHub单向镜像。

## 测试目标

1. 主线同一夹具1倍与3倍，最终基础/加成/合计均精确3倍；包含契约、药水、升级及技能点结算。
2. 支线不变；合法主线子任务适用、无经验步骤仍0；错误/缺失父链不误算主线。
3. 倍率变化后重放保持原回执，失败事务不扣材料、不发奖励、不改经验；溢出拒绝。
4. bridge配置正确传入，0默认及非法环境值按1；实例/profile非法值拒绝；源配置、容器及进程读回一致。
5. 原主线券无奖励语义、领域/bridge/control及仓库必需检查通过。真实PVF选取低中高等级主线，对比1倍/3倍结算。

## 验收目标

上线后用正常交付的主线比较获得经验及角色经验变化，确认3倍、升级后经验/SP保持，重复点击不重复领奖。任务手册预览仍可能显示PVF基础值，实际入账与服务端回包为验收依据；不追补历史任务。
