# QST-007：剧情 APC 销毁报告兼容

任务3538「夜战司令官巴比伦」，副本89、迷宫3的第四房92334，真实basic action在单次ON START MAP调用CMT2216。CMT明确对APC静态index1（敌对10409）执行DESTROY，show=0、reward=1。

## 成因与实现

匹配客户端的show=0 DESTROY调用APC死亡发送器。当owner和正贡献记录为空时，合法请求为ownerFFFF、count0、原因7。原服务端只支持战斗死亡或既有PROC来源，拒绝该CMT报告，未同步对象死亡状态。

修复沿活动clear-map任务、当前迷宫与地图、已宣告敌对对象、真实ACT→CMT链接和精确APC主体索引证明来源，再复用权威死亡、op38通知及重放。限定闭合单次ONSTART、ME行为和show=0；省略开关采用原生默认show0/reward1，reward0同样允许。重复开关、错误类型、未知值、show1、错来源和非零贡献不由本分支授权。APC与MONSTER索引分开处理，友军保持原状态，不修改PVF或EXE。

原基线五个普通怪清完后，服务端已允许过门。原生DESTROY行为下一tick自身结束，不依赖op38；op38另有APC对象收尾作用。因此本项是已证实的脚本销毁兼容修复，原反馈的画面不开门仍由实测确认。
