# QST-017：年轻时的吉赛尔击杀进度

## 目标与成因

任务 3687 要求在地下城 72 击杀怪物 56158，正常领奖获得零件 10164766，再回地下城 517 完成 3688。真实 PVF 的 517 → 72 → 517 顺序成立。

公共基线 `967cc282` 已有 `[hunt monster]` 领域规划与持久化函数，但正式怪物死亡入口只调用 `[hunt enemy]`，没有调用 `persistCurrentDungeonHuntMonsterKillPhaseA`。因此死亡确认与任务进度可以脱节。

## 方案

在权威普通怪物死亡与既有掉落处理后调用现有 hunt-monster owner；保留普通死亡通知、经验和Boss清房顺序。保留 hunt-enemy 和正常 FinishQuest 奖励结算。记录本次副本、房间、对象的处理结果；保存失败可以重试，保存后发包失败不会重复扣进度。死亡重放补齐未完成的任务处理。

修改范围为死亡入口、hunt-monster 桥接及必要运行回执；使用内存仓储和真实 PVF 做验收。

## 测试与验收

- 正式死亡入口：3687 从剩余 1 变为 0，奖励状态 pending；死亡本身不发零件。
- 正常领奖只获得一份零件，随后 3688 能交付。
- 错副本、错怪、未知对象、未接任务保持进度；同一死亡重复上报不重复计数。
- 多只怪分别计数；保存失败重试、保存后发包失败重试均只计一次。
- 真实 PVF 核对任务链、72 的任务迷宫及怪物 56158，再执行死亡与领奖链。

实测目标：按正常主线进入对应副本，击杀吉赛尔、取得零件、回到下一段剧情完成交付。

## 当前结果

正式死亡入口已通过修复前失败、修复后通过的回归。任务进度与事件摘要在同次任务保存中记录，重复事件和提交结果丢失后的重试不会再次计数。成功完成目标后清除临时事件摘要，保留最终完成回执。

真实PVF专项通过：正常接取父任务及带奖励的3687子任务，选择地下城72的任务迷宫2，在地图91857通过正式死亡入口击杀56158；任务变为待领奖，正常领奖获得一份10164766，重复领奖不增发，3688交付扣除一份。前序517清图由既有领域入口模拟，路途中清房和NPC回调为测试输入。
