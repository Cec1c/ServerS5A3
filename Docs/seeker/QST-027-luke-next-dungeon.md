# QST-027 普通卢克下一地下城

## 成因与目标

普通卢克结算后点击“下一地下城”，重新进入诞生之圣所。真实PVF序列42列出5101、5102、5103、5104、5105、5106，并启用`[next dungeon auto enter]`。

当前op72 `{1,0}`沿`retryCurrentCompletedDungeon`重进；代码仅解析任务迷宫的后继任务，普通卢克没有该连接，因此复用5101。真实六图定义的隔离测试已复现：结算菜单请求后，新runtime为5101，期望5102；难度保持2。该测试从已完成结算状态开始，不覆盖此前战斗。

## 方案

在现有结算重进链加入普通卢克序列42的后继选择。读取批准PVF的顺序及自动进入标记，选择当前图的下一项，沿既有选图、组队、入场和城镇返回逻辑创建新run。适用范围为普通卢克，剧情后继及团队副本沿用既有规则；末图保持现有再次挑战行为。

在退休旧run之前完成序列和目标检查；读取失败时保留本次结算以便重试。进入机械王座继续执行各角色已有的五图前置校验。沿用当前难度和入场参数，保留一次性退出与奖励门槛。

主要入口：`dnfbridge/dungeon_card_flow.go`、`dungeon_luke_normal_rules.go`及独立回归文件。可复用现有序列42解析，普通王座入场语义保持。

## 测试与验收

- 当前失败场景5101→5102修复前失败、修复后通过，最终下行包含正常选图与地图进入包。
- 顺序覆盖5101→5102→5103→5104→5105→5106；末图、普通非卢克、剧情和团队副本保留原行为。
- 尚未完成结算、重复点击、组队非队长不重复入场或扣费；队长带队进入同一目标。
- 序列缺失或错误、目标不存在时保留旧run；机械王座前置不足仍拒绝入场，满足条件可进入。
- 普通回归及完整bridge、领域、control、list、vet与双平台构建；真实PVF专项串行执行。
- 用户实测：正常打通诞生之圣所，结算后选择下一地下城，进入湮灭之圣所；继续推进并核对末图行为。

允许失败，返回已尝试方法、失败证据、当前修改和下一步所需信息。

## 实现结果

- 普通卢克 op72 `{1,0}` 在退休旧 run 前读取序列 42；只有 `[next dungeon auto enter]` 明确存在、当前图位于序列且下一图已载入世界地图时，才选择后继。标记关闭时保持原同图再次挑战。
- 5101→5102→5103→5104→5105→5106 连续推进；5106 没有后继，保持现有同图再次挑战。
- 序列读取失败、顺序定义错误、当前图不在序列或自动进入目标未载入时，不退休旧 run、不扣入场资产，并重新开放本次结算动作。
- 手动机械王座前置只读取序列顺序，不依赖 `[next dungeon auto enter]`；自动进入关闭仍可由已完成的 5101..5105 手动进入 5106。
- 剧情后继优先沿用原任务链规则；团队副本、非普通卢克及末图原行为不变。团队与单人仍由既有队长进图和机械王座五图前置校验接管。
