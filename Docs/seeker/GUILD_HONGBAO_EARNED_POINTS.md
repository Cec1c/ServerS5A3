# 红包贡献榜的获得数

成员 `ContributionPoints` 同时累计两类来源：公会地下城旧 `[contribute]` 分数，以及会发放贡献币的签到、聊天、组队/公会通关活动和红包结算。红包页直接展示混合值，因此与本页规则的获得数不符。

保留存储和旧消费者，通过原有不可变地下城结算回执，在公会锁内只读扣除同公会、同账号、同角色、当前入会时间之后的旧地下城分数。真实活动和红包所得保持，消费贡献币不会倒扣累计获得数。没有对应回执的存量分数不凭空扣除；矛盾或损坏回执拒绝展示，避免下溢或虚构奖励。

仓储提供限定为地下城结算回执的遍历接口。MySQL 在当前事务内读取写入分片，内存仓储在同一公会锁下提供快照；不读滞后副本、不改表、不回填成员/资产。查询按最早入会时间和结算 scope 前缀限制范围。

验证覆盖混合值 74→14、独立成员、退会重入、账号归属/公会变化、活动所得保留、重复查询不写数据、回执异常、写入分片与公会事务中的读取。发布仍累计保留既有线上修改。
