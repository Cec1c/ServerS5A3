# 账号适级通关榜

该候选复用冒险团适级通关，不另设等级、难度或副本资格。客户端增加第三类榜单；是否生成、安装和执行实机验收由独立发布流程记录。

- 权威累计键仍为 `adventure_recommended_dungeon_clears`。累计榜直接读取未删除角色的原值，再按账号汇总；没有历史回填或第二份累计迁移。账号分数使用 64 位相加，冒险团原生 32 位显示饱和规则保持。
- 资格只取现有 `currentDungeonIsRecommendedClear`；入图等级与副本推荐区间、服务端接受最终房间完成的条件保持。深渊最后一波与完整副本结算的区别沿用当前冒险团规则，不添加过滤器。
- 同一成功结算在原事务内记录一条 `recommended_clear` 日期事件，和经验、战令、冒险团累计共同提交或回滚；结算回执及账号/角色/局次哈希避免重放重复计数。日期沿用北京时间 06 点服务日、周一 06 点换周。
- 日周榜只包含接入后记录；已有累计不拆成历史日周。日期账本保留删角前的已提交贡献，累计榜随冒险团现存角色变化。
- 查询沿用认证游戏连接 class1/0x7f02，指标 0 疲劳、1 史诗、2 适级通关；请求与回包长度、分页、账号隔离、64 位分数及缓存限流不变。旧客户端 0/1 继续可用。
- 原生月榜下拉准备九项：三种指标各有今日、本周、累计；角色贡献、原公会榜、个人统计、战令和已安装 NPK 布局保持。
- 周结算支持新增指标的外观待发资格。没有配置实际外观、定时发奖或创建奖励道具。
- 累计查询使用主库现有角色统计表和角色删除标记，一条语句覆盖写分片，不加载全服背包或拾取明细；复用 15 秒缓存和后台查询上限。

源码准备、专项用例、编译和安装分别记录，不能用源码存在推断游戏验收。
