# 账号统计分组与排行榜筛选

排行榜下拉只保留疲劳、史诗、适级通关、无色、金币五类，今日/本周/累计使用独立按钮。切换榜单保留当前周期，切换任一筛选清零分页并废弃旧请求。继续使用原公会月榜的独立实例、原生下拉和分页，不改原公会窗口。

账号统计按通关、装备、消耗、史诗来源四组展示。每组上方只放本组账号汇总，下方为本组角色贡献；默认隐藏全零角色，可切换全部角色。史诗来源独立分组，移除旧的来源切换按钮和主屏重复铺设的四条来源文字。顶部显示冒险团与当前角色，移除重复的账号统计标题。

消耗组包括疲劳、实际无色和金币养成费用；通关组包括适级及深渊；装备组包括史诗、粉装、传说；来源组展示四类史诗来源。金币口径与排行榜相同，排除 NPC 买卖/转账；适级累计复用未删除角色的冒险团原值，日周使用现有成功通关账本。只读取既有数据，不重新记账或清零。

沿用 class1/0x7f00，只读请求 `PSQ2` 仍为 12 字节，`PSR1` 外层不变。新 `PSA3` 在原四项头文字之后添加冒险团名，每个周期及角色的指标从五项扩为八项，顺序为原五项、适级、无色、金币养成；四项史诗来源不变。`PSQ1` 仍返回 `PSA2`，客户端解析保留 `PSA2`；缓存按格式分别核对，避免新旧格式串用。64 KiB 容量、账号会话鉴别、后台查询、换角色隔离和限流保持。

分组与周期切换在客户端复用同一份快照，不增加每次点击的数据库查询。扩展快照复用原三次汇总，额外只读取一次当前账号冒险团名；不加载背包或额外扫描全服榜。游戏 EXE 生成、安装、原生交互和视觉效果由独立发布流程验收。
