# 公会成员在线状态与最后在线时间

本单元补齐成员最后在线时间的保存链。此前名单以 `LastOnlineAt` 计算离线时长，但生命周期没有写入该字段，缺值时一直退回入会时间。修复前已复现登录、断线、返回选角和直接换角色四种场景均未更新时间。

## 保存与刷新

- 在 canonical 角色绑定或真正移除的临界区内捕获账号、角色和观察时间；释放运行时锁后进入 Guild UoW，重新校验角色归属和成员归属。
- 最后在线时间单调前进；旧事件不能覆盖新事件，也不能写入观察时间之后才加入的成员关系。重复绑定和名单查询不写入。保存失败保留旧记录并记日志，连接清理继续完成。
- 辅助连接关闭、同角色连接接替及被替代连接的迟到关闭不产生下线记录；在线状态仍取当前 canonical 连接、账号和频道。超过角色 ID 范围的记录不再截断后冒用另一个在线角色。
- 保存成功后重新核对同会接收者的成员关系及会话代次，更新管理状态和已订阅名单。角色资产、贡献、里程、出勤日期及成员职务保持原值。

## 协议与限制

已匹配客户端模块 SHA256 `6fd3183de3cff52fa2feb5a5327ca43855cabbc6b0b63d920a87ab8ddf316da5`。成员回调 RVA `0x01bd2d10` 在品级字节之后读取一个 DWORD，并保存到成员模型的 `+0x154`；频道字段独立处理 `0xff`。本次保持既有秒数编码和包布局，没有新增 EXE 修改。该字段在原生 UI 中的时间单位、取整及刷新表现尚待进一步确认，不把回调位置核验当作原生显示验收。

正常离开后持久化准确的服务器观察时间；进程崩溃或保存失败时只能保留最近一次成功保存的观察时间。没有后台心跳、伪造崩溃时间或读取触发的补写。旧成员没有历史记录时仍使用既有入会时间回退，不能据此恢复丢失的登录历史。

## 验证与交付边界

自动化覆盖生命周期、辅助连接和接替、账号归属、只读查询、失败回滚、迟到及并发事件、离会后重入、独立名单解码、同会刷新、跨公会隔离和新 Service 重读持久状态。源码使用独立候选，不包含尚未接通的退出/踢人草稿。

该项只覆盖成员列表范围中的生命周期部分。排序、分页、其他管理流程和原生多人验收分别跟踪；真实数据库验证未执行。累计候选仍依赖前序公会客户端修订，发布与实际玩家通道验签/配套资产摘要一致的部署门槛继续适用，不能单凭本项无需新 EXE 补丁部署累计服务端。
