# 普通装备零上浮等级窗口

现用PVF的`item drop ref table`给89级怪物配置`89 6 0`，表示从83级至89级以下的装备模板选取。共用装备选择器曾把上浮值0当作无效参数，即使83～88级的自然装备池有候选，也直接返回未选择；普通杀怪和使用同一引用的翻牌均受影响。

修复仅将上浮值的拒绝条件由`up <= 0`改为`up < 0`，沿用左闭右开的等级窗口。负值、越界值和空窗口继续不产出，不放宽模板自然生成资格、品质或等级限制。外层掉率、品质概率、抽取次数和现有白装回退保持。

单元回归比较`89/6/0`与等价窗口`88/5/1`的物品和随机数状态，覆盖上下界、四种自然品质、两条选择入口及无效/空窗口。真实PVF回归覆盖89级四品质选物、翻牌装备实例生成、普通怪和领主自然掉落及重复拾取一次入包。89级为隔离夹具解析出的怪物等级，不把该夹具称为真实时间广场的原始等级配置。

本项不修改PVF或客户端；源码、构建、安装及游戏内验收分别记录。
