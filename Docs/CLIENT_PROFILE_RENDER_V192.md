# 跨地图成员资料窗口副职业绘制

资料窗口已收到目标的副职业种类和经验，但副职业等级查询仍依赖场景角色。辅助资料对象没有场景角色，或者该角色不再提供资料对象时，原查询返回 `-1`；绘制函数随后使用 `level-1` 访问资源数组，触发边界检查并终止客户端。

修复只改变资料窗口的这一处绘制续接。先保留原等级查询，清理其两个调用参数并核对资源数组；原结果为 `-1` 时，使用窗口已经解码的目标经验调用原生资源表的经验转等级函数。有效的原等级（包括原生上限结果）保持。零值、其他负值、越界值及缺失或不完整资源均不访问数组；该行仅保留标签，不伪造等级，也不把缺资料误显示为“无副职业”。原无副职业分支保持。

补丁接受精确正式 V192，新增独立只读执行节 `.prender`，保留来源通知、红包、频道名称、菜单刷新及售货机提示。生成器核对输入 SHA256、PE 布局、完整原指令、独立输出和所有声明范围以外的字节。不会运行游戏、修改玩家文件或服务端数据。

回归从原资料行 renderer 入口执行到原函数返回，覆盖缺少/失效场景角色的原版失败、新版经验阈值、原等级上限保持、缺表/空表/异常向量、无副职业、连续绘制及栈和保留寄存器。原场景 getter、等级查询、经验转等级、数组边界和函数尾声执行实际机器码；资源管理器查找、受保护数值读入、字体/字符串与图形输出为明确夹具，不代表完整窗口、网络或游戏画面验收。合成经验阈值用于核对计算，不冒称实际 PVF 的等级数值。

运行 `DNF_PROFILE_V192_CLIENT=<精确V192>` 后执行 `python -m unittest test_profile_render_v192 -v`。最终独立构建、磁盘候选及 Windows 非执行映像验证分别留证。正式发布和玩家“查看资料”复测仍须另行确认。
