# 婚姻客户端收包准入与使用说明

本次服务端接入依赖原生婚姻处理器能收到对应报文。仅补服务端时，可能出现没有失败提示、宾客不能入场、倒计时不播放、家具不刷新或配偶升级无提示。下面的脚本补充分类收包门槛，保留原生界面、位图、处理器及已有准入回落链，不添加 DLL。

## 精确版本与执行入口

脚本只接受下表中的精确 EXE；所有阶段文件长度均为 **112549888** 字节。这里的 SHA256 用于确认模块身份，不表示当前玩家下载通道已发布该版本。其他累计 EXE 必须重新核对地址、原指令及预留空间，不能删除哈希校验后强套。

| 阶段 | 输入 SHA256 | 输出 SHA256 | 准入变化 |
| --- | --- | --- | --- |
| 基础婚姻 | `a5f1d5ef432064cccaeac6362d5f1405fceddd62739da85661154fc008d47f7d` | `7ae08949bd575990db56003f848dee511717fb3a382e15561171bc6fa37fad6e` | 18 个显式分类项，实际新增 16 个 |
| 礼堂、宾客、婚房扩展 | `7ae08949bd575990db56003f848dee511717fb3a382e15561171bc6fa37fad6e` | `d11237feaaf8535429eed59545d69a36e67c5760370ae07185eac85db8e55853` | 新增 22 个 |
| 配偶婚戒通知 | `d11237feaaf8535429eed59545d69a36e67c5760370ae07185eac85db8e55853` | `a59db943c5f44c82e7db0e02305b3403aac3a16d0ec025b396e97da491a42231` | 仅新增 C0/1001 |

推荐统一入口，自动从上述已知输入的相应阶段继续，输出最终版本。参数路径为示例，先替换为自己的备份与独立候选路径：

```text
python scripts/client/patch_wedding_receive_complete.py --input "backup/DNF.exe" --output "candidate/DNF.exe" --receipt "candidate/wedding-receive.json"
```

构造候选只需要 Python 标准库。输入与输出必须不同，输出及回执必须不存在；未知版本、变动文件和已完成版本均拒绝，不覆盖现有玩家文件。单阶段实现为 `patch_wedding_receive_admission.py`、`patch_wedding_full_admission.py`、`patch_ring_notice_admission.py`，其中前两个也支持 `--input/--output/--receipt`，最后一个由统一入口调用。

只读核对原件与最终候选，可在 Python 独立环境中安装 `capstone==5.0.9 pefile==2024.8.26 unicorn==2.1.4` 后执行：

```text
python scripts/client/verify_wedding_receive_complete.py --input "backup/A5-DNF.exe" --candidate "candidate/DNF.exe" --report "candidate/native-check.json"
python -m unittest discover -s scripts/ci -p test_wedding_client_tooling.py -v
```

第二条不需要客户端资源，只检查工具契约。第一条要求最初 A5 原件和最终 a59 文件，完整执行两类各 65536 个操作码的前后准入链，共 262144 次原生调用，核对实际仅新增 39 个分类项，并执行逐分类 ABI 样本、校验和与范围检查。分类 2～255 使用不依赖操作码的回落结构证明和逐类样本，没有宣称执行完整 1600 万项矩阵；这也不等同于联网或图形实测。

## 修改范围、发布与回退

接收调用点 VA `0x2523A13`，第一层适配器 `0x6F8B400`，扩展适配器 `0x6F8B500`；最终扩展为 304 字节，非目标回落至第一层及原入口 `0x6F06100`。仅改接收调用、RX 末节原有零预留、末节 VirtualSize 和 PE 校验和，文件长度、共享位图和原生业务处理器保持原样。

最终相对 A5 的文件偏移范围为 `[216,220)`、`[4064,4068)`、`[34748947,34748952)`、`[112546816,112547065)`、`[112547072,112547376)`。最后一层仅增加 C0/1001，不另改调用点。

公开提交只提供源码和验证工具，不携带 EXE/PVF/dstr，也不发布玩家 Release。部署前按照 [客户端发布同步规范](CLIENT_RELEASE_SYNC.md) 先完成正式客户端 Release、指定镜像和实际玩家通道验哈，再部署依赖这些报文的服务端；配套启动器如绑定精确 EXE 哈希也需同步其已审定版本记录，不能放宽为任意文件。

安装前正常退出游戏，整组保存 EXE、启动器版本绑定、配套资源身份及服务端回退版本。出现问题按同一备份组恢复，避免单独回退 EXE 后服务端仍发送新增报文。脚本自身不执行安装、停止进程或修改启动器。

时间选择框、申请弹窗文案、公会名单客户端查询、同性结婚均未包含在 EXE 改动中。婚姻属性还需要服务端的角色创建字段、婚姻及婚房快照，单独开放报文不能替代这些状态链路。
