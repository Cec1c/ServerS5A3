# V110 公会成员菜单空对象修复

状态：已捕获原版崩溃，独立候选通过局部机器码回归；尚未发布、安装或完成修复后的游戏内验收。

输入 EXE SHA256：`fc4fa42ce9fd47307992fb6808840e68f84d89285570c383a100918aa641c3de`。
候选 SHA256：`413bbe6b900c419ec430ec10ba9acd3307d678351d423be6ae6007ce91078bd4`。

公会名单支持按名字打开不在当前场景的成员菜单。成员的社交区服为零、菜单未持有场景角色时，原生菜单仍调用角色区服读取器，解引用空对象的 `+0x3ac`，发生 `0xc0000005`。实际异常位于 RVA `0x02561d40`，直接返回地址为 RVA `0x03143c75`；服务端名单完整且身份字段为零。社交身份与当前场景公告编号有不同用途，不能通过改写持久角色身份绕过崩溃。

修复只重定向 RVA `0x03143c70` 的单一调用。新增只读可执行段中的局部读取器在对象为空时保留零身份，非空时按原字段读取；保持返回值之外的寄存器、栈与标志，不修改全局读取器、权限检查、原接收位图或其他公会补丁。

生成独立候选：

```text
python scripts/client/patch_guild_member_menu_v110.py <V110输入EXE> <新候选EXE>
```

工具核对完整摘要及 PE 布局，拒绝未知输入、覆盖已有文件和原地修改，不安装客户端或修改玩家更新通道。
