# 安徒恩组队接纳与单人奖励边界

团队内成员通过普通组队组成实际入场小队时，原普通队伍与团队分组可能不一致，随后在冻结参与者时被组号校验拒绝。本次在接纳普通队伍后，为同一团队的成员原子规划合法小队和槽位；新团队邀请、申请审批也直接分配合法位置，并在首次开团前物化历史组号 0。

规划保留组长的有效组号，计入已占容量，处理历史重复槽位。整队放不下时不部分移动；有活动副本或当前参与记录、绑定失效、已冻结账号与当前账号不一致时不改分组。普通组队只修改 live roster，奖励冻结名单保持原值。route2 保持八个单人组，普通队伍不合并单人组。

普通组队接纳后为城镇队员补发既有双向 actor 投影。继续保留同区、频道、团队实例和公会区域限制。同区已存在角色不重复创建；此变化覆盖跨区域组队缺少 actor 的路径，不能据此证明所有城镇不可见现象已解决。

单人安徒恩的地面掉落规则冻结在实际入场记录中，怪物、被动对象及主动丢弃等入口沿用统一规则，团队状态消失或阶段改变不会恢复地面掉落。单人卢克与普通地下城保留原有规则。单人安徒恩不创建普通地下城翻牌计划，不重复发送普通翻牌界面；普通结算的经验事务及幂等回执保持，团本专用奖励流程继续负责团本奖励。
