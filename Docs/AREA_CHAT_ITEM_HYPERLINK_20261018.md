# 普通区域聊天装备链接转发

本项处理普通区域聊天中的装备链接。用户在 v137 预览确认装备链接已修复。范围不包含背包整理或排序。

## 协议与范围

客户端上行使用 op424，类型必须为 3：`u8 type, u16 hint, u32 reserved=0, u32 message_len, message, u8 count, count*148B`。消息限 1..255 字节并拒绝 NUL；条目数限 1..5；正文总长必须精确匹配。`hint` 只作为客户端元数据记录，不用于确定发送者。

私聊、组队、公会及其它聊天类型不在本路径内。服务端对这些类型返回明确失败，不推测目标，也不伪造成功路由。

## 路由与身份

成功时先发送 class1/424 单字节 `01`，再向发送者本人及同频道、同场景、同实例的合法在线 peer 发送 class0/370。通知正文为 `u8 type, u16 sender, u8 channel, DSTR message, u8 count, count*148B, 空 DSTR`。

发送者取自当前绑定的角色会话，并校验角色记录的账号归属。旧 socket、已换角会话和账号归属不符的请求不会获得成功回包，也不会转发给其他玩家。接收方同样只选择当前绑定且在相同区域范围内的会话。

## 验证与边界

`go-server/internal/services/dnfbridge/online_item_hyperlink_test.go` 覆盖 1/2 条目、畸形长度、非零保留字、非法类型、NUL、零或超量条目、255/256 字节边界、私聊/异频道/异区域隔离、旧会话和账号归属不符。测试夹具只含物品名称与不透明条目字段，不含账号、角色名或凭据。

转发限于当前服务进程内的在线会话；跨独立服务进程的聊天转发不在本项范围内。客户端接收门与显示属于配套客户端版本，本仓库只保存服务端源码和测试。
