## 1. 线协议（当前客户端 DNF.exe 8bf1d39df74c6ca6fdbea30a95e055398aad9729305c7ea510ce01af2141e387）

C2S 438（0x1b6），发送端 0x25fae0c/0x25fae16 开包后写序：

| 字段 | 写入点 | writer |
| --- | --- | --- |
| u8 list | 0x25fae4d | 0x374f390 |
| u16 slot | 0x25fae5a | 0x374f3c0 |
| u32 itemTemplateID | 0x25fae67 | 0x374f3f0 |
| u16 materialSlot | 0x25fae77 | 0x374f3c0 |
| u32 名字长度 + 名字字节 | 0x25faebe | 0x374f550 → 0x374f4c0（长度前缀、无 NUL） |
| u8 confirmation | 0x25faece | 0x374f390（来自发送函数参数 [ebp+0xc]） |

现场样例（main slot 9、item 101011368、材料槽 121、两字节名字、confirmation 0）：
`00 0900 a84f0506 7900 02000000 ced0 00`。

class1 438 回包：注册 0x447a740（push 0x1b6 → 0x251e1c0 → 0x2524210/0x25242a0），回调 0x24836b0。
回调先 `cmp byte ptr [ebp+0xc], 0; je 0x2483b60`（成功字节由调度器消费），成功时按序读
u16 materialSlot / u32 materialRemaining / u8 oldLevel / u8 outcome / u8 newLevel / u8 targetList / u16 targetSlot
（0x2483751..0x24837b6），即回包体 13 字节；outcome 0 = 成功、1 = 掷点失败。
失败走 0x2483b60：先 0x12030a0 复位锻造 UI，再按错误码查表显示消息（错误码来自调度器参数 [ebp+0x10]）。
class0 438（0x200e590）是另一条只读 u16 的通知，与本族无关，不能当锻造 ACK。

## 2. 真实 PVF 参数（forge-client-evidence/real-pvf.txt；同一份运行时 Script.pvf，SHA256 369d072b82c715aea4e02813d89ad9225686983e147bc7be0ee0cae2e296bb06）

- `etc/upgrade_separate.etc`：`[separate upgrade max]` = **8**；`[table]` **10 档 × 4 个数**（档位 = 序号+1、第 3 个 = 10000 基成功率、第 4 个 = 材料倍率）；`[item weights by grade]` = 三元组（**grade**、材料模板 **3326**、基础数量，真档 1..25）；`[item weights by rarity]` = 7 个数（0.40 0.70 1 1.25 1.40 1.10 1.30）。
- 参考实现 `Game/Inventory/Services/InventorySeparateUpgradeService.cs`（A21，无 portable 实现，不盲搬）：
  - 普通锻造（:175-270）：目标必须是装备、模板匹配、未上资产锁、`EquipmentTypeInfo.IsWeapon`、耐久等于 PVF 元数据；`oldLevel >= MaxLevel` 拒绝；取 `[table]` 的 **oldLevel+1** 档；材料消耗 `max(1, int(BaseCount × ItemWeightsByRarity[rarity] × level.MaterialWeight + 1e-7))`；材料槽必须是对应模板的堆叠品且数量足够；掷点 `roll ∈ [0,9999]`，`succeeded = roll < level.SuccessWeight`；成功才把等级写成 oldLevel+1；材料已扣而目标写入失败时回滚材料（同一事务内显式补偿）。
  - 券路径（:60-160）：材料槽放券（数量 ≥ 1、堆叠、模板匹配）；`succeeded = roll < ticket.SuccessWeight`；成功 → 目标等级 = `ticket.TargetLevel`（`IsAdditional` 时 = oldLevel + TargetLevel，受 ApplyValue 上限约束）；失败仅在 `FailureDecrementLevel > 0` 时掉级（幸运锻造券为 0 → 保持原等级）。
- 券参数与目标白名单：`tickets.txt` 只是全部 stackable 的 `[reinforcement usable item list]` 扫描（42 KB，CP936）；每个券的 `[action type]`/参数仍需按 stk 逐件 dump 后才能实现（见第 5 节）。
- 便携式锻造炉 10164035（`stackable/10164001/10164035.stk`）：`[action type] = [portable genuine damage upgrade upgrede]`，说明文字明确「使用后可以对装备进行 1 次锻造；锻造时不消耗强烈的气息」→ 消耗炉子本身、不消耗 3326；`[need material] 10164052 200` 是购买/兑换要求，不是锻造消耗。
