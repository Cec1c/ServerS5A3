# 碳结晶体领主固定产出

史诗制作已读取并消耗碳结晶体 `10163135`，但普通材料池要求正数 `[creation rate]`，真实材料没有该字段；现用 WorldDrop、Independent_Drop 也没有该物品。教程“制作普通催化剂”只赠送一个，无法提供持续加工所需材料。

## 规则与实现

- [Neople 的90级史诗制作更新说明](https://www.dfoneople.com/news/updates/967/Epic-Weapon-Crafting-System)明确规定 Lv55及以上地下城的领主必掉碳结晶体。该依据来自国际服；不据此修改其它地区的交易属性或制作周期。
- 配套真实材料说明额外排除不消耗疲劳的地下城。等级取地下城 `basis level`，不是角色等级、当前剩余疲劳或单只怪物等级；等级缺失时不新增产出。
- 已有领主判定涵盖地图 rank、boss 后缀和怪物模板声明。普通怪、绿名、冠军不因所在房间是领主房而获得本项。
- 本实现每次接受领主死亡，为既有掉落归属流程中的每名接收者追加一个碳结晶体。它不参加随机抽取，也不改变普通掉落的随机数流；数量使用一个物品的最小单位，官方说明未单列数量参数。
- 普通怪物掉落和魔界裂缝、时空裂缝的专用领主奖励均接入；现有团本禁用地面掉落和材料抑制规则继续生效。
- 使用同一地面物品账本、原生119字节物品投影、拾取资产事务和死亡重放去重。沿用现有队伍独立/共享策略，不新增归属策略。
- 旧PVF未包含此物品时不新增产出。编号、物品类型、制作必需材料与真实90级PVF交叉校验；不修改PVF、客户端EXE或DLL。
