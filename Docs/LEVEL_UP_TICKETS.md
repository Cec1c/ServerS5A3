# 角色升级券

接入运行时PVF中 `[stackable type] [etc]`、`[action type] [level up ticket]` 的角色升级券，正常入口为 class1/op418，历史分发也登记同一处理器。SP/TP书、任务券、宠物及装备升级券保持各自入口。

## 使用与结算

按PVF核对最低/最高等级、增加级数、职业、城镇可用区域、冷却及硬核模式限制。没有权重表时固定增加 `levelup range` 级；有 `[booster info]/[etc]` 时按 `(1, weight, levels)` 抽取，零权重行不参与。目标超过服务器90级上限时拒绝。顶层 `need material` 为商店兑换价格，使用时不重复扣取；成功消耗来源券1张。

只在角色与场景均已就绪的城镇或赛丽亚房间使用；地下城、决斗房间或匹配、转场及绑定失效时拒绝。核对真实实例槽位、账号、锁定及到期时间，不续期历史活动物品。对尚未核验的额外规则拒绝使用。

扣券、角色等级/累计经验、SP/TP、冷却与任务在同一角色结算事务提交，任意写入失败均回滚。按PVF逐级增加SP/TP，保留已用点数、额外点数及技能；每个实际跨过的等级通过现有经验结算记录升级事件，交由既有升级奖励入口消费。提交后网络刷新失败不重复扣券，请求没有操作nonce，未知事务结果不自动重试。

历史存档累计经验低于当前等级起点时，按存档等级确定目标并补足目标等级的起始累计经验；SP/TP和升级事件只计算本次跨过的等级。缺失、负数、超过u32或达到下一等级门槛的经验，以及不一致的技能点账本仍拒绝。多级券同样只补到目标等级起点，不额外叠加原等级进度。

任务清理截止目标等级减1，只关闭可达普通/主线任务及其已激活子任务，保留前置、分支、碰撞和职业规则。跳过的普通奖励标记已结算；转职、栏位、深渊等特殊权限与每日/重复/活动任务保留。不另行实现描述中的QP、时间碎片或其它活动奖励。

## 发包契约与场景刷新

请求正文3字节：`slot:i16, list:u8`，只接受非负槽位及主背包列表0。成功正文12字节：`1:u8, slot:u16, list:u8, exp_gain:u32, sp_gain:u16, tp_gain:u16`。失败正文为 `0:u8, error:u8`，使用配套读取器的通用错误99；22专指预约角色，不能用于通用拒绝。错误class不进入结算。

成功顺序为418应答、来源槽位op14、同一已提交角色的op2 mode0资料与mode1本体属性、绝对经验/点数op37、已提交技能op19及激活/可接/已完成任务。两份角色正文先完整构建并重新核对绑定与场景owner，再依次发送；不重新选角或转场。完整mode1后沿用现有同实例宠物、称号附魔与换装buff恢复，黑暗武士沿用连招感知技能投影。

场景刷新职责参考S4A21城镇升级流程，字段与对象契约使用当前90实现。当前配套418的增量读取和37通知不能替代场景本体等级更新，因此先刷新角色资料及本体，再发37。保留90的12字节成功应答，不复制其它客户端的两字节短应答。

目标客户端必须支持并允许class1/op418及上述读取布局；接收许可与服务端字段正确性需要分别核对。本贡献仅含服务端与说明，没有客户端、PVF或接收位修改。切换客户端后须重新验证配套，单独开放接收许可不能证明等级和特效正确。

## 验证与范围

真实PVF索引中578件升级券，575件满足本实现规则；10001556限定服务器类型0、10156788带额外动作参数85、490004364缺少标准可用职业且有额外限制，仍拒绝。未索引脚本不计入可领取物品。不同PVF应按实际配置重新核对。

专项测试覆盖固定与权重多级、90级上限、店铺兑换材料保留、实例/职业/场景/冷却、历史低经验、已用SP/TP、逐级事件、任务分支和特殊奖励、并发及四个保存阶段失败回滚。真实PVF桥接测试检查请求分发、持久结果及418→14→mode0→mode1→37→技能/任务顺序。设置 `DNFBRIDGE_REAL_PVF_SMOKE` 为有效PVF路径可执行真实配置用例；不设置时相关用例跳过。可选 `DNF90_LEVEL_TICKET_FIXTURES` 输出合成测试角色的发包夹具，便于独立读取器核对。

累计部署中用户已确认升级券可用且出现升级特效；独立公开组合尚未另行部署，575件券、固定/随机多级、宠物及多人场景尚未逐项实机验收。局部原生回放的读取原语、对象查询等有桩，只证明读取与本体等级赋值链路，不能替代完整GUI、动画和多人验收。

可用10151463验证单级及89到90，10151466验证固定10级，满足配置等级时使用2683638等权重券。逐项检查扣券、等级与经验条、SP/TP、任务列表、后续道具使用及重登持久化。
