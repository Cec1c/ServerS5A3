# 公会福利购买与生效

本阶段接通匹配PVF的永久属性（内容1）、1/7/30天属性（2/5/8）及地下城杀怪经验加成（3/6/9）。永久属性花费36000公共积分；两类限时福利每天200积分。权限使用职位bit8，金币不代替公共积分。

## 购买与续期

限时商品按已批准规则续加剩余有效期，过期后从购买时间起算；同类型的不同天数商品共用有效期，不叠加倍率。永久属性只能购买一次，限时及永久属性分别生效。扣积分、福利状态和购买回执在同一公会事务内提交，失败全部回滚。

沿用761的连接序号幂等机制，回执可在数据库重建连接后读回。相同序号不重复扣费或延时；仓库、成员扩容与福利之间不能复用操作标识。跨连接重新点击视为新请求。非法币种、未实现内容与超出可表示期限的请求不收费；永久重复返回9，积分不足22，权限不足36。

## 实际效果

- **杀怪经验**：真实成员的有效福利在已接受怪物死亡时为基础经验增加10%，取整后计入既有等级/经验/SP/TP事务。与成长契约分别按基础经验相加，总额防溢出；通关及任务经验不调用此福利。经验总量按既有op37刷新，独立的公会加成分类字段与结算统计尚未映射，不冒充成长契约。
- **属性**：客户端按同一PVF的VariousBuff167（限时）、169（永久）应用四项60属性。各自有独立system group，共用图标206。未修改持久角色基础属性。
- **福利显示**：NOTI70投影真实生效状态、到期时间和余额；已过期福利不再显示。到期使用既有统一定时队列，重新检查会员与连接代次，刷新列表并移除属性；转场占用时延后重试，断开时取消。
- **续购及场景**：续购先移除全部旧公会属性，再重建有效实例，避免客户端更新参数却保留旧计时起点。重登及op24角色重建后恢复剩余效果；无有效会员身份时清除本连接已投影的公会效果。

服务端读取怪物死亡时的公会资格快照，经验提交随后继续校验角色/账号及成长版本；不追溯补发过期、退会或此前击杀。购买成功后的广播不持有发起者预约再逐个预约其他成员，保持既有锁序。
