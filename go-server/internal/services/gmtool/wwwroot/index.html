全服物品邮件 · 新角色福利

直接填写物品 ID 和数量，按当前 PVF 校验名称。同一规则每个角色只发一次，领取或删除邮件后仍保留记录。后续补发请复用同一规则；新建规则会独立发放。

新建规则默认停用。启用后，首次启用时间之后创建的角色由后台定时发放邮件；老角色需预览后手动补发。暂停再启用不清空记录，暂停期间创建的角色也可补领。

全服金币邮件

预览时已有的每个角色各一封，领取后金币到账。先预览名单，再确认发放；在线玩家可尝试重开邮箱，必要时重新登录。不覆盖角色现有金币。
