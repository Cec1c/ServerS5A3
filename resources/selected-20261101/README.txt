下载与重组

GitGud单次上传有大小限制，玩家资源ZIP为4卷，GM索引ZIP为8卷。所有卷的URL、大小、SHA256及完整ZIP摘要均在downloads.json。下载对应包的全部分卷到同一目录，执行：

python join_resources.py <下载目录> --output-dir <新输出目录>

工具先核对每卷，再重组并核对完整ZIP摘要；拒绝覆盖已有输出。解压后的每份资源还可按manifest.json核验。downloads.json的链接与本次资源发行一致。
