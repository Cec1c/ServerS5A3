# 六期礼包商品与赠礼配置片段

`chn_cerashop_multibonus.fragment.etc` 从当前配套资源精确提取，只包含 `private festival periods`、`private festival commodities`、`private festival rewards` 三节：六期期次/名称/重复赠礼、273项商品与期次映射，以及各购买档位的奖励物品和数量。

导入目标 `etc/chn_cerashop_multibonus.etc` 时按节整合，保留其中原有的其它优惠规则；不可用本片段覆盖整个文件。一个节只能出现一次。商品ID、奖励ID及道具定义必须在目标PVF中实际存在，服务端目录验证失败时不得伪造或略过依赖。

窗口路由60001–60006分别对应201601、201605、201607、201701、201801、201807。它们是客户端日历解析得到的页面标识；页面XUI由 `scripts/client/festival-ui` 的静态组件提供。

历史续期的50项节日规则和357项经验规则位于桥接层两个精确名单文件。它们要求物品ID、规范路径、旧实例期限和PVF目标期限均匹配，目标期限按现有PVF编码为1861826400；每日删除、相对期限、租赁或独立指定期限继续排除。只提交名单不会改变目标PVF的定义期限。

本目录不含完整PVF，不含其它商店、活动、奖励表或玩家数据。片段解析回归可以在没有私有资源的环境运行；真实PVF兼容检查需要操作者显式提供自己的匹配资源。
