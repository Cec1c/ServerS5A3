# 组队外观与相邻队伍记录复用角色构造

## 变更

- 城镇及副本投影已加载角色后，相邻 op9 队伍记录在同一次构造内复用该角色，避免再次完整读取。
- 复用结果深拷贝并绑定当前角色、账号与连接代次；后续重试重新读取，原成员、运行及发送前校验保持。

## 验证

- 实际隔离 Linux 42 项顶层测试、108 个通过节点，零失败和跳过，覆盖装备读取错误、换代、重新进图及准确 PVF 的超时空场景。
- 六轮恢复夹具中，被投影角色完整读取 18→12、接收角色保持 6，完整帧内容摘要与旧源码对照一致；后续重试读取改名后的新资料。旧源码计数负测按预期失败单列。
- 相关 vet、依赖、边界和正式 Linux 构建通过；该复用不跨请求，线上端到端收益及玩家画面需部署后验收。
