# 公会目录与历史查询使用按需投影

## 变更

- 账号公会列表、搜索和推荐、入会申请、资料访问及历史窗口改为精确源版本上的只读字段，避免每次读取完整公会源及无关历史。
- 仓库广播只选择有权限的成员，接收时仍走原查询复核；申请决定、创建和其他修改仍在原权威事务内验证和保存完整状态。
- 资料访问与婚礼邀请继续核实当前成员、账号、连接代次和入会时间，不向调用方暴露共享可修改状态。

## 验证

- 实际隔离 Linux 49 项顶层测试、137 个通过节点，零失败、零跳过；覆盖搜索、申请权限、创建同意、资料和历史回包，以及婚礼邀请的账号变化、离会和损坏数据。
- 相关 vet、依赖、边界和正式 Linux 构建通过。源码合入、部署及玩家验收分别记录。
