# GitHub 贡献模板、历史记录兼容与最新客户端展示

## 变更

- 新增错误报告、功能建议与 PR 模板，提供版本、操作过程、验证和资源依赖的填写入口。
- 接续 PR68 的历史片段校验修复：新增片段保持格式检查，既有缺章节片段保留原文并可参与发布说明汇总。手动 Verify 拉取父提交，避免浅克隆再次把历史片段当作新增。

- YAML 模板、贡献文档链接与 diff 检查通过。本次不修改游戏逻辑或玩家资源。
