# 容器自选元数据与零期限礼包定义兼容

## 变更

- 自选容器读取 default select 的 count+IDs 元数据，保留真实奖励行数量和类别，验证固定选项、选择数及重复项；无匹配奖励行的旧默认编号不生成奖励。
- 补原生 cera / special avatar 奖励标签，兼容明确正选择数量下的完全相同选项，以及无内容的相邻重复类别结束标签。冲突行、数量不明的重复行和嵌套类别仍拒绝。
- 零期限 package data include usable period 三元组使用奖励自身期限；非零覆盖期限未实现，明确拒绝而不静默遗漏奖励。
- 仅当全部实际奖励均能解析为堆叠物品时，允许原 equipment 标签携带的合法装备属性元数据；实际装备、混合奖池、缺失定义及非法值保持拒绝。不改变装备实例投影，也不改历史奖池。

## 验证

- 本地 overlay 对固定 PVF 的720候选逐ID记录 parse、dispatch、effect；对新增可解析自选项枚举选择组合并核对确切奖励、失败不扣、保存后事务回滚。旧生产源码 overlay 保留同一测试的失败证据。
- 当前原生EXE指令有界模拟验证元数据语法和奖励字段；不代表原生UI或游戏验收。两个历史礼包固定数量断言与当前内容不同，原源码同样失败，另以测试专用overlay核对当前数量，未改生产测试期望。
- 完整结果位于本地 AUD-20261101-002 容器证据与独立台账。本改动未部署、未上传、未操作客户端；最终全域/桥接/vet/build由主线程统一执行。
