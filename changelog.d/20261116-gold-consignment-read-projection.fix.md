# 缩小金币寄售搜索和均价查询的读取范围

## 变更

金币寄售搜索只读取挂单，单档位搜索和最近成交均价优先按档位读取。沿用现有仓储投影接口，旧仓储继续兼容；投影失败直接返回错误。购买、退款、结算事务和存储格式保持原有逻辑。

## 验证

隔离 Linux 中 17 个主测试、76 个通过节点全部通过，覆盖新旧读取结果、过期和错误记录、排序、最近 20 笔均价、买卖回滚、退款、防重复及客户端响应。真实 MariaDB 在参数插值两种配置下验证完整字段相等，混合数据返回行数从整包 22405 行减少到挂单/成交前缀 3201 行、单档位 280 行；该数据只代表测试工作集读取范围，不代表整服延迟改善比例。相关 vet、list、依赖检查及 Linux 正式构建通过。尚未部署或完成玩家实测。
