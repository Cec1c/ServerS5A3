# 公开选定的黑钻混合支付与武器外观服务端

- 黑钻礼包 490709931 在代币券不足时允许点券补足，其他仅限代币券的商品保持原限制。
- 接入武器外观目录、林纳斯制作会话和原子化扣料发成品；神奇模具成品不可交易或邮寄，秘传模具成品仅限同账号邮寄与流转。
