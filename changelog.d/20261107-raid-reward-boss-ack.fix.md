# 团本奖励投影不再重放首领死亡确认

## 变更

普通团本奖励展示结束后仍将单字节 `00` 的 NOTI115 当作结束／回城通知发送。当前客户端该包属于首领死亡确认，零状态分支还会读取第二个字节；该投影既不满足读取边界，也不会执行城镇切换。

移除奖励投影中的该通知，保留真实首领死亡请求的完整回复、已提交奖励牌面、阶段休息时钟和单人安徒恩已有类型化回城流程。未改任务的普通模式同样会走到原错误分支；这项协议修复不代表普通模式的动画、开窗和回城已完成实机验收。

## 验证

真实PVF、原版攻坚计数目标及内存仓储，覆盖普通安徒恩两阶段、两名有效参与者：修复前四种情况均重放单字节115，修复后不再重放，牌面及物品数量保持、重复投影不再发送。当前累计客户端原生115读取分支的有界执行确认单字节包下溢，正常四字节成功回复读取完整；未执行渲染器。既有单人翻牌、回城、错误归属与动画跳过／自然结束专项通过。普通团队模式双端实机验收仍待完成。
