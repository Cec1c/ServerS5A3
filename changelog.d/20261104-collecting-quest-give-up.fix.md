# 允许收集任务在事务内放弃并回收专用道具

## 变更

- 补齐完整 seeking 收集任务的放弃路径，任务专用掉落不再导致零持有量也无法放弃；普通材料保留，其他活动任务共用需求按既有最大需求规则保留。
- 角色库存与任务两个状态字段在同一事务内修改，失败不返回成功；提交后先刷新变化槽位再返回既有放弃应答，保持同会话重复请求保护。
- 接取赠予、未知定义/物品、未支持的回收结构及禁止放弃任务继续拒绝执行。详见 Docs/QUEST_COLLECTING_GIVE_UP.md。

## 验证

- 本地 Linux 20项事务/边界场景、既有放弃任务专项、真实 PVF 4099 的0/5/12/36数量与精确协议回归通过。
- 扩展任务包出现三项完成券/3971任务链失败，已在未改相同基线、同一PVF复现；保留失败，不宣称全套通过。
- 以上为最初本地候选的验证记录；本次从公开祖先纳入源码，后续部署与游戏验收另行登记，不由公开授权代替。
