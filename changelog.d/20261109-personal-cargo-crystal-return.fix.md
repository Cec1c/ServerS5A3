# 个人金库取出晶块回到账号晶块仓库

## 变更

- 从个人金库取出无色等六种小晶块及六种灵魂时，按实际道具重定向到账号固定仓库格，不再写入普通材料页。
- 来源扣减与账号入账在同一资产事务内完成，成功应答和增量刷新使用实际格子；目标不兼容、容量不足或提交失败时保持两边数量。

## 验证

- 冒险团成长胶囊另经现用 PVF 和角色数据核对：经验已累计，领取限制为 50～86 级；90 级领取按钮置灰遵循资源规则，本次不更改领取等级。
- 本地 `go build -tags=timetzdata ./...` 通过；取出晶块的仓库落点与事务回滚需游戏内实测。
