# 累计公开功能的旧回归契约

## 变更

- 队伍退场同时检查单人客户端旧绑定清理与服务端固定成员、运行实例保留；多人存留禁止该清理。
- LOGIN 端点断言沿用当前原生定长字段，团本信息查询沿用实际普通队伍投影。
- 奖励诊断分别构造个人已提交与个人待提交状态，整团时间不充当个人资产回执。
- 外观成本分别约束默认 mode0 的一次装备读取与完整 mode1 回退的七次读取；旧公开基线和当前候选在独立 Linux 对照下相同，原六次阈值失配留证。默认路径预算从六收紧为一。

## 验证

隔离 Linux 对照已确认旧公开基线与当前候选的两档读取成本相同；已校正的端点、团本查询及奖励诊断四项通过。最终固定提交由公开 Linux CI 完整验证。仅修正测试，未修改运行代码。
