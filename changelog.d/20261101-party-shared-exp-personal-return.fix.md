# 同房队员经验与个人退队回城

## 变更

- 同房、同实例的有效队员按各自角色和账号状态结算已接受的击杀经验，保留原有 PVF 经验公式、经验与技能点事务及死亡去重。
- 副本内退出队伍只让退出者回城；留图成员继续保留队伍和副本，队长退出时由最低占用槽位接任。
- 普通离队名单清理使用当前客户端的离队记录，避免被踢后再发送会触发“队伍已解散”的记录。
- 邀请者切换场景后客户端关闭原场景邀请，仍需重新邀请；不把尚未接受的邀请视为已入队。

## 验证

- 回归覆盖双方轮流击杀、死亡重报、已离队及异房队员、队长和队员分别退队回城、留图成员状态及被踢文案对应的原生帧。
- 修复前后测试、部署与游戏内验收状态分别保存在本机运行回执；不将服务端协议回归写成实际客户端验收。
