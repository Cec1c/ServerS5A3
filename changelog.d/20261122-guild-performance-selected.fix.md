# 公会写入、名册广播、历史归档、婚姻与选角热路径优化

## 变更

- 公会写事务复用同一仓储视图和锁内设置读取，写后失效缓存；在线状态提交前使用权威只读预检，并支持可配置的最小落库间隔，同时保留实时在线广播。
- 成员刷新使用独立异步令牌投递到接收会话事件循环，队列满时按接收方容量退避并在队列释放后恢复；名册广播复用同一次在线采样和分片结果。
- 过期公会契约领取、传送、红包和离会记录按有界批次归档，归档与主注册表更新保持原子性，回执重放、冲突校验和跨 06:00 服务日领取语义保留。
- 婚姻资料预热按会话、世代、频道、公会和外观版本去重，只在所有资料帧实际写出后登记；婚姻字段读取拆为角色主键查询与婚礼属性范围查询。
- 选角初始化将余额和会员数据合并为一次账户快照读取。

## 验证

- 已补充锁内设置缓存、成员异步刷新恢复、在线状态节流、婚礼预热、名册分片缓存及归档事务专项测试。
- Linux 专项回归覆盖锁内读取、异步唤醒、名册分片、婚礼预热与单次选角快照读取。
