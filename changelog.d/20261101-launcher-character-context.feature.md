# 登录器诊断角色与时间上下文

## 变更

- 登录认证可按玩家诊断同意建立独立只读关联，返回本次启动的角色、连接、频道、场景和最后结算阶段；换角、重连和业务断线保留代次与时间，不向玩家暴露管理接口。
- 有界内存记录和能力凭据校验隔离不同登录，服务端实例、UTC 及请求时间用于关联与时钟偏差估算；无额外数据库查询、写入或游戏报文。
- 需登录器及玩家网关配套，未请求诊断时不建立订阅。

## 验证

- 原候选通过诊断生命周期、换角、重连、过期、容量与账号隔离回归及 race 检查，Go 完整测试和双平台构建通过。
- 累计时保留现有战令会话状态、停止推送与其他清理步骤；源码集成验证单独留档。
- 实际玩家新格式角色日志在配套发布后验收，源码合并不代表已部署。
