# 减少开盒与奖励结算事务对无关资产行的重复写入

## 变更

- 账号、角色与邮件共用的资产事务启用已有的背包、账号仓库、装备、账号元数据及角色属性前像比较，只保存实际变化的行。赛丽亚幸运值和奖励仍在同一事务提交。
- 保留账号先于角色的锁顺序、所有权校验、邮件溢出、永久回执及失败回滚。没有可用完整前像时继续走完整保存。

## 验证

- 隔离 Linux 的关系行对照覆盖批量大小 1/200、同事务重复保存、无关行保留及 182 个逐条写失败回滚点；原事务覆盖负测复现重复写入，修复后通过。
- 真实一次性 MariaDB 的确定性赛丽亚十连对照：批量大小 200 时写语句 172→9，大小 1 时 540→18，奖励、扣盒、幸运值及持久化账号／角色／背包均一致。
- 关联账号资产、邮件、奖励未知提交及全部礼包领域回归通过；适用 vet、模块校验与普通 Linux 服务端构建通过。以上是专项验证和合成事务对照，实际交互延迟与玩家画面须在部署后验收。
