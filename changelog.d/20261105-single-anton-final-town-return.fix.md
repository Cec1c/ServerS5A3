# 单人安徒恩最终翻牌后自动回城

## 变更

- 修复单人安徒恩最终团队翻牌结束后仍留在心脏地下城：完成工作队列在已提交奖励展示结束后，复用现有角色重建和城镇切换流程，不再等待普通地下城翻牌菜单的回城请求。
- 回城只接受当前会话、角色代次、最终地图入场及通关记录、已提交周次数和已成功展示的奖励列表；重复回调不会重发奖励或重复切图。延迟显示时保留完整展示时间，返回准备失败保留原运行实例。普通地图、团队安徒恩和卢克保持原流程。

## 验证

- 真实 PVF、隔离内存仓储回归覆盖完成队列、结束前后、重复请求、过期归属、缺失提交、延迟展示及准备失败重试。
- 下游累计部署于 2026-11-06 经玩家确认最终团本牌面显示及约 20 秒后自动回城；本次公开补丁的专项、构建与 CI 单独记录。
