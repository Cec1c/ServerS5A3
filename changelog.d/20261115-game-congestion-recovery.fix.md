# 游戏连接为短时拥塞保留恢复时间

## 变更

- 游戏连接等待发送锁及默认发送期限独立为 30 秒，避免仍可恢复的短时拥塞触发原有 3 秒期限并关闭连接。已准入的组队资料回包使用同样的独立发送窗口。
- 数据库与业务操作期限保持；显式调用方的更早期限、取消、账号退役及真实断连仍生效。超过界限或部分帧失败仍关闭该接收连接，防止继续使用已推进的保护编码序列。

## 验证

- 模拟接收方先读取部分 37KB 帧，暂停超过原期限后恢复，核对同一连接的完整剩余字节及下一帧；模拟发送锁拥塞超过原期限后继续发送。
- 覆盖显式期限、取消、短写、永不读取的接收方和正常接收方隔离。此项延长可恢复窗口，不保证真正断网或客户端自行超时仍能保留连接。
