# 攻坚队预组队连接保留与等候区分组同步

## 变更

- 当前安徒恩、卢克开团时，成员、队长、固定位置和在线会话完全一致的原队伍保留中央队伍身份与 UDP 端点，仅刷新名单；真正变更分组继续按原流程重建。避免相同队伍被拆建及重复连接握手。
- 开团后的自由组队按实际队伍投影分组，单人状态的历史位置不占席；原组存在别的队伍时选可用组，不挪动其他队伍或修改冻结奖励归属。五组均被占用时保留失败边界。
- 成员状态、普通队伍离队标记和自由组队分组同步只更新攻坚队名单，不重发整团外观。真正资料刷新仍发送人物资料，单次广播内复用完整752记录，后续广播重新读取。
- 两份既有客户端工具 README 及单人开窗构建脚本统一 LF，修复公开累计时空白检查失败；正文及工具行为不变，构建脚本 AST 一致。

## 验证

- Linux 专项覆盖预组队开团身份/端点、双向 loopback UDP、真实桥接分组/离队/重新加入、冻结奖励保护、状态通知不等待副本锁和单批资料读取次数。
- UDP 数据为合成传输数据，未执行客户端渲染器；不等于实机连接超时、缺失模型或卡顿全部解决。源码候选，未部署、未发布玩家公告。
