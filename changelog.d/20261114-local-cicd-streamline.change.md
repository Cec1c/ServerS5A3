# 本地靶向验证与精简发布载荷

## 变更

- 核心全量入口恢复 Go 测试缓存，提供显式强制重跑开关；本地 Docker 入口按包/用例验证并新构建，复用命名缓存，避免全仓验证压缩包。
- 增加独立 compact 载荷生成器，只输出程序、部署工具和身份清单。远端默认入口等待协议接入，本次不改线上执行代码。

## 验证

- 本地入口与载荷边界专项、Docker Linux 实际靶向验证和缓存复用检查；具体命令与结果见贡献回执。
- 无游戏逻辑、玩家资源或生产容器切换；云端工作流与私有权威保持。
