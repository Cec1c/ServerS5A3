# 客户端镜像支持固定公开项目的鉴权取包

## 变更

当包接口拒绝匿名访问、同项目令牌可正常读取时，客户端镜像使用已有项目令牌取回并核验完整归档，避免在附件阶段停留。

鉴权仅限配置项目的规范 generic package 路径，先核实项目公开且 ID 匹配；拒绝凭据请求的全部重定向，保留摘要、大小、归档与来源检查。GitHub 附件仍匿名读取，玩家实际下载和正式发布结果单独验收。

## 验证

专项回归覆盖请求头、路径与项目范围、私有项目拒绝、重定向拒绝、完整摘要及大小上限，以及 GitHub 下载不携带凭据。客户端同步 62 项本地回归通过。
