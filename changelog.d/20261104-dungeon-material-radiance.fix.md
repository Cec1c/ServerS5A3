# 补齐按副本配置材料掉落及次元光辉配方

## 变更

- 增加可选 PVF 服务端扩展，按副本编号、材料和四种怪物类型配置独立概率；未配置的归档保持原掉落和随机流。
- 接入普通怪物及魔界裂缝、时空裂缝专用领主奖励分支，沿用个人地面物品、死亡重放和拾取事务。
- 提供独立 PVF 配方：魔界六图及魔界裂缝领主 10% 掉落一个次元光辉；时空裂缝普通/精英怪 1%、领主 10%。这组数值须由运营者选择配方启用，不在服务端硬编码。

## 验证

- Linux 回归覆盖配置解析、概率与范围、无配置兼容、两条奖励入口、组队归属与重复拾取；真实 PVF 专项验证八图及真实材料落地、入包。
- 配方使用摘要守卫、原 token 保留与全档不变校验。实际发布须同步配套 PVF、服务端及 GM 索引；原生刷图验收另行记录。
