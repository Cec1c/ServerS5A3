# 接入结婚流程、婚戒婚房与精确客户端收包工具

## 变更

- 接入大司祭订婚、婚前任务、预约、请帖、宾客随礼、礼堂加载和婚礼结算，按 PVF 收费、奖励及保存双向关系。
- 接入婚戒升级、心意点、配偶外观、婚房家具、树、胶囊及留言归档，补齐角色创建和场景刷新中的权威属性投影；各操作保留事务、归属、会话与重放校验。
- 提供精确 EXE 收包候选脚本与只读原生验证器，列明 41 个显式准入项、实际新增 39 项及原已开放/未使用项；不附带客户端二进制或新增 DLL。
- 部署依赖配套客户端正式发布，入口及版本哈希见 `Docs/WEDDING_CLIENT_RECEIVE.md`。取消的同性结婚功能不包含在本次改动中。

## 验证

- 本地已安装累计版本已有用户游戏反馈；公开源码从当前权威主干独立提取，保留主干活动、战令与普通经验胶囊实现。
- Linux 模块清单、静态检查、测试编译和正式构建与完整 Linux CI 分别登记；以 PR 检查状态确认公开验收。
- 收包工具包含无资源契约回归，精确模块另执行全 u16 准入矩阵及 ABI 样本；不将其表述为实际联网游戏测试。
- 重复“恭喜”、公会列表客户端适配及部分原生文案仍有验证边界，详见 `Docs/WEDDING.md`。
