# 普通拍卖单物品搜索缩小读取范围

## 变更

普通拍卖搜索一个有效物品 ID 时，仅查询该物品的在售槽位；重复 ID 和零值保持原过滤语义，多物品与旧仓储适配器保持兼容。保留排序、到期排除、资产结算和错误传播。外观缓存、公会与拍卖关系表的本批采用评估见 Docs/PEAK_OPTIMIZATION_SCOPE.md。

## 验证

实际隔离 Linux 的搜索筛选、顺序、损坏与到期行、最大物品 ID、接口兼容、查询错误、分类和分页调用方验证通过；连同外观采用评估共 11 个主测试、36 个通过节点，无失败或跳过。相关 vet/list、边界及 Linux 正式构建通过，未变 SQL 窄接口引用已有实际 MariaDB 证据。未部署。
