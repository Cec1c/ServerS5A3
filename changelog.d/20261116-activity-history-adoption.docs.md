# 按持续负载比较保留现有活动历史布局

## 变更

2 GiB缓冲池条件下重新评估活动冷热候选，保留原活动事件、计数和资产的同事务永久防重。候选虽减少冷读，但延长热态比较没有稳定尾延迟或总吞吐收益，额外写入和存储仍存在，因此从本次发布候选撤下迁表相关代码。独立的增量写、窄读和容量优化继续保留。

## 验证

实际隔离Linux/MariaDB，每路径540万历史、合计172000新增事务，保留全部交错轮次；重试、冲突、回滚、来源和重启验证完成。游戏Go输入恢复到此前已验证的累计版本，仅新增评估文档；未重复未变游戏测试或部署。具体数据与限制见Docs/ACTIVITY_HISTORY_ADOPTION.md。
