# 修正资料查询、团本交互、保存读取与史诗完成发放

## 变更

- 补齐他人Buff强化和称号簿legacy查询入口，卢克团队塔罗牌罐不重复要求兑换材料。
- 同步安徒恩现代队伍房间登记、队员优先选图、战况表整队返城、二阶段普通队伍保留及失败电影不打开空翻牌；提供固定输入客户端登记和空来源保护的累计配方。
- 公会只读投影按实际内容指纹复用，排行批量读取并在后台采样，宠物事务保留增量保存，属性批量写和固定表族观察保持原事务语义。
- 无会籍角色仍直接返回空公会投影，不增加人物读取或阻断登录/返城；有会籍时继续验证权威人物、账号和会话归属。
- 装备entry保存发布参数以精确输入源码补丁提供闭合字段、配置生成与运行读回绑定；外部旧发布器不随附。
- 提供八图次元光辉单条目资源配方；史诗满进度在原事务内发目标武器、清目标与进度并发送完成通知，满包失败回滚。周加工策略沿用公开主干。
