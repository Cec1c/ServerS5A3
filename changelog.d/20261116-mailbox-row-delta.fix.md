# 邮件保存只写发生变化的记录

## 变更

正常 MySQL 邮箱保存改为在原事务锁下比较写分片的现状，只更新发生变化的邮件、附件和元数据。读信、领附件、发信和删信减少无关记录重写；保留清空整箱、孤立附件修复、领取编号、高水位和唯一键冲突行为。完整可写邮箱继续包含历史记录，原因和兼容边界见 Docs/MAILBOX_ROW_DELTA.md。

## 验证

实际隔离 Linux/MariaDB 验证原始数据库行等价、参数插值两档、逐写入与读取失败回滚、重复保存、旧写者及其他收件人隔离。最终 31 个相关数据库/仓储主测试通过，复用二进制完全相同的 42 个邮件领域主测试；共 73 个主测试、200 个不同通过节点，零未解决失败或跳过。相关 vet/list/依赖边界和 Linux 正式构建通过。80 封合成邮件工作集的读信写入次数 645→2，领取 640→6，非空保存增加 4 次读取；这不是整服性能倍数或玩家实测结果。未部署。
