# 累计通用占用与组队读取优化

## 变更

- 收敛角色、背包、装备和设置的热点读取，新增只读角色镜像投影、背包槽位投影、事务内父行锁和设置联表读取缓存，避免登录、组队、公会及副本流程重复扫描无关数据。
- 批量准备并发送组队进图角色状态，确保所有参与者的 mode0 与 mode1 行在绑定前一次性生成，并在写入时复核会话和队伍成员代次。
- 复用登录城镇、任务、背包和角色外观的同请求快照；快照仅位于单次调用栈内，不跨请求保存，不改变持久化格式和错误回退语义。
- 修正副本 mode0 刷新时的角色用户状态保留，避免装备外观重绘清除副本过图状态。

## 验证

- `gofmt -l`：116 个变更 Go 文件通过。
- 依赖闭包定向测试：61 个 `dnfbridge` 目标通过；1 个需要部署后 PVF 的真实资源用例在无 PVF 环境跳过。
- MySQL/Quest 窄读：11 个顶层用例及其 13 个子测试通过。
- `adventuregroup`、`buffswap`、`guild`、`repository`、`repository/memory` 包测试通过。
- 受影响包 `go vet`、`go mod verify` 和完整 Linux 服务端构建通过。
