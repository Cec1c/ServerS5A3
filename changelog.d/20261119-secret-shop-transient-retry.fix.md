# 加百利中奖后的临时失败重试

## 变更

- 命中特殊商人后立即冻结本次 NPC、随机 nonce 和成员资格；货品构建或库存恢复临时失败时，不再提前把本局标记为已检查，也不会再滚动新的 NPC。
- 下一次自然到达的 op46 结算请求最多重试一次，并复用已冻结的 encounter 重新构建或发送；正常首次成功时 op46 不重复发包。
- 保留 `official-24.9` 与 `DNFBRIDGE_BLACK_DIAMOND_SECRET_SHOP=on` 的货架兼容门，不新增或合成默认 1000 通知。
- 组队同房仍只在创建 encounter 的那一次执行 fanout，后续重试只处理当前成员，避免每名成员再次广播全部队友。
- 加百利表读取失败不再由一次性的 `sync.Once` 永久缓存；成功后才缓存目录。

## 验证

- 真实 PVF 覆盖 DGN50 等级池和 DGN7155 override，均保持 `1003=500/10000`，并从完成结算进入 `279(1003)+280(count=2)`。
- 回归覆盖候选构建临时失败、库存恢复临时失败、op46 重试不重抽、重复开窗不重发，以及加百利表首次读取失败后重试成功。
