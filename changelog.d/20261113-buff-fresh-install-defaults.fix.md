# 全新实例自动配置配套双组 Buff 协议

## 变更

- Docker 首次准备面向当前 V212+ 保存双组同步设置，并写入 Compose 实际使用的环境文件；提供客户端目录时识别已验证的 V212/V213/V214 与旧 v56，未知文件要求显式选择。
- 新普通控制器模板增加协议选择，官方原生客户端的 auto 模式启用双组同步，旧协议保持原包格式；控制器显式传递配置，避免外层环境清理丢失设置。
- 旧实例未配置和明确关闭的选择保持，重复准备保留持久设置；不改变游戏服务程序的全局默认值。

## 验证

- 隔离临时目录验证首次准备、实例持久化、Compose 环境文件、重复准备、旧实例与客户端识别；Docker 资源解析使用明确的测试替身，不作为真实 Docker 或 PVF 验收。
- Linux 控制器回归检查模板创建、设置读回、运行身份和真实测试子进程的环境传递；最终公开 CI 以该 PR 固定提交记录。
