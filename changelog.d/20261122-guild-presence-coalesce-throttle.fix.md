# 公会成员列表广播按活跃窗口节流并纳入防抖与副本延迟

## 变更

- `memberListRequested` 改为仅由客户端主动请求/刷新公会窗口续期，并在超过 60 秒活跃窗口后自动清理，避免城镇关窗后每 250ms 持续推送全量公会成员列表引发客户端重建。
- `membershipRefresh`（入退会、改职位、改备注等成员变更广播）纳入 250ms 防抖合并与副本战斗期延迟跳过，避免战斗期间全公会同步重建卡顿。

## 验证

- Docker Linux 执行 `dnfbridge` 公会存在感/成员广播专项单测、`go vet` 与 Linux 服务端构建。
