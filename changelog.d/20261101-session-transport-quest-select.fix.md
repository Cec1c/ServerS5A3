# 慢连接隔离、装备资格回执与选角窄读

## 变更

- 游戏连接写入和写锁准入设有界预算，实际写出统一管理截止与取消，嵌套预算退出恢复父作用域。短写、部分写入和超时关闭对应传输；保留已有零字节错误重试、团本资料已准入帧窗口及真实事务清理后的账号退休栅栏。
- 城镇进入、离开、移动、队友回城与退出门店通知进入收件方事件队列，不等待其他玩家网络。保留单收件方包顺序，校验会话/角色/城镇代次及副本状态；队列过载只关闭该收件方，过期场景通知丢弃。
- 三类装备资格任务允许严格验证的金币支出回执，沿原有顺序发送完成应答、余额、槽位和任务快照。发包前验证原子提交、角色及解锁位；保留不足不扣除、重复不重复应答与断线后持久回执恢复。
- 选角使用可选身份列表接口，仅完整读取所选角色；初始化父记录存在性及单任务状态使用可选窄查询，保留旧仓储回退、空记录语义和状态优先级。选角关联计时覆盖排队、身份/角色读取、初始化、准备及真正写出的ACK，缓冲入队不算已发送。
