# 统一公开搭建预设、客户端配对与公网通告

## 变更

为配套客户端新建 Docker 实例时，直接加载同一份推荐预设。赛马活动 2365 默认关闭，标准搭建同时启用三大会、公会和相关兼容设置。配套旧实例可用 `--apply-recommended` 补齐缺项，保留实例已有开关及凭据。旧数据库中单独保存的活动状态仍从活动管理核对。

`--public-host` 单独指定玩家收到的公网 IPv4。频道目录、游戏和中继通告共用该地址，Compose 继续绑定宿主机私网地址。Buff 自动模式和远端更新统一优先使用活动 EXE 摘要。

补齐组队房间恢复与回执配方引用的生命周期构建和验证源码。

## 验证

配置测试覆盖首次准备、旧实例补缺、已保存的关闭值、旧客户端、活动 EXE 切换、公网地址与私网绑定的生成及远端读回。配方测试覆盖公开构建入口的完整导入链。
