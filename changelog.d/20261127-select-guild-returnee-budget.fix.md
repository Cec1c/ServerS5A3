# 返回选角、公会名单和回归赠礼准备预算修正

## 变更

- 返回选角后重新进入普通频道时，完整场景准备完毕后统一发送，避免显示半初始化城镇；冷启动仍等待原生进度回执。
- 公会名单先返回，再做可选同频道资料预热，保留婚礼关联顺序、共享预热总预算、场景围栏及独立传输预算。
- 回归 NPC 规则准备与资产写入各用独立时限，避免首次冷加载消耗资产事务预算。
- 入场回滚测试覆盖活动结算事务路径，检查疲劳、次数及活跃度原子回滚。
- 更正此前 P5 说明：目录缓存使用互斥锁及不可变快照，未采用 sync/atomic 热读。
