# 安徒恩前置任务目标替换后正常发送阶段结算

## 变更

内容包将卢克准入规则引用的安徒恩任务改为材料提交等目标后，正常安徒恩阶段结算仍尝试更新原攻坚计数目标。已有任务记录的角色因此在结果发送前收到目标类型错误，缺少阶段动画和翻牌展示。

仅对当前任务定义仍为 `raid phase clear` 的目标推进原计数；其他目标由其原事务处理。缺失定义、原计数格式错误、归属、周次数提交和传输失败检查保留。结果和奖励不补发、不重抽。

## 验证

真实PVF及隔离内存仓储覆盖两阶段、两名参与者和未接取／进行／已完成三种任务状态，检查结果发送、重复投影与任务状态保持；原计数目标继续在周次数提交后更新。错误账号／频道／实例、周次数回滚、超时与传输失败回归通过。实际游戏动画另行验收。
