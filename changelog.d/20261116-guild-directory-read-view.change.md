# 公会聊天与成员刷新减少完整源读取

## 变更

- 聊天发送和队友接收、在线广播、组队贡献冻结、公会副本与余额通知、公会大厅、传送及婚礼邀请校验复用精确源版本的成员字段。
- 公告及窗口刷新只复制管理回包字段，不再读取完整历史；每次后续接收和提交后刷新仍重新核实当前版本。
- 原账号归属、成员离会重入时间、连接代次、权限与权威写事务保持。

## 验证

- 实际隔离 Linux 106 项通过的顶层测试、279 个通过节点，包含聊天隔离、换角/离会、慢接收者、贡献、入场、传送和刷新回包；另外两项可选资源/导出环境测试跳过并单独记录。
- 相关 vet、依赖、边界及正式 Linux 构建通过；未代表实际线上收益或完整玩家画面验收。
