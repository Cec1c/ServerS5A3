# GitHub 权威源码与 Linux CI

## 变更

- 公开主干和贡献入口迁至 GitHub，GitGud 改为异步单向快进镜像。
- 公开 PR 按源码、工具、容器与文档分流，仅验证 Linux；取消分支 push/合并后的重复全量验证和普通 PR 构建附件上传。
- 部署准备只校验依赖并重新构建 Linux 正式程序；源码回归在贡献阶段完成，保留权威拉取、备份、批准、切换与读回。

## 验证

- 镜像回归覆盖方向、分叉、并发变更、无强推和凭据输出边界；检查范围覆盖文档、源码、工具及手动全量。
- 控制器回归检查 Linux 构建、失败传播和源码变化。实际 CI、源码累计及控制器安装另行留回执，不因工具更新重启游戏。
