# 黑暗武士自动学习保留手动上排快捷栏

## 变更

- 黑暗武士普通主动技能的新学习和未分配技能布局使用技能树槽位，优先 150..197，满后使用 6..149；不再自动占用 198..203。
- 初始布局和整页重建先按现有 PVF 规则安置六个固定连招根，再分配普通技能；已有手动上排绑定在学习升级和重新加载时保留。
- 技能树槽满时返回错误，学习批次不提交技能、点数或布局变化；其他职业继续使用现有自动快捷栏规则。

## 验证

- 新增回归覆盖两页新学习、整页初始/缺失布局、192 个树槽容量、六个手动上排绑定及持久化重建、固定根、非黑武布局和槽满批次回滚。
- 隔离 Linux 的 skillcmd 与 darkknightcombo 包全部通过（99 顶层、135 通过节点），包含本次新回归；gofmt、Linux 目标 vet、依赖边界和片段检查通过。原生客户端画面仍待实机验收。
