# NPC 金币购买晶块直接进入账号仓库

## 变更

- 金币购买的六种小晶块按固定账号仓库槽位入账，与材料兑换使用同一分配路径；角色材料背包已满但仓库可容纳时仍可购买。
- 保留仓库满额后的背包溢出规则和异常占位物品，金额、仓库及背包在原购买事务中一起提交或回滚；购买应答仍返回本次数量，增量列表返回合并总量。

## 验证

- 新增六种晶块的真实购买处理器回包、满背包、合并、仓库溢出、32 位计数上限、异物占位、金币不足和仓库保存失败回滚回归，交 Linux PR CI 执行。
- 不包含资源价格修改；源码提交不代表已部署或游戏画面验收。
