# 超时空随行队友不再被进图坐标校验挡在门外

## 变更

- 同一区域的玩家一起进战斗区域时，进图坐标校验只对**进图发起者**生效，随行队友不再因为「人还在出发区域」而整队失败被踢回基地。
- 原因：入场允许判定 `currentFiendWarAdmissionAllowsPeer` 明确允许随行者人在出发区域、发起者已在目标区域（只要双方出发区域相同就放行），但紧接着的 `freezeCurrentRaidDungeonGroupEntry` 又要求 `fiendOrigin.AreaID` 等于目标区域，两条判据互相矛盾：前者放行、后者挡死，整队被拆散。
- 队友位置仍由 roster 的出发区域匹配与入场允许判定双重把关，放宽后不会把无关玩家拉进战斗。
- 与「同一区域有一人进入战斗区域即组队进入」的规则一致，无新增配置。

## 验证

- 已做：`go build ./...`、`gofmt` 无差异；`dnfbridge` 全包在目标基线上做改动前后集合对比，失败集合完全一致（零新增、零消失）。
- 待验收：同区域两名玩家由其中一人发起进入战斗区域，确认两人同时进图且不会退回基地。尚未部署。
