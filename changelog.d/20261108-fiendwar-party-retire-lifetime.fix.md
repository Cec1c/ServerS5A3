# 超时空遭遇战队伍等最后一人离开副本再退役

## 变更

- 战斗区域组成的临时队伍改为「最后一名成员离开该副本 run 时才退役」，此前每个回城者都会各自触发一次退役。
- 原因：先回到区域地图的成员触发退役时，队友还在副本里。服务端随后发出的 op9 `party_id=0` 在副本态下不被客户端应用，等后一位退出时队伍早已退役、不会重发，于是队伍框残留到下次进战斗区域。
- 离线队友不参与该判断（其副本运行态已回收，断线另有处理路径）。
- 新增 `game-fiendwar-encounter-party-retire-skipped` 诊断，记录 `party_already_replaced` / `roster_changed` / `retire_snapshot_rejected` 三种跳过原因，便于后续定位。

## 验证

- 已做：`go build ./...`、`gofmt` 无差异；`dnfbridge` 全包在目标基线上做改动前后集合对比，失败集合完全一致（零新增、零消失）。
- 待验收：两人进入战斗区域打完并分别返回区域地图，确认两人视角的队伍框都消失。尚未部署。
