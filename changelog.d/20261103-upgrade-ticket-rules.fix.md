# 修复祝福强化券随机强化与用券装备限制

## 变更

- 补齐 `[enchant random]` 的候选数量、目标强化等级与十万分比权重解析，合法祝福券不再整类返回限制错误。抽取可以覆盖原有等级，未分配概率保持原等级；目标装备与一张券在同一资产事务保存。
- 按 PVF 校验品质、武器/防具/首饰部位及封装状态。角色契约不改变装备本身的 `[minimum level]`；固定券与随机券均保留适用等级和明确装备名单限制。
- 无效配置、锁定、耐久不足、强化/增幅模式不符及缺少券时拒绝，不扣券、不修改装备。绑定与封装分别判断，保留首次穿戴已解封的状态。

## 验证

- 新增全部十万档随机区间、Lv90 上衣、史诗排除、部位、封装、名单、契约等级、单张扣除与重复请求回归；既有固定券、便携强化和事务失败回归继续执行。
- 本机只做格式、源码边界与 Linux 交叉编译检查；Linux CI 结果以 PR 实际运行记录为准。未执行部署或游戏验收。
