# 擂台赛接收门补丁迁移到上游 V208（v2.0.8.1）

## 变更

- `scripts/client/patch_pvp_relay_gate_v208.py` 增加上游 V208（`5ce2ce3f…`）输入，生成 v2.0.8.1（`58b7c5e6…`），同时包含上游开放的 817/818（史诗碎片商店）和擂台骰子需要的 112/113。
- 原有的 V207 输入不变，仍生成 v2.0.8（`c6adcdff…`）；脚本按输入的 SHA256 选择对应输出，并核对产物摘要。
- `verify_pvp_relay_gate_v208.py` 同时接受这两组输入和输出。文档补充了合并依据、版本号规则和比对结果。
- EXE 以 Release 附件分发，不进仓库；没有服务端代码、PVF 或玩家数据变化。

## 验证

- 从 V207 重新生成，结果仍与已发布的 v2.0.8 逐字节一致；从 V208 生成的结果与上表摘要一致。
- 接收门比对：V208 → v2.0.8.1 只有 (0,112)、(0,113) 从丢弃变为放行；v2.0.8 → v2.0.8.1 只有上游开放的 817/818 发生变化；均无执行错误。
- 尚未实机验收，也没有切换玩家更新通道。
