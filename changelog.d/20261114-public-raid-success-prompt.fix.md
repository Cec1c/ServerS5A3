# 团本成功结算提示的后续重试

## 变更

- 团本成功结算的 NOTI599 提示不再把一次成功的 socket 写当作客户端已经显示电影提示；若原生电影窗口在首次提示时尚未就绪，后续真实 659/0 输入可在一秒间隔后再次提示。
- 只有真实 659/1 完成请求才标记电影完成并开放后续翻牌；提示重试不会自动完成电影阶段、生成奖励资格或发放额外奖励。失败、重试与返回仍由原结算流程管理。

## 验证

- 本批加入成功路径回归覆盖：过早输入不推进阶段，一秒内输入保持节流，后续 659/0 恢复提示，659/1 才开放双方原生牌面，迟到的 659/0 不生成奖励。
- 上述适用回归已在隔离 Linux 执行通过；各包完整范围、跳过项和既有基线诊断见对应 PR 的验证记录。真实客户端的电影窗口时序、牌面展示和奖励流程仍待实机验收。
