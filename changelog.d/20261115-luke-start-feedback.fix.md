# 卢克开团失败显示原因并补齐异常成员反馈

## 变更

- official-24.9 客户端在卢克频道开团被拒绝时，保留原失败回包，并显示安全的玩家提示；入场材料、等候区等已有具体原因也会显示。
- 成员角色为空、名单重复或组别越界时，返回可解释的拒绝原因并进入已有拒绝日志；保持编队、人数、所有权及入场检查和扣票顺序。
- 安徒恩继续使用原提示，其他频道与非 official 客户端保持原回包行为；仓储和传输错误详情不写入玩家文字。

## 验证

- 新增专项覆盖 type23/type32、其他频道及非 official 客户端，检查负 ACK 顺序、安全文字、异常名单与组别、认证边界，以及拒绝后名单、战斗和背包不变。
- Go 格式、片段与服务端边界检查通过；新增专项已在隔离 Linux 执行通过，真实 PVF 下的门票、等候区断言也已执行。
- 新增真实 PVF 专项覆盖卢克门票不足和成员未到等候区的可见提示；需设置 DNFBRIDGE_REAL_PVF_SMOKE。专项执行已通过；原生客户端画面待实机验收。
