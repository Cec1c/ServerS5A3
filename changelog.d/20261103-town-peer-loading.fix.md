# 减少普通城镇入场的重复完整角色加载

## 变更

- 增加默认关闭的配套客户端能力开关：普通共享城镇先建立原生显示对象，保留外观、位置和交互数据，省略路人入场的完整装备/技能初始化。
- 覆盖退队后保留的单人大厅和同角色辅助连接，保留真实队伍编号、加入/邀请语义及频道、实例与代际隔离。
- 真正组队时先补齐完整角色，再发送血条和队伍记录；重复名单不重复建角色，离场、换角色和换场清理记录。
- 仅提交相关服务端源码、客户端离线补丁/有界验证源码及说明，不启用开关或发布客户端文件。

## 验证

- 新增普通入场、单人大厅、辅助连接、再次组队、名单顺序、重复补发及旧代际拒绝回归。
- 客户端专项覆盖48组显示对象生命周期与16组单人队伍绑定；资源、渲染和原生适配器边界见 `Docs/seeker/TOWN_PEER_LOADING_20261103.md`。
- 公开候选基于当前主干独立验收；本地原有试用结果不能替代此候选的构建和游戏验收。
