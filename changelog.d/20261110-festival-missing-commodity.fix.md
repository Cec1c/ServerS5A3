# 商城礼包被 PVF 删除后不再导致整个商城无法购买

## 变更

- PVF 从 `etc/cerashop.etc` 删掉礼包，而多买多送商品表仍列着这些礼包时，服务端只把它们移出多买多送白名单，商城其余商品照常购买。此前整个商城目录加载失败，所有购买都提示“物品栏空间不足”。
- 商城目录加载日志新增 `festival_commodities_skipped`，记录被跳过的多买多送商品数。

## 验证

- 本地 `go build -tags=timetzdata ./...` 通过；缺失礼包的跳过路径需在 PVF 变更后由商城实际购买验证。
