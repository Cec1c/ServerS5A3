# 修复选角初始化后六期礼包日历页面消失

## 变更

- 选角阶段会提前发送完整活动目录并标记已初始化；原路径漏掉六期礼包页面，进入城镇后不再补发，活动日历因此只剩原目录。
- 将可选礼包条目合并移入选角与城镇共用的目录构建函数，每次完整目录都保留六期页面且只添加一次；目录构建失败不提前标记成功，未配置礼包的资源保持原行为。
- 无客户端、资源、价格、购买计数或玩家数据变化。

## 验证

- Linux 隔离协议回归在修复前复现选角目录缺少礼包条目及错误配置被标记成功，修复后验证选角到城镇、重复刷新、失败后重试和无礼包配置四个场景。
- GitHub Linux 验证按服务端改动范围执行；实机活动日历显示仍须在部署后验收。
