# 卢克收益、加百利商店与运行参数

## 变更

单人卢克按照对应模式处理复活和材料，普通卢克按角色的持久通关记录判断当天的重复收益。

加百利商店的 Docker 开关为 `black_diamond_secret_shop`。新实例使用 `auto`，按配对客户端的 SHA-256 决定开关。旧实例没有配置时沿用原有环境。使用 `prepare --client-dir <客户端目录>` 重新准备配对时读取实际 DNF.exe；单独更新游戏服务时使用活动快照的客户端身份。回退恢复原配置文件。积分商城另由 `DNFBRIDGE_MILEAGE_SHOP_ENABLED` 控制。

更新游戏服务时，从已安装的 server.env 承接 GOMEMLIMIT、地图缓存、PVF 读取缓存、公会广播合并和在线状态写入间隔。准备与切换分别核对实例配置，并验证生成环境的全部键值。部署工具与 Docker 生成器需要配套更新。

## 验证

专项测试覆盖单人复活、真实 PVF 掉落过滤、重复通关收益。部署测试覆盖新旧客户端切换、未知客户端关闭商店、旧配置兼容、参数越界及生成环境意外变化。
