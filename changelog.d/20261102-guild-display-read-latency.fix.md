# 公会名册与贡献榜查询阻塞

## 变更

- 名册和红包贡献榜使用主库一致性只读快照，批量读取成员当前名字、等级、职业和成长信息，保留账号归属、删除状态、在线频道与换角校验。展示请求不再逐人加载完整角色，也不获取公会写锁。
- 公会副本贡献在原结算事务内维护本次会籍的累计计数，贡献榜直接投影；历史会籍在启动监听前补算，正常查询不再扫描历史结算回执。补算比较原注册表后写入，并发结算或离会重入会触发重新读取，保留原贡献总分、奖励与幂等回执。

## 验证

- 回归覆盖 191/1000 人名册、旧处理函数失败与候选通过、跨分片读快照、并发结算、失败回滚、重复结算、历史补算及离会重入。生产查询时延与玩家操作体验在部署后独立验收。

实现与验证说明见 [公会展示读路径](../Docs/seeker/GUILD_READ_LATENCY.md)。
