# 修复分解无色、艾肯暴击和史诗返片

## 变更

- NPC 装备分解先按 `equipment/pricetable.tbl` 的装备卖价千分比换算，再计算无色小晶块；与商店共用卖价换算，保留缺失价格时至少一个无色的规则，拒绝无效比例和数量溢出。
- `warriors dungeon` 艾肯装备的附加材料只使用普通数量档，保留等级除数的小数概率取整。普通传说装备仍按原概率暴击；艾肯禁产传说灵魂的规则保持。
- 以装备原始价值 68400、卖价比例 200/1000、分解系数 1.53/150 为例，无色由 697 修正为 139；90 级艾肯在普通除数 5.65 时产出 15～16 个附加材料，取消原暴击档的 473～474 个。
- 玩家副职业分解机原有卖价比例及机器等级系数正确，保留其 10% 加成；补齐艾肯禁止材料暴击的规则及无色数量溢出检查，普通装备暴击保持。
- NPC、玩家摊位和自身副职业分解史诗时，每件按 PVF 图鉴映射返还 30 个对应碎片。碎片进入使用者账号图鉴，与装备消耗、材料、金币和机器状态同事务提交，失败全部回滚；成功后同步绝对余额，不把碎片塞入背包产物行。

## 验证

- 新增卖价比例、价格回退、算术溢出、强制普通传说暴击与艾肯对照、单件和两种批量入口、重复源槽拒绝及共享仓库保存失败回滚回归。
- 新增史诗映射、累计和封顶、批量重复槽、账本/仓库/背包/提交失败、应答失败后重试，以及玩家摊位使用者与拥有者隔离和批量原子性回归。
- Linux Verify 执行领域、桥接和控制器测试、vet 与 Linux 服务端构建；具体结果见本 PR 检查回执。真实 PVF 数据只读核算已完成，未在本次 CI 提供私有 PVF。
- 本项仅提交服务端修复，不部署；游戏内验收尚未进行。
