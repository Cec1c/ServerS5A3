# 史诗分解结果显示本次图鉴碎片

## 变更

- NPC与玩家分解机的结果窗口支持显示本次实际记入图鉴的史诗碎片；批量按碎片合并，达到图鉴上限时只显示实际增加量。
- 专用展示行使用槽位FFFF。配对客户端只生成临时显示对象，复制图标和名称后释放，不插入背包、槽位刷新或额外发奖。
- 服务端默认关闭此协议扩展。只有对应客户端正式发布、镜像、玩家签名通道及下载身份全部核对后，才可在绑定的部署配置中显式启用`DNFBRIDGE_DISJOINT_EPIC_DISPLAY=paired-v1`。
- 累计V210构建工具保留V208及V209的卢克/完成券修复，并包含游戏TCP缓冲调整；不会启动游戏、发布或切换线上资源。

## 验证

- 离线执行两条原生结果接收路径的挂接指令，覆盖普通行不变、临时对象释放、空结果/创建失败跳过及栈平衡。UI和物品工厂叶子使用适配桩，完整游戏画面仍待玩家验收。
- 本地Linux通过开关默认兼容、单件/批量展示量、图鉴上限、不进背包及不重复发奖回归。真实资源与最终CI单独留回执，未据此宣称已经上线。
