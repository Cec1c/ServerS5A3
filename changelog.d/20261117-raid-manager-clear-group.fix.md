# 支持攻坚编队的清空小队请求

## 变更

当前客户端清空所选小队时，会逐个发送目标组为 0 的编队请求。服务端现在允许安徒恩、卢克当前布局的团长清空成员编队位置，之后可以重新分配成员；清空不会解除已有普通队伍，也不会改写当前副本准入和已冻结奖励归属。请求字段在转换前检查范围，拒绝成员或组号截断后冒用合法值，以及其他模式的零组请求。

清空后进入下一阶段时，在副本和等待区检查通过后提交合法的下一阶段准入位置，保留单人意图；失败时保持原状态。旧布局与超时空编队策略保持原有约束。

## 验证

公开原代码的两项负测确认零组请求被拒绝。修复后隔离 Linux 的相关回归覆盖清空重编、满员换人、重复请求、非团长和越界字段、开团意图、真实公开 PVF 的战况队列、手动和定时下一阶段及奖励归属。相关 vet、依赖校验和完整 Linux 服务端构建通过。

客户端验证执行当前成品的原始回调，确认清队模式和逐成员零组请求；界面查找及发送端点为夹具。实际按钮交互、四个客户端的同步画面和 Docker 部署后效果仍需验收，未在本项中宣称完成。
