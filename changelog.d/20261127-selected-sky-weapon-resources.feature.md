# 选定资源配方：天空合成器与武器皮肤目录

## 变更

- 增加天空 A20-A22 外圈更新、A21 清理和 A22 审计工具；990032001 外圈固定为 14 项，A15-A19 的五个合成器定义必须在输入中已存在并保持排除，发布配方不包含其外观定义。
- 增加武器皮肤 C14-C17 资源配方：林纳斯第五页、神奇模具 1,000,000、秘传模具 2,000,000、13,329 行原生目录、40,032 个内容路径及五个 NPK 依赖。
- `equipment.lst` 与 `stackable.lst` 仅追加缺失的选定行，保留公开输入中的其他索引；配方不包含私有 PVF、EXE 或 NPK 二进制。

## 验证

- 配方和计划记录输入摘要、原生目录摘要、逐路径 token SHA256 和严格允许差异。
- Linux 101 由主控串行运行 Go 测试与候选构建；本目录不在 100 上执行重负载构建。
