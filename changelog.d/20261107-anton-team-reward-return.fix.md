# 普通安徒恩复用已提交奖励后的完整回城路线

## 变更

原自动回城调用仅处理单人安徒恩，普通两阶段奖励展示完成后没有对应调用。将既有角色重建、类型化场景切换及延迟展示路线复用于普通安徒恩；每位玩家独立核对账号、角色、会话代次、入场实例、已接受通关、参与记录及已提交奖励。阶段一返回本阶段城镇并保留休息时钟，阶段二在最终周次数提交后返回；未完成地图、旁观者及其他团本不会因此自动回城。

普通二阶段同时显示本地小队牌与团队牌，组合去重签名可能随小队变化，不能直接套用单人签名。奖励投影成功写出团队牌后，独立记录其实例身份、内容摘要与显示时间；回城只读取这份回执，不发奖、不重抽、不重置次数。延迟订阅者保留完整展示时间，失败准备可重试。

## 验证

真实PVF与内存仓储覆盖普通两阶段各两名参与者的完整角色／装备／场景切换，单人旧入口作为拒绝普通模式的对照；检查重复回调不重放结果、奖励或回城。覆盖周次数未提交、奖励未提交、牌面不匹配、实例／阶段／账号／通关记录／会话代次／运行时替换及非安徒恩模式。单人既有回城与拒绝边界继续回归。普通模式两端实际动画、翻牌和回城仍需实机验收，不以发送回执或内存事务替代。
