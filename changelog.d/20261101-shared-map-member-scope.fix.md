# 组队进图与过图更新全部成员的房间关联

## 变更

- 修正 START_MAP 尾字节语义：整队进图、完整过图、层刷新和缓存房间回访使用 `0xff` 更新当前队伍全部既存模型的房间关联，不再填写收件人的自身槽位。运行时身份与名单槽位保持。

## 验证

- 增加二、三、四人真实处理器入口回归，核对单次进图、共享种子、怪物对象键与一致报文；覆盖完整、刷新、缓存三种过图和独立身份槽位。
- 提供固定客户端摘要的原生窗口验证器，覆盖密集及空洞队伍、缺失模型、指定成员与全员选择。读取字节和房间查找使用显式夹具，测试不包含画面渲染或游戏实机验收。
