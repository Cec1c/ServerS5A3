# 累计集成消耗品审计修复与客户端回包许可

## 变更

- 接收既有扩容券、容器奖励语法、水晶之光、疲劳药来源守卫、固定强化/锻造和随机强化概率修复，并保留塔推荐书的未实现项审计。
- 将已注册活动赠品 op430 入口统一到扩容券事务，保留银质金库、灵跃永久券和五件防具套装判定。
- 提供精确累计客户端的408/430 class1接收许可补丁与独立原生验证入口；未知输入拒绝，输出新候选。

## 验证

- 直接套入旧包时已复现43种背包扩容券被旧入口截获；新增公开回归覆盖实际分派、回包、扣券和容量效果，以及默认选择和重复奖励边界。
- 客户端原生有界验证覆盖发送分支、回包调度、pending清理及接收门全opcode对照；只改变class1的408/430许可，Windows不可执行映像映射通过。
- 本次源码集成需要重新验证累计输入；既有包的历史逐ID与领域记录保留来源，不等同于新累计或游戏内验收。客户端发布与实际通道读回必须先于依赖服务端部署。
