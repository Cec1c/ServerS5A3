# 公会地下城贡献币与战令进度

## 变更

- 启用公会贡献奖励时，公会地下城通关的 PVF `[contribute]` 奖励同步发放等量贡献币并累计战令公会贡献任务；成员贡献不重复增加。
- 保留每日五次额外奖励，达到每日额外奖励上限后仍发每次通关奖励。任务栏满时沿用 15 天系统邮件。
- 贡献币、战令、成员记录与通关回执在同一事务提交，旧回执重放不补发。贡献榜保留历史未发币分数的扣除，仅计入新获得的贡献币。
- 无需修改 PVF 或客户端。

## 验证

- Linux Docker 的领域、桥接层和控制器回归通过；新增用例在修复前失败、修复后通过，并发专项 race 通过。
- 隔离 MariaDB 验证通关奖励、重复/并发、满栏邮件、失败回滚和重连；内存回归补充每日阈值、提交结果未知和历史回执兼容。
- 尚未部署，游戏内交互待上线验收。
