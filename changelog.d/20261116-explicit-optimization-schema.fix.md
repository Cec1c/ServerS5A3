# 补齐公会指纹与升级奖励恢复索引的显式安装

## 变更

新增普通服务端的独立维护入口，导出固定规格、只读核验实际对象，并在明确维护调用下安装公会持久指纹和升级奖励恢复索引。先检查全部分片，读副本不被误写；错误定义拒绝，完整就绪状态只读返回。普通启动和业务数据保持原合同。

## 验证

实际隔离 Linux/MariaDB 的分片、部分安装、错误对象、旧写者、奖励索引与来源保持检查通过；普通程序通过 TCP 和 Unix socket 完成安装与回执丢失后的只读确认。8 主测试/32 通过节点及相关静态检查、Linux 构建通过。未生产安装或部署；范围和失败恢复要求见 Docs/OPTIMIZATION_SCHEMA_MAINTENANCE.md。
