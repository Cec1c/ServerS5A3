# 普通商城打开计入每日战令

## 变更

- 原生商城通过已有打开条件、进入商城场景时，在点券查询中附加固定访问标记。服务端只为匹配标记、命令类别及当前角色归属的请求记录访问。
- 登录初始化、普通点券刷新、重复打开已显示的商城及未通过打开条件的路径不附加标记；保留原场景切换和应答行为。
- 独立候选基于累计攻坚与扩容兼容客户端；精确输入、原挂接字节、空闲区及范围外字节均有校验，保留累计来源通知。

## 验证

- 原生局部验证覆盖打开、已打开、不可用、连接未启用、其它场景值及登录自动查询；原场景状态、调用约定及Windows映像检查通过。界面构造和网络末端为测试替身，游戏实机验收待完成。
- 服务端回归覆盖真实上行分派、空查询、标记长度/版本、分类及角色归属变化。
- 依赖最终累计客户端发行、玩家实际通道验哈后再切换服务端；源码修改不代表已上线。
