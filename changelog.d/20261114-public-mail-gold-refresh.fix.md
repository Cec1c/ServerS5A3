# 纯金币邮件领取后的角色金币刷新

## 变更

- 邮件领取结果区分角色金币变化与账号钱包变化；纯金币领取提交成功并发送领取 ACK 后，服务端重新读取该角色的权威金币，以单行 op14 刷新客户端，无需重新选择角色或重新登录。
- 刷新只更新金币投影，不重建整套物品容器或打开中的邮件明细；读取完成后再核对会话角色代际，已切换角色或已失效的旧绑定不会收到余额。

## 验证

- 本批加入回归覆盖：纯金币领取的 ACK 后 op14 顺序、权威金额读回、重复领取金额不增长，以及读取期间角色重绑定后旧金币包被丢弃。
- 上述适用回归已在隔离 Linux 执行通过；各包完整范围、跳过项和既有基线诊断见对应 PR 的验证记录。真实 MySQL 事务读回、真实客户端领取后的界面刷新仍待验收。
