# 恢复未写出的队员跟随过图包

## 变更

异步跟随过图的首个房间包发送失败时，只有传输层确认连接仍可用、该包尚未写出且原角色及房间归属仍有效，才保留原任务重试。写入重试间隔为250毫秒，使用既有30秒传输恢复预算，执行前再次检查预算；部分帧或已失效连接继续沿用传输层退役规则，不重放房间包。

恢复预算到期也必须匹配原运行态、运行令牌、房间访问和实例；过期旧任务只会被清理，不会关闭替换后的角色运行或正在个人返城的连接。

房间包已经送达后再遇到无法继续的失败，不会重放已送达的房间包；只有本次操作仍拥有的未完成接收连接会被关闭，随后由既有退出清理移除该成员，其他队员继续加载。

## 验证

覆盖队长在投递后确认个人返城或断线的既有计划继续执行；首次房间包零字节失败后恢复，仅发送一次有效房间包且疲劳与正常队员一致；部分帧失败不重放，调用正式关闭入口清理后剩余三人完成加载。预置已过期的重试时间检查预算上限，不把该检查称为实际等待30秒。所有测试使用本地合成连接，未控制电脑或部署。
