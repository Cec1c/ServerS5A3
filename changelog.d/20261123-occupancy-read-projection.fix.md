# 降低公会投影与仓储读取开销并补齐掉线诊断

## 变更

- 合并并发公会投影构建，复用编码器与排序结果，避免在线推送重复读取婚戒状态。
- 减少独立只读查询的事务与反序列化后的多余复制，统一任务父子记录锁序。
- 门控正常高频诊断日志，为已绑定角色的非主动断线保留轻量结构化摘要。
- 不引入玩家可变资产跨请求缓存，不变更数据库连接池、数据库容量或清理策略。

## 验证

- Linux 仓储相关测试876项通过（3项既有外部数据库条件跳过），桥接定向14项通过；对应私有候选桥接race14项通过。
- 公会投影相同夹具完成前后基准，依赖校验、相关包vet及Linux构建通过。全量vet的既有无关报错单独记录，未宣称全量通过。
