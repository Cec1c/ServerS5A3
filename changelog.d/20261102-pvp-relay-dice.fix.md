# 补齐自由决斗擂台战的骰子与出战流程

## 变更

- 模式 3 在参战者加载完成后发送骰子结果和双方出战席位，解决缺少擂台选人通知导致无法开战的问题。
- 补充替补申请、击败后的队友接替及观战者晚加载快照；重复加载不重新投骰子，退出和结算清理计时器。

## 验证

- 增加双协议入口与多人流程回归；修复前因缺少选人任务失败，修复后通过。
- `go list`、DNF 领域、bridge 全量及 control 测试、`go vet`、服务端构建和源码边界检查通过；擂台随机选人回归连续运行 50 轮通过。
- 客户端静态证据、服务端选择策略及待实机验收范围见 [技术说明](../Docs/PVP_RELAY_DICE_20261102.md)。本次未部署或修改客户端。
