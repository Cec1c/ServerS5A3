# V209 游戏连接套接字缓冲区提升至 256 KiB

## 变更

- 新增精确 V209 客户端候选工具。输入必须匹配 SHA-256 `478f4f5dc070253e7679aa7d8f8fda3b71ea6376569fc794865c44d0107098f4` 和 112549888 字节，并核验实际连接函数的唯一直接调用、两条入口、连接类型、发送/接收缓冲区及 `TCP_NODELAY` 原始指令。
- 仅在 `0x38c83f9` 将 `mov eax,0x400` 的即时数改为 `0x40000`，保持五字节指令和文件长度不变；该值继续同时写入发送、接收缓冲区参数。工具输出独立候选并重算 PE checksum，拒绝覆盖输入或已有输出。

## 验证

- Native Unicorn 离线夹具执行实际 `0x38c8250` 路径，外部 Winsock 与日志叶子使用观察桩。原版 `SO_SNDBUF`/`SO_RCVBUF` 为 1024，候选为 262144；`AF_INET`/`SOCK_STREAM`/`IPPROTO_TCP`、`TCP_NODELAY=1`、异步事件绑定、地址解析、连接参数、寄存器与返回栈保持。另覆盖精确字节门禁、错误长度/摘要、重复应用和已有输出拒绝。
- 以上为固定 EXE 的离线验证，不代表游戏实机或线上断线问题已解决；本项未发布、部署或修改玩家原文件。
