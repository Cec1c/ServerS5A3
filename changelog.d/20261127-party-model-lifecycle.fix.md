# 补齐队友模型、加载和原生连接生命周期

## 变更

队伍成员关系提交后、队伍端点与名单发送前创建跨区域城镇队友 actor，并阻止提前或半套名单。端口重新上报时重播完整队伍快照与 actor 投影；中继腿按角色、会话代次和 TCP 观测地址保持身份，短时自报端口变化不再拆除健康连接。

原生连接准入新增有界轮次重试、nonce 轮换和提交宽限。加载准备按实际准备时间启动 watchdog，瞬时失败快速重试，慢成员从准备满 5 秒开始提示，仍由 25 秒总截止时间处置。加载角色缓存补充转发 `LoadCharacterMirrorStats` 与 `LoadCharacterExtraStats`。

初始队伍读条尚未完成时，迟到回城确认、回城和放弃请求被安全保留；启动器诊断新增回城与原因代码字段。公开文档见 [组队与队友模型生命周期服务端修复](../Docs/PARTY_MODEL_LIFECYCLE_20261127.md)。

攻坚队改名只向修改者补发其紧凑资料，再发送名册；重连时只补发新成员相关外观并清空连接本地视图。资料准备预算按队伍人数缩放，准备截止后仍发送已提交名册。

## 验证

- 已添加跨区域邀请/加入、名单顺序、中继诊断、原生准入重试、加载 watchdog、初始读条回城/放弃、迟入队无提前选择器包及诊断字段回归。
- 已添加二十人攻坚队改名/重连/离队名册扇出，以及资料准备预算过期后仍交付名册的回归。
- 当前 Windows 开发机未执行 Go 测试或构建；主发布流程需在 101 Linux 按精确提交串行执行定向测试、`go vet` 和服务端构建。
- 未执行部署或实机验收；四人首次进图、跨区域邀请、读条超时、回城和重进仍须游戏内验证。
