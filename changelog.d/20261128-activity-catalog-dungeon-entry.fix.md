# 活动配置迁移保留进度，进图提交失败明确回复

## 变更

- 修复同一服务日活动配置更新或回滚导致部分角色无法进入地下城的问题，迁移保留任务原始计数、完成状态、已得积分和奖励领取记录，防止配置切换后重复计分或发奖。
- 进图提交失败按已有原生协议返回拒绝与系统提示，结束客户端等待；保留活动副本重复请求和旧兼容模式的处理约束。
- 迁移策略与同日回滚要求见 `Docs/ACTIVITY_CATALOG_MIGRATION.md`。

## 验证

- 活动领域回归包含升级/回滚、目标升降、积分保留、并发领取、事务失败回滚与服务日切换。
- 桥接回归覆盖真实 PVF 活动状态迁移进图、单人失败后重试、组队路由拒绝、原生拒绝字节和中文系统提示。
- 相关仓储检查、vet、依赖校验与 Linux 服务端构建纳入本次合入验证；源码合并不代表已部署或玩家实机验收。
