# 金币拾取反馈、强化战令计数与选角公会刷新

## 变更

- 金币拾取按当前客户端八个固定队伍槽写出完整结果，保留离队空槽；先校验金额和槽位，再提交原有资产事务。重复拾取只重发已提交结果和余额，不重复入账。
- 使用乔纳森转换材料强化时，将实际扣除的材料身份和数量写入周战令计数；失败但扣料仍计数，拒绝或事务回滚不计数。
- 登录和返回选角只同步持久化公会最后在线时间，将可延后的通知与名单刷新交给各接收者的有界队列，避免等待另一个成员的锁或连接；角色重新绑定后丢弃旧刷新，队列满时不关闭正常会话。

## 验证

- 回归覆盖金币八槽、非法输入不入账、拾取重放、强化成功/失败/拒绝/回滚，以及公会阻塞成员、满队列和角色重新绑定。
- 固定累计客户端离线运行64组金币结果读取，覆盖本人与队友分支及完整读长；原19字节包存在越界读取。界面末端使用测试替身，音效与游戏表现待实机验收。
- 本次不改任务进度规则、金币收益数值或公会经验奖励。
