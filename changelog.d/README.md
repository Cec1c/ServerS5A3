# 独立变更记录

每项改动新增一个 `YYYYMMDD-事项标识.类型.md` 文件，例如 `20261031-peer28-null.fix.md`。日期后必须有唯一事项标识；不能多人共用一个日期文件。类型为 `fix`、`feature`、`change`、`docs`。

文件使用 UTF-8、LF 和末尾换行，最多 16 KiB。复制以下格式，替换标题和正文：

```markdown
---
category: 功能修复
---

# 简短标题

## 变更

- 用户可观察的行为变化、原因和必要依赖。

## 验证

- 实际完成的检查；发布、部署和实机验收分别说明。
```

公开目录只放可公开的功能修复记录。详细方案放 `Docs/`，原始日志、玩家信息和环境资料放 ignored 私有目录。已合并的记录不修改、不删除；后续纠正或验收另建新文件并注明原事项。历史 `changlog.md` 保留，普通改动不再追加。

校验、CI 预览、发布汇总和旧分支迁移见 [完整规范](../Docs/CHANGELOG_WORKFLOW.md)。
