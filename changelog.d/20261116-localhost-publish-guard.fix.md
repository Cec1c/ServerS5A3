# 旧版 Docker 内核 NAT 保留回环发布边界

## 变更

- 增加受进程锁保护的 IPv4 回环发布规则工具，按固定策略幂等插入，保留其他规则；冲突或重复策略拒绝处理。
- 回退按封存的原始存在状态保留预设规则，只移除本次创建的策略；明确要求恢复桥接参数及原始 Docker 运行配置。
- 增加固定 helper 与 Docker 启动前 hook 的受限安装/恢复 API，保留已有匹配文件和无关目录内容；协调器负责批准、持久化及配置切换。

## 验证

- 实际隔离 Linux 18 项工具测试通过；Docker 20.10.24 的 187 个 TCP/UDP/回环绑定、二层正负探针、数据库身份/标记、同配置重启连接、缺一绑定检测及完整回退通过，临时业务 schema 最终为零。
- 启动 hook 的服务管理器调用使用替身，实际 helper 按启动前顺序执行；不冒称 systemd 开机验收或生产同环境验证。
- 该源码变更须由实际发布协调器完成安装及启用，实际主机效果另行核验。
