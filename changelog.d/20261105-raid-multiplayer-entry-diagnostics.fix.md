# 自由组队多人进图回归与选图拒绝诊断

## 变更

- 补充攻坚队自由组队从双人连续扩为三人、四人的真实邀请接受与选图处理器回归，核对每个成员的副本状态、共享参与集合和固定位置。延续 `20261105-raid-party-runtime` 的历史单人占位修复，不改变冻结奖励分组。
- 关闭原始包日志时，普通运行日志保留选图请求的队伍人数、成员准备拒绝、团本地图拒绝和最终准入拒绝阶段。只保留有界标量，不输出账号、原始报文或错误对象。
- 旧拒绝事件的 `reply_sent` 在运行诊断中明确为 `reply_planned`；该事件发生在写包前，不能用作客户端收到回包的证明。准入、回包和事务行为不变。

## 验证

- Linux 专项通过，覆盖历史占位算法对照、双人/三人/四人实际选图、后加入成员错误归属时整队不绑定、诊断写失败与隐私过滤。
- 使用合成角色与地图，不执行客户端渲染器；不代表现场已通过实机验收。尚未部署或发布玩家公告。
