# 玩家内辅参考实现（供参考，默认关闭）

## 变更

- 整理自动拾取、出售/分解/修理、金库和合法相邻房间切换的服务端接口与领域事务验证；保留短期租约、快照复核、幂等回执及穿戴修理投影等通用修复。
- 在 `tools/player-helper` 提供 Windows 插件宿主、SDK、原生金库桥接及夹具、隔离构建脚本和登录器会话发布示例，作为 Draft 参考方案供上游评估。
- 服务端仅在 `DNFBRIDGE_PLAYER_HELPER_REFERENCE=on` 时开放接口，自动拾取另需 `DNFBRIDGE_HELPER_AUTOPICKUP=on`；宿主默认不启用插件。示例公钥需自行替换，HTTPS 网关/登录器/发行签名需接入。
- 当前适配依赖精确客户端摘要，详见 `Docs/PLAYER_HELPER_REFERENCE.md`；不携带私有运行配置、发行私钥或玩家资料。

## 验证

- .NET SDK/Windows 宿主/登录器示例编译通过；SDK 116 项检查通过，包括 50 次插件重载及加载上下文释放。
- 服务端专项覆盖租约、鉴权、资产回滚、快照变化、重复请求、机器费用、组队导航和穿戴修理投影；Linux 完整验证结果记录于 PR。
- Windows 宿主和原生 hook 未在本参考分支重新执行实机验收；本贡献未创建 Release、更新玩家通道或部署服务端。
