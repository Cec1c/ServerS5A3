# 三钱包与强化/增幅金币客户端源码

从混合活动载荷中独立提取已授权函数。gold_wallet.h 公开额度与预检，private_upgrade_gold.h 保持原生成功报价后的七分之一金币及材料换算例外。
MSVC x86 编译 economy.cpp 为对象；挂接地址及调用约定保留于源码。不能直接将新对象拼接到任意EXE；须由客户端整合方分配固定载荷地址并校验匹配基线。
test_upgrade_gold_offline.py 接收实际累计候选与map验证2160个离线场景，其旧载荷节名固定，不宣称对本提取对象执行了游戏验收。
完整旧活动/节日载荷、其余构建与部署工具不在本次授权内。原有群服规则玩家验收与公开构建分别记录。
