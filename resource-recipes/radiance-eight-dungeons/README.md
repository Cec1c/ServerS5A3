本配方仅向`etc/independent_drop.etc`追加八图材料规则：310、311、312、313、314、315、316、7539地图的普通/精英/超级精英怪各10000/1000000，领主100000/1000000，每次一个10163136次元光辉，无保底。专用裂缝领主走既有同代材料管线，不改原物品或其它地图。

输入PVF SHA256为`d3507920cdb8038b900ab9897fdc181ff97840c775a06d4c2108b656cc952c56`，外部PVF-CLI SHA256为`32954604a61342de3304b6412c8df8e038cd1998a4c94829ca5152c7ccef5178`。工具需支持schema 2 typed-token patch/verify及read tokens/text契约；该旧通用工具本体不随本次授权公开。提供CLI摘要和接口不表示工具本体或完整历史资源已获公开授权。

运行：`python -B build_candidate.py --base <匹配的PVF> --tool <匹配的PVF-CLI> --output <不存在的输出目录>`。

脚本先核实八个地图路径、材料名称/类型和原掉落表末尾，再生成唯一条目修改；patch与verify回执须证明其余条目未变，逐token读回原掉落表前缀及新增50个token。史诗制作配置逐token保持。本配方不修改周加工次数，不发布客户端，不生成索引或改变服务/数据库。
