本目录公开金色小晶块价格、练级少女角色限购、六种 +13 增幅券图标、地下城材料掉落配方及经逐项授权的资源发布工具增量。配方使用固定输入摘要，生成新目录；完整 PVF、客户端、六索引、生产配置、凭据、玩家资料和私有 Git 历史不随目录分发。

| 目录 | 内容 | 执行范围 |

公开配方不自动启用某个服务器的商品策略，也不执行部署。既有商品 ID、资源路径和 private_ 命名保留，以避免改变资源引用；该命名不代表本目录仍未公开。每次实际发布仍须从自己的权威累计输入生成，并通过相应服务的签名、配对、备份和维护流程。
