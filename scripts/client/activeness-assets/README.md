# 活跃度内嵌图块与布局（公开提取）

本目录在 2026-11-02 经用户授权公开 08-05：保留每日活跃度窗口使用的帧映射、文字颜色和嵌入布局，共 9 个源文件。提取时保留原内容，部分头文件将 CRLF 行尾归一为 LF；帧数据及布局数组保持。

## 文件

- **Activeness.xui**：窗口布局 XML。已公开的 scripts/client/activeness-ui/Activeness.xui 与本文件内容一致，仅比本文件多一个行尾 LF。
- **art003.h、art004.h、art005.h、art007.h、art008.h、art009.h**：历史或备用的活跃度帧映射，含尺寸、档位、行列帧、控件名和文字颜色。本目录没有 art006.h。
- **art010.h**：当前累计组件使用的帧映射；布局数组单独保存在 layout.h。
- **layout.h**：布局嵌入数组。已公开的 scripts/client/activeness-ui/layout.h 与本文件逐字节一致。
- **SHA256SUMS**：本目录公开文件的摘要。

## 使用

公开的 ../activeness-ui/activity.cpp 包含 layout.h 和 skin_mapping.h；其中 skin_mapping.h 对应当前 art010.h 映射。本目录保留原命名便于比对，不要求覆盖现有组件。历史头文件只在匹配皮肤时使用。任务、奖励、帧号和 NPK 路径必须与匹配的 PVF、NPK 及 ../activeness-ui 构建输入一致。未知配置不应被当作可领奖状态。

本目录只提供静态数据，不提供覆盖完整私有 payload 的安装或部署脚本。集成时须保留宿主客户端已有的通知、协议和累计修改，并单独核对原生窗口行为。

内容只有活跃度图块、文字颜色和布局数据，不含位图二进制、寄售或钱包代码、七分之一费用、生产配置、部署脚本或玩家数据。本次未编译 EXE、未重生成 PVF、未运行游戏或执行完整测试；源码公开不修改玩家更新通道。
