# 小队奖励页离队成员卡片刷新

小队奖励页打开后，奖励缓存按收到的卡片增量合并，短列表不会删除已离队成员；已绑定的卡片也不会因重复投影重新绑定。本候选在绘制和命中入口检查当前小队关系，使离队成员的整张旧卡片在已打开页面中隐藏，同时保留其已取得的奖励资格。

范围限定为该卡片类的 category0。本人卡片保留；缓存本人有效但没有 party 时只保留本人；本人仍在关联 party 且 namespace 一致时，以八项完整 DWORD key 判断其他 owner。category1/2/3、arena、未绑定卡片及无法确定关系的上下文沿原行为。每次重新查询，不写持久隐藏标记；同一成员重新入队可恢复显示。

三个 outer vtable 入口分别覆盖整行绘制、父树命中与独立输入/绘制。隐藏会暂停该行 tick 和子树遍历；父页面的完成判断读取 owner 绑定，候选保留此字段。固定 v161 的页面完成遍历、手动与计时状态选择在五种行状态下与原路径一致，具体切页动作仍需 GUI 验证。

四个固定卡槽属于奖励协议 slot，候选保留原槽位、坐标与绑定，不重排为当前 party 槽。离队后的空位不重新赋予新成员，也不删除 category2 冻结团队资格。重新打开页面时仍按当前关系过滤既有奖励卡片。
