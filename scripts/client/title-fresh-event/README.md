# 称号右键卸下一次性事件候选

直接右键已装备称号时，称号控件会通过真实owner与record回调进入装备请求，并在producer内再递归一次。旧边界把这次内层调用作为普通刷新，丢失手动卸下标记。绘制回调中的旧右键目标又可能残留，因此不能只凭父帧提升标记。

本候选在真实右抬目标写入时保存一次性目标，在UI帧入口和通用输入根入口清理它。只有精确称号父帧与参数全部匹配，且一次性目标等于当前右键目标，才消费一次并写出标记2；残留目标、重复刷新和错误目标不提升，原17组边界保持。

`build_fresh_event.py` 只接受公会累计加锁前输入 SHA256 `7777de23d051b28e7cabf75328a8a5b911f50768220fbff8f2e971e3b953fe5f`。状态放在新增可读写、不可执行的 `.titlert` 段，代码放在既有 `.op19ui` 空尾。生成器核对完整输入、空白段头、原钩子、原门和空闲区，声明修改范围并更新PE校验和，拒绝错误版本、重复应用、未知尾部和已占用区域。

```text
python scripts/client/title-fresh-event/build_fresh_event_cli.py --input guild-raw.exe --output title-internal.exe
```

输出是未加锁的内部构建材料，不能进入发行附件或玩家通道。历史 `build_candidate.py` 保留原df496输入契约，仅供旧测试框架复用；不能修改其输入常量绕过检查。

安装Unicorn后，以环境变量 `TITLE_FRESH_RAW` 指向精确输入，运行：

```text
python -m unittest discover -s scripts/client/title-fresh-event -p test_fresh_event.py -v
```
